A brief without templates\agents\BRIEF-PREAMBLE.md is not sent; a report that does not cite R-numbers is returned. Rules that must hold every time (EGM prompt gate, secret guard, no native plan mode) live as hooks in settings.json; memory only records why. After any rule change, check the hook text still matches CLAUDE.md.
