Core (hadavin-sdk) gate before every commit: `uv run --all-extras --group test ruff check`, `uv run --all-extras --group test ruff format --check`, `uv run --all-extras --group test pytest`, `bandit -ll`. Gate on pytest's own exit code, never on a `| tail` pipe (the pipe's status is tail's): `pytest ... > log 2>&1; rc=$?; tail -n 1 log; [ $rc -eq 0 ] && git commit ...`. Never run plant/mutation scripts that rewrite files while a gate runs. Run tests with no cloud configuration in the environment (a test that forgot to fake a client must not build a real one). Use `.github/workflows/ci.yml` as the local checklist and do not start the next change until CI is green.
