**What this proposes**
A "lead desk" demo. It writes every incoming sales lead to a database file before acting. It then gives one verdict (new, duplicate or review), one CRM row and one follow-up email per email address. It is run locally against demo servers that stand in for the CRM, the mail system and the AI step. The PR only rewrites docs and comments so they match what the code and tests show, plus three small code changes.

**How the existing system works, per the docs**
Requests arrive through two "doors" (form or webhook). A receipt is written first. A repeated request number gets its stored answer back (a "replay"). A new request number with a known email is a "duplicate". A background "reaper" retries or resolves stuck follow-ups, up to 5 automatic tries. If the desk cannot tell whether an email left, the follow-up is marked UNKNOWN for a person. A keyed mail system ignores a repeated send key. A blind one does not, so the desk stops and asks a person.
