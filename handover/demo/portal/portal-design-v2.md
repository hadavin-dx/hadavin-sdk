### 2.1 server.py: routes and check order (WP-A)
`_route(method, path)` (server.py l.63-81 at 337f5bf) gains four cases, before `case _`:
```python
case ["ui"] if path == "/ui":            name, arg, allowed = "ui_redirect", None, "GET"
case ["ui", *rest]:                       name, arg, allowed = "ui_static", "/".join(rest) or "index.html", "GET"
case ["api", "ui", *rest] if rest:        name, arg, allowed = "ui_api", "/".join(rest), "GET"
case ["api", "demo", *rest] if rest:      return ("demo", "/".join(rest))   # any method; the extension answers 405
```
Route tuples returned: `("ui_redirect", None)`, `("ui_static", relpath)`, `("ui_api", endpoint)`, `("demo", rest)`. `parts` are already `unquote`d per segment (l.65), so `%2e%2e` arrives as `..` and simply misses the fixed map (404).

`_dispatch` (l.151-195) order, frozen:
1. **Host / Origin / Sec-Fetch-Site gate, every route, before `urlsplit`** (new `_gate_ok()`):
   * `Host` header required; its host part (port stripped, lower case, IPv6 brackets kept) must be in `allowed_hosts = {"127.0.0.1", "localhost", "[::1]", config.bind (unless "0.0.0.0" or "::"), *config.allowed_hosts}`. The port is not compared (rebinding is about the name). Else 403 `{"error":"forbidden_host"}`.
   * `Origin` present: must equal `http://<allowed host>:<bound port>` exactly; `Origin: null` is refused. Else 403 `{"error":"forbidden_origin"}`.
   * `Sec-Fetch-Site` present and not in `{"same-origin","none"}`: 403 `{"error":"forbidden_origin"}` (blocks pages on other local ports, e.g. the n8n editor tab).
   * The body is drained with `_skip_body()` before the 403 reply. Requests without `Origin`/`Sec-Fetch-Site` (n8n server side, scripts, tests) pass when `Host` passes.
   * **Docker case:** n8n in Docker reaches the desk at the host address, e.g. `host.docker.internal`. Then set `DESK_BIND=0.0.0.0` and `DESK_ALLOWED_HOSTS=host.docker.internal` (new `Config.allowed_hosts: tuple[str, ...] = ()`, comma list in `from_env`, each name validated `^[a-z0-9.-]{1,253}$|^\[[0-9a-f:]+\]$`). The video uses portable Node n8n on 127.0.0.1, so the default needs nothing.
2. `urlsplit` failure: 400 (unchanged).
3. `_route`: 404 / 405 (unchanged texts).
4. Handler: `ui_redirect` -> 308, `Location: /ui/`, empty body. `ui_static` -> `relpath.startswith("demo/")` ? `server.demo.assets[relpath[5:]]` (404 when `server.demo is None` or missing) : `portal_api.STATIC[relpath]` (404 when missing); sent by `_send_bytes`. `ui_api` -> `portal_api.handle(desk, endpoint, parts.query, server.started_at)` -> `_send(status, obj)`. `demo` -> 404 `{"error":"not_found"}` when `server.demo is None`, else `body = rfile.read(min(content_length, DEMO_BODY_MAX))` for POST, then `server.demo.handle(method, rest, body)` -> `_send`.

`make_server` (l.295-310) adds two lines: `server.started_at = int(time.time())` and `server.demo = load_demo_portal(desk)`. `_Server` declares `started_at: int` and `demo: DemoPortal | None`.

New `_send_bytes(status, body: bytes, content_type: str)`. Both `_send` and `_send_bytes` write `SECURITY_HEADERS` (constants.py):
`Content-Security-Policy: default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self'; connect-src 'self'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Cross-Origin-Resource-Policy: same-origin`, `Cache-Control: no-store`. ### 2.2 loader.py (WP-A)
```python
class DemoPortal(Protocol):
    assets: Mapping[str, tuple[bytes, str]]            # "portal_demo.js" -> (bytes, "text/javascript; charset=utf-8")
    def handle(self, method: str, path: str, body: bytes) -> tuple[int, Any]: ...

def load_demo_portal(desk: Desk) -> DemoPortal | None:
    """None ONLY when the demo module is absent: ModuleNotFoundError whose .name is "demo_only" or
    "demo_only.portal_demo". Any other import error propagates (a broken extension fails loud)."""
    try:
        mod = importlib.import_module("demo_only.portal_demo")
    except ModuleNotFoundError as e:
        if e.name in ("demo_only", "demo_only.portal_demo"):
            return None
        raise
    return cast(DemoPortal, mod.make(desk))
```
`loader.py` stays the only product file naming `demo_only` (existing `test_no_demo_only_outside_loader`).

### 2.3 portal_api.py (WP-A, new)
```python
STATIC: Final[dict[str, tuple[bytes, str]]]   # built at import: rglob over Path(__file__).parent / "portal";
```

Endpoints (all GET; unknown endpoint 404 `not_found`; unknown or repeated query parameter 400 `{"error":"bad_query","field":<name>}`):

| Endpoint | Query | Fixture |
|---|---|---|
| `summary` | none | `summary.json`, `summary-empty.json` |
| `leads` | `q` (0..`SEARCH_MAX`=100 chars), `state` (one of `FOLLOWUP_STATES` or empty), `offset` (0..`OFFSET_MAX`=100000), `limit` (1..`LEADS_LIMIT_MAX`=100, default `LEADS_LIMIT_DEFAULT`=50) | `leads.json`, `leads-empty.json` |
| `leads/<lead_id>` | none; `lead_id` must match `^L[0-9a-f]{12}$` else 404 | `lead-detail.json`, `lead-detail-not-found.json` |
| `review` | none | `review.json` (every kind), `review-empty.json` |
| errors | | `error-envelope.json`, `error-busy.json` (503 when the read hits a lock: `db.is_busy`) |

Reading rules:
* One connection per request: `sqlite3.connect(Path(desk.config.db_path).resolve().as_uri() + "?mode=ro", uri=True, timeout=BUSY_WAIT_SECONDS, isolation_level=None)`, `PRAGMA query_only=ON`, `BEGIN`, all SELECTs, `COMMIT`, `close()` in `finally`. One read transaction per response.
* All SQL is fixed text with `?` parameters; optional filters use `(? = '' OR f.state = ?)`, so no SQL is assembled and no `noqa: S608` is needed. `q` uses `LIKE ? ESCAPE '\'` after escaping `\`, `%`, `_`, over name, email, company, lead_id and the first request id.
* `summary.counts` comes from ONE SELECT with the five sub-counts (same predicates as `_COUNTS_SQL`) inside the read transaction; `reconciled` = `received == new + duplicate + review + open`; never call `desk.counts()`. `refused_at_door` = new public `Desk.rejected_envelopes() -> int` (reads `self._rejected` under `self._rejected_lock`; the only desk.py change; no decision logic touched). `needs_action` = `SELECT count(*) FROM review_items WHERE kind IN ('review','failed','unknown')` (the schema's own view). `waiting` = open receipts and pending/sending follow-ups older than `now - config.stall_seconds` (same predicates as `_REVIEW_SQL`'s stalled branches).
* `series`: 60 buckets (`SERIES_BUCKETS`) of 5 s (`SERIES_BUCKET_SECONDS`); first `t` = `(now // 5) * 5 - 59 * 5`; a receipt counts in the bucket that holds its `decided_at`, under its verdict; open receipts are not in the series.
* `recent`: the 12 (`FEED_ITEMS`) newest events from one `UNION ALL`: receipt received (`received_at`), verdict (`decided_at`), follow-up last change (`updated_at`), ordered `at DESC, receipt_id DESC`; `name` joined from `leads`.
* `leads/<id>`: `duplicates` = receipts with `outcome='duplicate' AND outcome_lead_id=?`, newest first, at most `DUPLICATES_MAX`=50, plus `duplicates_total`; `differing` = for each name in `differing_fields`, `{field, first, this}` from the first receipt's payload and this one's (`json.loads`). `review_items` = item ids whose `lead_id` is this lead.
* `review`: rows from `desk.review()` (the desk's own list and hints), then names from the read connection (leads are write-once, so a later snapshot always holds the name), then `tab`, `title`, `reason_text`, `actions` from this fixed table:

| kind (prefix) | reason | tab | title | actions (id: endpoint body; confirm?) |
|---|---|---|---|---|
| failed (F) | any | action | Follow-up failed; nothing was sent | `retry`: `/review/F…/retry`, no body, no confirm |
| unknown (F) | not `crm_unconfirmed` | action | UNKNOWN: the email may or may not have gone out | `resolve_sent` {"decision":"sent"} confirm; `resolve_not_sent` {"decision":"not_sent"} confirm |
| unknown (F) | `crm_unconfirmed` | action | UNKNOWN: the CRM may or may not hold this lead | `resolve_crm_present` confirm; `resolve_not_sent` confirm (`sent` never offered: the desk refuses it) |
| review (R) | `incomplete:<fields>`, `invalid_email`, `bad_field:<f>`, `internal_error` | action | Incomplete request: … / The desk could not decide this request | none (hint shown) |
| stalled (F) | `pending` | waiting | Queued longer than <stall_seconds> s | `retry` |
| stalled (F) | `sending` | waiting | Sending longer than <stall_seconds> s | none |
| stalled (O) | `open receipt` | waiting | Request received, no verdict for longer than <stall_seconds> s | none (desk `HINTS["O"]`) |
| duplicate_with_new_info (D) | JSON field list | info | Repeat with new details: <fields> | none |
| replay_payload_differs (D) | text | info | Same request id sent again with different data; the first answer stands | none |
Action element: `{id, label, endpoint, body, confirm: {title, body, verb} | null}`. Exact words: `review.json`. Young open receipts (younger than `stall_seconds`) appear only in `summary.counts.open` (R368: counted, never hidden).

Constants (constants.py, WP-A): `SEARCH_MAX`, `OFFSET_MAX`, `LEADS_LIMIT_MAX`, `LEADS_LIMIT_DEFAULT`, `DUPLICATES_MAX`, `FEED_ITEMS`, `SERIES_BUCKETS`, `SERIES_BUCKET_SECONDS`, `DEMO_BODY_MAX` (4096), `HTTP_FORBIDDEN` (403), `HTTP_PERMANENT_REDIRECT` (308), `SECURITY_HEADERS`, `STATIC_TYPES` (suffix -> content type). Ruff PLR2004 and mypy strict (`--platform linux` and `--platform win32`) pass.
