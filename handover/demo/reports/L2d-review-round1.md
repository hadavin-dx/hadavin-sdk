# Review of live_l2 tools (L2d snapshot), egm-implementation-readiness, fresh, static read only
Verdict: the checker cannot yet be trusted as "never PASS on loss or duplication". All-lost, missing-lead and double-send books ARE caught and tested.
F1 Blocker: a CRM follow-up lost on every sent lead passes: check 4 only requires CRM rows to be a subset of crm_done leads; nothing requires state `sent` to have crm_done=1 and a CRM row (check_invariants.py:360-389). No test plants it.
F2 Major: scenarios with max_failed=None (model-timeout, model-429, -malformed, -refusal, -5xx, -flaps, catcher-down) pass a book where every follow-up `failed`; a `failed` without mail needs no last_error. Fix: per-scenario ceiling from the fault window, last_error required, leads submitted after recovery must be `sent`.
F3 Major: the checker never confirms the fault fired or that the model was used: model_calls_of gives 0 for an empty/result-only log and check 5 passes vacuously; catcher-* and model-flaps have no minimum evidence; harness_faults checks only crash events; event thread join ignored.
F4 Major: check 5 bounds 2 (crash) and 6 (model down) can hide a real double model call per lead (slack granted to every lead; a re-ask after a 200 is invisible). Fix: count leads with more than 1 call (cap at DRIVE_MAX in crash scenarios), rule "no arrival after a 200 result for that lead", cap non-200 calls at SEND_MAX_ATTEMPTS; CLI default bound 6 too loose.
F5 Major: check 1 compares only line counts; a missing request X plus one duplicated line passes; facts distinct_request_ids not used. Fix: compare distinct ids; store the full intended (door,id) list.
F6 Major test gaps (mutations that survive): check 1 foreign-receipt, mismatch; check 2 lead with no follow-up row; check 3 stray; check 4 twice, extra vs not_leads; no wrong-recipient test; check 6 is report-only in the campaign (no --max-503-rate), so "ALL 7 HOLD" is 6 enforced plus 1 report-only.
F7 Major: driver Pool.map hangs if a worker is killed; orphans may keep sending.
F8: marker checks silently skipped when the facts file is missing with --intended. F9 nits: boot() failure aborts the campaign leaving only earlier scenarios; MODEL_DOWN_MODES omits malformed_label; crash driver retries only ~0.5 s; README-L2.md stale lines; catcher record_of malformed charset; case-sensitive address compare; recheck takes bounds from the current catalogue.
SMTP outbox: mapping sound after text start (ambiguous), refused only for 4xx/5xx before text and input problems; header injection characters rejected; no resolver call. Minor: _ADDRESS allows , ; " ( in `to`; bare "250" reply; no HELO fallback; infinite timeout OverflowError.
