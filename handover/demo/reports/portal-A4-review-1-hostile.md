# A4 review round 1, lens: honesty and hostile input (egm-design, snapshot A4-r1)
Saved from the reviewer's inline report. Reading only: no shell, nothing run. No Blocker on the default loopback bind; 5 Majors (M1 becomes Blocker on a non-loopback bind).
- M1 The 64-connection cap is checked before the Host gate: 64 silent or 1 byte/s sockets hold every slot for 10 s, reconnect, and give a permanent 100% outage (about 6 connections/s). Before A4 this needed thousands of threads. Fix options: shorter first-line deadline, evict oldest header-phase connection when the cap is hit, higher cap, per-peer cap; test: N-1 slow sockets and a fast client still gets 201.
- M2 A handler thread (slot) is held for the whole follow-up (`run_followup` in `_dispatch` finally), so a hung mail system or CRM can pin 64 threads and lead 65 gets 503 before any receipt. Count the slot only until the reply is flushed, or run follow-ups outside the cap.
- M3 The cap's 503 `{"error":"busy"}` has no `receipt_id`, no Retry-After, no security headers, is indistinguishable from the lock-busy 503 (the driver counts it as database contention), and closes without draining (reset can destroy the 503). Fix all; document.
- M4 contract.md does not describe the 10 s deadlines, the cap, the header-phase 408 (`{"error":"request_timeout"}`) vs the body-phase 408 (`...,"receipt_id":null`), or the cap 503. Unify and document.
- M5 `portal_actions` always lists `demo_controls` although /api/demo/* is 404 without the demo extension; test compares a constant with itself. Derive from what is loaded; test with and without the extension.
- M6 test_150/300 simultaneous tests pass with 503 accepted and no retry, so they no longer prove "no lead lost" above the cap; assert desk-recorded count versus client results and add a retry test.
- Lost-lead check for 408: no path found where a 408 is sent after a commit (body is read before desk.process).
Nits: `_resolve` has no TimeoutError handler; host_check/origin_check are constants (say so in spec/contract); page must say "browsers on other sites", must not show a bare "read-only" badge, must key "this computer only" on `access.bind`; `mode` is a class self-declaration; first-page sentinel hides rows with received_at >= 10**18 while total counts them (use 2**63-1 or no WHERE on the first page); `count(*)` per page; cap tests read `_live` via getattr(-1) (fail on old code for the wrong reason), vanished-client test uses a fixed sleep, timing margins `took < 3`; body 408 inflates the rejected counter; 10 s is a judgement not a measurement.
Could not check: frontend, demo extension, schema.sql NOT NULL, demo_only.burst, drive semaphore values (`_background`, send timeout).
