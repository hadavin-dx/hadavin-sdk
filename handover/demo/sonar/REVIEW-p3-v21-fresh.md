## Findings (worst first)
### MAJOR M1: `_unused_result_sinks` is unsound in constructs the NOTES say it handles; 8 mutants of real sites survive it AND the behaviour tests
Claim in the test/NOTES: "names that CERTAINLY hold a helper result on every path (walrus, try handler, loops...)". Measured on 57 synthetic shapes (harness runs the real test functions): 33 accepted although the sink uses a raw value. The ones that matter, with the cause in the code:
* walrus in an uncertain context (`c and (p := raw)`, `x if c else (p := raw)`, `assert (p := raw)`, a comprehension element): `expr()` skips the binding when `certain=False` and does NOT discard the name, so p stays "clean". Fix: in a non-certain context, a binding must discard the name (and comprehension walrus must leak to the function scope).
* `break` / `continue`: not modelled (the stmt falls through), so the state at the break is never joined into the loop exit: `for ...: p = raw; if c: break; p = confine(..)` then `p.read_text()` is accepted. Same for `while True`.
* try handler start state = the state on entry to the try, but the body may already have rebound the name before it raised (`try: p = raw; c() except OSError: return p.read_text()` accepted). Fix: handler state = entry minus every name assigned anywhere in the body.
* `nonlocal`/`global` in a nested function: the outer state is not updated after the call (`def swap(): nonlocal p; p = raw` ... `swap()` ... `p.read_text()` accepted). A nested def is also read at the definition point (stated limit) so `def rd(): return p.read_text()` then `p = raw` is accepted.
* subscript / attribute store (`ps = [confine(a)]; ps[0] = raw; ps[0].read_text()`) is not a rebinding to `_names_of`, so accepted.
* sink list is incomplete: `mkdir`, `rename`, `replace`, `rmdir`, `os.replace/remove/makedirs`, `shutil.*` are not sinks (`os.replace(tmp, raw)` unseen); a bound method kept and called later (`rd = raw.read_text; rd()`) or `getattr(raw, "read_text")()` is not a sink (count 0).
* derived-from rules too loose: `clean / raw` and `Path(clean, raw)` / `clean.joinpath(raw)` are clean although an absolute right operand replaces the base (stated limit, but this is the classic escape); `Path(clean.read_text())` and `json.loads(clean.read_text())["x"]` are "clean" (file CONTENT treated as a confined path); `_is_exit_call` accepts ANY `.exit()` call (`thing.exit()` in a handler ends the path); `with Quiet():` (any swallowing context manager except literally `suppress`) is trusted; match-capture rebinding not seen; class bodies, decorators and default arguments are not walked.
* false rejects (harmless, noisy): `os.open(q)`, `gzip.open(q)`, `os.unlink(q)` (receiver is the module), `open(file=q)`, `sqlite3.connect(database=...)` (keyword path), `Path.read_text(q)`, bare `exit(2)`.
