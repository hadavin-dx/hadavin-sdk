## Failures / findings first
Minor 1 (regression the NOTES do not list): double negation `! ! [ x ]` / `if ! ! [ x ]; then` / `{ ! ! [ x ]; }` was flagged by v3.2 (it treated `!` anywhere as a separator) and is NOT flagged by the delta (it allows exactly one `!\s+` before the assignments). It is a real single-bracket test in bash, so this is a new false negative. Contrived (not in the repo, no tool emits it), but the NOTES say only `echo a ! [ x ]` changes, and the "known gaps" list in the test docstring lacks it. Fix: `(?:!\s+)*` (bounded `{0,4}+`) or list it as a known gap. Measured: p2.py in /tmp/work/rv28-x/cmp.
Nit 2: one own mutant survived (1 of 26): making `'...'` consume a backslash escape (`'(?:[^'\\]|\\.)*'`). The existing probe `echo 'a\'; [ x ]` is still flagged by the mutant (unmatched quote). A probe with a later quote, e.g. `echo 'a\'; [ x ]; echo 'b'`, kills it (the delta flags it correctly: measured).
Nit 3: no repo `.github/actions` directory exists (checked on db54e13 and on the combined tree): the composite scan only runs on synthetic trees; the real-tree test passes because `Path.glob` on a missing directory returns nothing (python 3.12 and 3.13 both run). Fine, but a future malformed `action.yml` would raise from yaml (loud, not silent).
Nit 4: temp-repo tests call `hygiene._git_text` without scrubbing GIT_DIR / GIT_INDEX_FILE; same pattern as existing tests (test_hygiene.py:126, :226, :253). Only matters if run from a git hook.
Nit 5: `.github/actions` glob only matches `*/action.yml|yaml` one level deep (the GitHub layout; also correct).
