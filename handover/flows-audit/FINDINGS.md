## Words used in this file
- take = the one filmed run of the demo, made with the files in n8n-flows-real-v5 and n8n-flows-film-v5. "not in take" = a file or document the filmed run does not use.
- entry flow (the "door") = a flow that receives a lead from outside. "desk doors" = the two old entry flows that send leads to the desk program; all other uses of "door" in this file mean an entry flow.
- lease = the time (45 s) one flow run holds a lead before the recovery flow may take it over. claim (database step) = the first INSERT that records a lead. claim (statement) = a sentence in the run sheet or page statements that a reader is told is true.
- stand-in = a small test program that plays the real service (mail server, CRM, stage service).
- UNVERIFIED = needs a running n8n, HubSpot, a mail server, the desk program, or a document that is not in this repository. IMPOSSIBLE-NOW = cannot be checked here.
- Tier A = files used in the take or by the desk entry flows (every step judged). Tier B = older versions (every step listed, judged only where it differs from its successor).
- class: dead = nothing reaches or uses it; duplicate = a copy of something else; store = where data is kept; ops = failure behaviour; security = access or leakage; claim-not-backed = a written claim no flow step supports; inconsistent = two places disagree; unverified = cannot be settled from the files.
- Severity rubric (PLAN-002 section 4): Blocker = could lose or double-apply a lead or mail, leak a secret or personal data, or a published claim is false; Major = wrong failure-path behaviour, a second store for one job, or a claim with no backing step; Nit = naming, leftovers, wording.
