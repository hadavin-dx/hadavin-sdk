## Words used in this file (one word, one meaning)
- mail = an e-mail message. e-mail address = the address a message goes to. Never "mail" for the address, never "address" for the message.
- mail service = the service that sends e-mail messages. test mailbox = the mailbox that receives them in a stand-in scene.
- mail step = the step in the n8n flow that sends the lead's e-mail message.
- CRM = the program where a company keeps its customer contacts (the customer list). real CRM service = a real vendor service. stand-in CRM = our own small test program that acts as a CRM.
- stand-in = our own small test program in place of a real service. In captions I write "stand-in" with its plain gloss the first time ("test copy").
- lead = one made-up person who asked for contact. lead ID = the code that names the lead (the same lead sent twice has the same lead ID).
- lease = how long n8n waits before another run takes over a lead whose run stopped (45 seconds in these flows). On screen: "setting: lease 45 s".
- the person who looks after the leads = who receives the alert e-mail message (a setting called DESK_ALERT_TO in the real flows; a test address in the film flows). I do not call this person "the owner" in text for viewers.
- stop point = where in the lead's journey n8n was stopped: K1 = after the lead was noted, before the CRM write; K2 = after the CRM write, before the mail step; K3B and K3 = once the mail step had begun. Lead-column use only; a viewer sees the plain description.
- screenshot = a still picture. A "take" = a filming run. I never write "take one picture"; I write "capture one screenshot" (W-10, W-22).
- Lead table columns, one name each (W-23). Plain name (name on screen): lead key (lead_key), state (state), attempts (attempts), mail sent (mail_sent), alert sent (alert_sent), last change (updated_at). "Mail sent" means the mail step was started, not that the mail arrived.
- Numbers rule (W-18): a recovery number is quoted only for one stop point at a time, with its number of runs and "relayed". Never a pooled range across stop points. Never "within 60 seconds".
- Quotes: a sentence to paste sits in double quotes; a quote inside it uses single quotes (W-24).
