## How to read the tables
- "Paste this" holds ONE clean string in double quotes (the quote marks are not pasted): the words that go in one place in one go (one caption, one spoken passage, one card line, one file line). It has no label, no condition, no placeholder and no alternative. If a cell reads NO PASTE, nothing is pasted; the note says why. If a cell reads DELETE, delete the current sentence. A row with two places or two uses (voice and screen, default and D1 variant, two file lines) is split into rows with a letter (a, b), one string each. Conditions are in the last column.
- A paste string may be only part of a line when the row is FILE EDIT and the "exact current sentence" cell starts or ends with three dots, or shows only part of a sentence: then the string replaces exactly the part shown, and the rest of the line stays.
- "Goes where": SCREEN = text that appears in the video. VOICE = spoken by the narrator. CARD = a line on the closing card. PAGE = a written statement for a reader of the demo page. FILE EDIT = the replacement text for a line of a working file (run sheet, plan, README); never said and never shown. Sections 3 and 4 use the same column and the same words.
- Section 3 holds PAGE and FILE EDIT rows. Section 4 holds only FILE EDIT rows: it has no viewer sentence. SCREEN, VOICE and CARD rows are in sections 1 and 2.
- Everything for the coordinator (sources, conditions, which line of the run sheet it replaces, what to say instead if a rehearsal fails) is in the last column.
