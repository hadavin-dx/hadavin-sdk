## How to read the tables
- "Paste this" holds ONE clean string in double quotes: the words that go in one place in one go (one caption, one spoken passage, one card line, one file line). It has no label, no condition, no instruction, no placeholder, no alternative and no quote mark inside. If a cell reads NO PASTE, nothing is pasted; the note says why. If a cell reads DELETE, delete the current sentence. A row with two places or two uses (voice and screen, default and D1 variant, two file lines) is split into rows with a letter (a, b), one string each. Conditions are in the last column.
- "Goes where": SCREEN = text that appears in the video. VOICE = spoken by the narrator. CARD = a line on the closing card. PAGE = a written statement for a reader of the demo page. LEAD = the replacement line for a working file (run sheet, plan, README); never said and never shown. For LEAD rows the string is the replacement line for that file. Sections 3 and 4 use the same column and the same words (PAGE for a reader of the demo page, LEAD for a working file, SCREEN for the video).
- Section 3 holds PAGE and LEAD rows. Section 4 holds only LEAD rows: it has no viewer sentence. SCREEN, VOICE and CARD rows are in sections 1 and 2.
- Everything for the lead (sources, conditions, which line of the run sheet it replaces, what to say instead if a rehearsal fails) is in the last column.
