## Words and ids (explained before first use)
Plain words
- mail = an e-mail message. e-mail address = the address a message goes to. Never "mail" for the address.
- mail service = the service that sends e-mail messages. test mailbox = the mailbox that receives them in a stand-in scene. stand-in mail server = our own small test program that receives them and can cut the connection on purpose.
- mail step = the step in the n8n flow that sends the lead's e-mail message.
- CRM = the program where a company keeps its customer contacts (the customer list). real CRM service = a real vendor service. stand-in CRM = our own small test program that acts as a CRM.
- stand-in = our own small test program in place of a real service ("test copy" in captions).
- lead = one made-up person who asked for contact. lead ID (lead key in the table) = the code that names the lead; the same lead sent twice has the same lead ID.
- door = one of the two ways a lead enters: the form entry (path mf-form) and the e-mail-style entry (path mf-hook).
- claim = the row that n8n writes in the lead table when it starts a lead; a second claim for the same lead ID is refused ("ON CONFLICT DO NOTHING" in the insert). "Claim window" = the time (720 seconds for an alert) during which no other check may send the same alert.
- lease = how long n8n waits before another run takes over a lead whose run stopped (45 seconds in the shipped flows). On screen: "setting: lease 45 s".
- take = one filming run of the video. recording = the finished video of one take. I write "this recording" when I mean the video being made now.
- screenshot = a still picture.
- flow set = one group of four n8n flows (form entry, e-mail-style entry, recovery, CRM + mail sub-workflow). real-v5 = the flow set in n8n-flows-real-v5 (real mail service and real CRM service), used for scenes 1 to 4. film-v5 = the flow set in n8n-flows-film-v5 (stand-in CRM, stage service and stand-in mail server), used for scenes 5 to 11. The closing card (scene 12) uses no flow.
- stage service = the small program that sorts each lead. recovery flow = the n8n flow that runs every 30 seconds, takes over stopped leads and sends alerts.
- two people called "owner": the studio owner (the person who decides and films) and the person who receives the alerts (the alert recipient; DESK_ALERT_TO in the real flows, a test address in film-v5). In text for viewers and readers I write "the person who receives the alerts". "Owner" alone is used only inside quoted current sentences.
- lead table columns (name on screen): lead key (lead_key), state (state), attempts (attempts), mail sent (mail_sent), alert sent (alert_sent), last change (updated_at). "Mail sent" means the mail step was started, not that the mail arrived. State 'review' = the e-mail address was invalid; it is only a word in the state column. It does not mean anyone has checked or approved the lead.

## How to read the tables
- "Paste this" holds ONE clean string in double quotes: the words themselves, with no label, no condition, no instruction, no placeholder and no alternative. If a cell reads NO PASTE, nothing is pasted; the note says why. If a cell reads DELETE, delete the current sentence. A row with two uses (voice and screen, or a default and a D1 variant) is split into rows with a letter (a, b), one string each.
- "Goes where": SCREEN = text that appears in the video. VOICE = spoken by the narrator. CARD = a line on the closing card. PAGE = a written statement for a reader of the demo page. LEAD = the replacement line for a working file (run sheet, plan, README); never said and never shown. For LEAD rows the string is the replacement line for that file.
- Section 1 and 2 mark each row by "Goes where". Sections 3 and 4 add a column "Type": VIEWER TEXT (heard or seen in the video), PAGE TEXT (read on the demo page by the public) or LEAD NOTE (never said, never shown). Section 3 holds PAGE TEXT and LEAD NOTE rows. Section 4 holds only LEAD NOTE rows: it has no viewer sentence.
- Everything for the lead (sources, conditions, which line of the run sheet it replaces, what to say instead if a rehearsal fails) is in the last column.
