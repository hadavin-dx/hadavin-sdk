**Limits of the role split (design review, three sentences).** Anyone who can run `docker exec` or holds the Docker socket is a Postgres superuser: the local socket is trusted, so the N-tests prove grants, not an access boundary. Any local process can reach loopback port 55433, so each role's password is the only gate there (true only if `pg-activity-4.txt` shows a client_addr that `pg-hba.txt` routes to scram-sha-256; if it matches a trust row, the roles are not password-gated on loopback). `smk_app` holds UPDATE on all of `mf_leads` and the flows use `executeQuery`, so whoever can edit workflows can reset a lead's state and cause reprocessing: the grants limit the damage to that table, they do not protect the state machine.
**Password authentication (what is actually shown).** A role is reported "authenticated by password" only when the Postgres log (1b.1 `log_connections=on`) holds `connection authenticated: identity="<role>" method=scram-sha-256` (or `md5`) for it. `docker exec ... psql` uses the trusted local socket: it proves privileges, never passwords. `smk_count` is expected to show NO such line (COULD-NOT-RESOLVE 6).
```python
import collections, re, sys

ours = {x.strip() for x in open(sys.argv[2]) if x.strip()}
ino = {}
out = collections.Counter()
dns = collections.Counter()
LOOP = re.compile(r"^(127\.|\[::1\]|\[::ffff:127\.)")
for line in open(sys.argv[1]):
    if line.startswith("fd "):
        f = line.split() + [""]
        ours.add(f[1])
        ino.update({i: f[1] for i in f[2].split(",") if i})
        continue
    f = line.split()
    if line.startswith("@") or len(f) < 6:
        continue
    peer = f[5]
    if peer.endswith(":*"):
        continue  # an unconnected UDP socket has no peer
    pids = set(re.findall(r"pid=(\d+)", line))
    i = re.findall(r"ino:(\d+)", line)
    if i and i[0] in ino:
        pids.add(ino[i[0]])
    who = "ours" if pids & ours else ("other" if pids else "no-process")
    k = (who, f[0], f[1], peer, ",".join(sorted(pids)))
    if peer.rsplit(":", 1)[-1] == "53":
        dns[k] += 1
    elif not LOOP.match(peer):
        out[k] += 1
for name, cnt in (("NONLOOP", out), ("DNS", dns)):
    for k, n in sorted(cnt.items()):
        print(name, n, *k)
```
