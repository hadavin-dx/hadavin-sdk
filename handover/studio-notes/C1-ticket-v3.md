## 0. Decisions that v2 left open (each reviewer finding answered)
| # | Decision |
|---|---|
| D1 | **One masker per run, owned by Runtime.** A mutable `MaskSession` (in `guard/redactor.py`) holds `mapping` (placeholder->original, private, `repr=False`, `__reduce__` raises) and `counts`. It only appends: the same value always gets the same mark, a new value gets the next number, nothing is renumbered. Tool results add new values to the same session. |
| D2 | **`MaskedLLM` (file `llm/masked.py`) is created per run by `Runtime`** as `MaskedLLM(inner, redactor, session)`. It accepts raw `str`/`bytes` and masks with the shared session; text that already contains marks ISSUED by that session passes through unchanged (so `_screen` text and the judge's input never double-mask); mark-shaped text NOT issued by that session is forged -> `RedactionError("forged_mark")`. `Runtime` never masks a second time itself: it calls `session`/`redactor` for tool results (`mask_text`) and put-back only. |
| D3 | **Choke point is structural, not a flag.** `Runtime.__init__`, `evals.gate`, `extract.*`, `guard/judge.py` and `k1b` require `isinstance(llm, MaskedLLM)`; the constructor needs a module-private token, tests use the public helper `MaskedLLM.of(inner, redactor)`. A raw LLM is only ever built via `app.build_llm(...)` which wraps it. Named raw-LLM sites to change: `cli.py:145` (gate), `cli.py:216` (k1b), `app.py:72-75` (wrap BEFORE the detector is built so the judge gets the wrapper), `app.py:118`. An import-graph/AST test fails if any module outside `llm/` and `app.py` imports a raw LLM kind or calls `.chat(` (AST, not text grep; covers `getattr`, `partial`, `*args` forwarding as call sites on the allow-list `llm/*.py`, `llm/masked.py`). |
| D4 | **k1b keeps its own pre-masked bundle path** through an explicit, greppable `MaskedLLM.premasked(inner)` used only by `k1b/loop.py` (bundles are masked by `k1b/redaction.py`); it records `premasked=True` in the outbound audit record and has a test. No double masking, no silent exception. |
| D5 | **Redactor interface (exact):** `class Redactor(Protocol): name: str; version: str; def mask(self, text: str, session: MaskSession) -> str; def check(self, masked: str, session: MaskSession) -> None; def put_back(self, value: Any, session: MaskSession, restorable: Mapping[str, Sequence[str]]) -> Any`. `bytes` are decoded UTF-8 strict in `MaskedLLM` (a BOM is stripped; invalid UTF-8, PDF/image signatures, NUL bytes -> `RedactionError("unsupported_input")`). Document + messages of one call are masked as ONE text (so a value found in one is masked in all). `RedactionError(RuntimeError)`: `.code` only, `__str__` returns the code, raised `from None`. Codes: `unsupported_input`, `too_large`, `forged_mark`, `self_check_failed`, `internal`. `check` is whole-token, case-sensitive, applied to originals of 4+ chars that `redact._sweep` itself would mask (same exemptions: short numbers and common words are not required to be absent). |
| D6 | **Kind wiring:** new capability `redactor` in `Backends`, `TABLE` (neutral=True for `regex`), `ALLOWED`, `DEFAULTS` (`regex`), build order after `llm` and before `detector`, factory `regex_redactor` in `backends/builtin.py`, settings `RegexRedactorSettings(kind="regex", max_doc_chars=200_000)` (applies to document + each tool result; over -> `too_large`). Config hash: add the redactor kind to `registry.config_hash` under `exclude_defaults=True`, so the default kind does NOT change existing hashes and existing `qualified.jsonl` lines stay valid; a non-default redactor changes the hash (intended; CHANGELOG upgrade note). `Runtime(redactor=...)` is a REQUIRED argument; pilot/prod config must name the redactor kind explicitly (the default `regex` is accepted for dev/test only; `load` refuses a missing explicit kind when `env` is pilot or prod). |
| D7 | **Put-back is built and tested but OFF by default.** Contract field `restorable: {dotted.path: [kinds]}` default `{}`; allowed kinds only EMAIL, PHONE, NAME, ADDRESS; never IBAN/CREDITCARD/SECRET_KINDS/BANKACCT/BANKCODE/SSN/AADHAAR/PAN. No shipped contract sets it. **A contract with a non-empty `restorable` is refused at load until ticket C1f (approval card design: per restored field shows kind + last 4 + source line; approval summary and `bedrock_guardrail` screen the MASKED plan) exists.** So in C1 the plan carries placeholders to the gate and card, `reply.text`/cards/shadow/abstain stay masked, no PII enters the plan table, and approval summary never sends restored values anywhere. Read tools get masked input with no restore (lookup by PII unsupported until C1f; README says so). |
| D8 | **Audit, no schema change:** `AuditEvent` has no free-form field; do not add one. One event per `chat` call (judge calls included): `domain="llm"`, `operation="outbound"`, `inputs_hash=sha256_hex(masked body sent)` (plain hash; README states the brute-force limit for short low-entropy bodies), `rule_id=f"{redactor.name}@{redactor.version}"` (+ `;premasked` for k1b), `result=f"chars={in}/{out};" + ",".join(sorted(f"{k}:{n}"))` with a fixed kind vocabulary (the `redact.py` kind names), `write_intent` BEFORE the call, `AuditUnavailable` -> `NEEDS_PERSON "audit_unavailable"` as the other handlers do. The `received` event now hashes the MASKED first body (`inputs_hash`); no raw-document hash is written anywhere. Error event: `error_code="redaction_error"`, `rule_id=f"redaction.{code}"`, no message; log line `type(exc).__name__` only. |
| D9 | **Error handling at EVERY site:** one helper catches `Exception` around mask and maps to `RedactionError("internal")` unless it is already a `RedactionError`; `Runtime.handle`, `_screen`, tool-result masking, `_submit` and the judge path catch `RedactionError` and go `NEEDS_PERSON` with the existing reason string `redaction_error` (no new constant, no chat, no judge call). `injection_check` re-raises `RedactionError` (it must not become `guard_unavailable`). `_CAUGHT_BY_ABSTAIN_REASON["redaction_error"]` changes from `"guard"` to `"abstain"` and the K6 test is updated. |
| D10 | **evals / gate:** golden docs go through the same `MaskedLLM`; comparison with `expected` happens AFTER `put_back_all` in a test-mode call (`evals` only), so the gate qualifies the masking path without weakening golden files. No `qualified.jsonl` migration is needed because of D6. Document in CHANGELOG. |
| D11 | **FakeLLM:** `src/.../llm/fake.py` logic and fields are NOT changed. Recordings are keyed by the hash of the MASKED first document; fixtures whose text the regex masks are renamed with a throwaway script (outside the repo) that masks each `tests/fixtures/inputs/*.txt`, hashes it and `git mv`s `recorded/<old>-<n>.json`; fixtures with no PII keep their names. A `RecordingLLM` test double in `tests/` records COPIES of `messages`, `documents`, `system`, `tools` of every call. Shared `masked_llm` fixture in `tests/conftest.py`. |
| D12 | **Honesty about strength:** the regex default misses names in free prose, obfuscated IBANs (zero-width, full-width, entities), spaced IBANs, images/PDFs. README lists (a) supported input types and (b) NOT masked, and a test asserts the README names those items. The spaced-IBAN test is written `xfail(strict=True)` with a reason on the default kind. "No client use of core" lifts only after a separate reviewed ticket **KERNEL-1** (generic kernel with its own interface: locator, spans, spellings, forged/collision checks, body check, injected `allowed(kind,path)`; invoice finder/money/supplier/schema stay in Intake; the re-mask check that needs the raw document is redesigned) or the owner's written acceptance of regex-only with the README list. Core is not used by any client today (no pilot depends on it); say that in the PR. |
