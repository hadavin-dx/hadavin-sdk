## 1. Principle (unchanged)
Foreign free text never reaches logs, dead letters, stored error fields or stderr of the unattended tick. Operators get a Diagnostic made only of allowlisted parts. Regex cleaning is NOT the primary control; a minimal `safe_str` backstop stays for the few operator-visible strings that remain.
Trust zones, used everywhere below: T0 literal constants in our source; T1 operator configuration values (secret names, paths, bucket names, config keys) - allowed in our own messages by policy because they are not document content; T2 everything else (documents, model output, third-party exception text, headers, response bodies) - NEVER printed.

## 2. Record and the two output grammars (answers impl B1/B2, critic M8)
Module `src/hadavin_sdk/guard/diagnostic.py` (new).
```
class Where(str, Enum): extract, model_call, queue, scan, approval, audit, config_load, registry_load, cli, other   # closed
Step = Where | TickStep('tick:' + token)   # token = [a-z_]{1,30}, validated; 'none' replaces '-'
class Code(str, Enum): config_invalid, store_unavailable, store_conflict, provider_http, provider_timeout, provider_rate_limit, provider_invalid_request, provider_auth, provider_exhausted, audit_unavailable, egress_refused, unqualified, validation_failed, scan_failed, timeout, os_error, db_error, internal_bug, foreign_exception, session_closed
class FactKey(str, Enum): http_status, retry_count, attempt, errno, winerror, gai, sqlstate, phase, cause_kind, count, position, line, column, field, key, provider_error_type, request_id, duration_ms, type, retryable
Fact = int | bool | SafeEnumValue | SafeToken     # SafeEnumValue: a member of an Enum declared in diagnostic.py only; SafeToken: see below
@dataclass(frozen=True) Diagnostic(kind, code, step, locator, lib_frame, facts, chain, fp, dropped_facts:int)
def diagnose(exc, *, step, facts=None) -> Diagnostic    # NEVER raises: outer catch BaseException -> fixed fallback Diagnostic(kind='unknown', code=foreign_exception, step=step, locator='-', ...)
def render(d) -> str
```
`SafeToken`: a final class (not a str subclass); constructors `SafeToken.of(value, allowed=frozenset)` (membership) and `SafeToken.shape(value, name)` where name is one of exactly: `sqlstate` (`^[0-9A-Z]{5}$`), `request_id` (`^[A-Za-z0-9_-]{8,40}$`, longer values dropped), `token40` (`^[A-Za-z0-9_.:-]{1,40}$`, used only for declared names). Mismatch -> the fact is DROPPED and `dropped_facts` increments (never raises). A `str` passed as a Fact is refused (TypeError in the constructor of `diagnose`; tested). Fact value bounds per key (enforced): http_status 100-599, retry_count/attempt 0-1000, errno 0-200 (names only via errno.errorcode), winerror 0-20000, gai -20000..20000, count 0-10^6, position/line/column 0-10^9, duration_ms 0-10^9; `phase` in {connect, auth, ssl, query, unknown}; `provider_error_type` in the closed map of section 5; `type` in the closed pydantic/json type list of section 3; `retryable` bool. At most 12 facts; if more, keep the first 12 by FactKey order and count the rest in dropped_facts (rendered as `dropped=N`).
`locator` = innermost frame whose file is in OUR package: `basename.py:line` (`^[A-Za-z0-9_]{1,40}\.py:[0-9]{1,6}$`); `lib_frame` = innermost frame overall: basename with the same regex, else `-`.
`fp` = first 8 hex of sha256(`kind|code|function|file`) where function is the innermost OUR-frame `co_name` (`^[A-Za-z0-9_]{1,40}$`): stable across line shifts, contains no document content, needs no key. (Round-2 critic: line-based fp breaks across releases.)

Grammar A, stored `TickState.last_error` / non-validation `DeadLetter.errors` (TEXT / list[str]; NO migration): `ClassName: diag_v=1 code=<code> step=<step> at=<file:line> fp=<8hex> [k=v ...]` where `ClassName` is `kind` (section 4) and the line is capped at 400 chars by dropping trailing facts first (diag_v, code, step, at, fp are never dropped). The `ClassName: ` prefix keeps `startswith("ConfigError: ")` tests valid.
Grammar B, the tick log line: unchanged keys `step=%s error_kind=%s at=%s message=%r`, where `message` = the Grammar A text WITHOUT the class prefix. Tests asserting `step=first error_kind=ConfigError at=test_p7_tick.py:` stay valid; the `message=` part changes. `at=` appears in both (accepted; stability over elegance).
Old rows are read as opaque strings; old programs reading new strings is harmless.

## 3. Facts from pydantic and json (answers critic blocker/M5, impl M4/M5)
Declared-set algorithm (module `diagnostic_schema.py`): given a root model class, walk `model_fields` recursively through Annotated/Optional/Union/list/tuple/dict/RootModel, collect for each model class its own field names AND aliases; cycle guard by class identity; cache per root class. A pydantic `loc` is rendered segment by segment with the model class tracked while walking: a segment is shown only if it is a declared name of the CURRENT model; ints become `[n]` (list index, no value); a dict key position becomes `*`; union/discriminator tags and `function-*`/`tagged-union` segments become `*`. For `extra_forbidden` (unknown key typed by the document or by an operator typo): the unknown name is NEVER shown (T2); instead facts `type=extra_forbidden` and `count=N`, plus, for CONFIG models only (T1 operator input), `key=<declared parent path>` so the operator sees WHERE the stray key is. (Config typos therefore show the parent path and "extra_forbidden"; the operator opens the file at that path. Honest limit.)
Closed `type` list = pydantic v2 error types that carry no input in their fixed message (missing, extra_forbidden, literal_error, int_parsing, float_parsing, bool_parsing, string_type, int_type, dict_type, list_type, too_short, too_long, greater_than, less_than, string_too_short, string_too_long, decimal_parsing, date_parsing, datetime_parsing, enum, url_parsing, json_invalid, model_type, union_tag_invalid(tag dropped), value_error(message dropped), assertion_error(message dropped), other). Fixed library text for retry prompts comes from the existing `_FIXED_TEXT` map plus a closed map of CPython json.decoder messages (Expecting value, Expecting property name enclosed in double quotes, Expecting ':' delimiter, Expecting ',' delimiter, Unterminated string starting at, Invalid control character at, Invalid \escape, Extra data, Invalid \uXXXX escape, Unterminated array/object): so the retry prompt keeps the reason without free text.

## 4. Codes, classes, identity (answers impl B2, critic M1/M6)
Own classes (17, verified): class attribute `code` (inherited by subclasses; the base-class `code` wins over any builtin ancestry such as OSError/KeyError): ConfigError config_invalid (StoreUnavailable overrides store_unavailable, BundleError config_invalid), StaleState/DuplicateEvent/AnchorConflict/IllegalTransition store_conflict, NotFound store_conflict (KeyError ancestry ignored), UnknownRecording config_invalid, ProviderError provider_http (ProviderExhausted provider_exhausted), AuditUnavailable audit_unavailable, EgressRefused egress_refused (PermissionError ancestry ignored), Unqualified unqualified, CallTimeout timeout, VaultError config_invalid, SlackError provider_http. A discovery test walks every module of `hadavin_sdk` for BaseException subclasses and fails on a class without `code` (own = defined in our package).
Provider/DB codes by facts: ProviderError with status 429 -> provider_rate_limit, 401/403 -> provider_auth, 400/404/422 -> provider_invalid_request, timeouts -> provider_timeout (set by R1P, section 5).
Foreign exceptions: code by `isinstance` families (OSError -> os_error with errno/winerror/gai facts; psycopg errors -> db_error with sqlstate and phase; ValidationError/JSONDecodeError -> validation_failed; TimeoutError -> timeout; others raised from a frame in OUR package -> internal_bug; else foreign_exception). The family test is by class identity against imported classes (psycopg.Error etc. when importable), never by module-name string alone.
`kind` identity rule: print `module.qualname` only if `getattr(sys.modules.get(cls.__module__), cls.__qualname__, None) is cls` (importable by path: static code, not data-built) and the string matches `^[A-Za-z0-9_.]{1,80}$`; otherwise `dynamic_class`. No allowlist of module roots, no hash.
Facts collection: merged along the `__cause__`/`__context__` chain (depth 4, cycle guard by id, first value wins per FactKey), so a psycopg OperationalError wrapping an OSError yields `phase=connect cause_kind=ConnectionRefusedError`. `chain` lists cause kinds by the same identity rule; ExceptionGroup members as `kind*count` (max 4 distinct, depth 2); `BaseExceptionGroup.message`, `SystemExit.code`, `KeyboardInterrupt` text and all `.args` are NEVER read. `winerror` and `gai` are read as ints from the exception attributes.

## 5. R1P provider plumbing (answers critic BLOCKER 1)
`llm/protocol.py`: ProviderError gets keyword-only attributes `status: int|None`, `error_type: ProviderErrorType|None`, `request_id: str|None`, `retryable: bool|None` (default None; existing `ProviderError("...")` constructions stay valid). `llm/retry.py` `with_retry` fills them from the CAUSE via one adapter per provider kind in `llm/common.py` (functions `provider_facts(exc)`): urllib/HTTPError (`.code`, headers `request-id`/`x-request-id` value checked against the request_id shape; body NOT parsed), Anthropic SDK (`.status_code`, `.request_id`, `.body` read only as a dict and only `body["error"]["type"]` mapped through the closed map), botocore (`response["Error"]["Code"]` and `response["ResponseMetadata"]["RequestId"]`), openai_compat/gemini via HTTPError code and, if JSON-decoded dict, `error.type`/`error.status` mapped through the closed map. Closed map ProviderErrorType: rate_limit, overloaded, invalid_request, authentication, permission, not_found, server_error, timeout, connection, throttled, quota, other. The f-string message stays only as an internal `.args` text that is never printed. Tests use real SDK error objects (constructed from httpx.Response/botocore ClientError/urllib HTTPError fixtures).

## 7. Logging layer, hooks, stderr (answers impl M2, critic BLOCKER 3, M4)
Installed by `bootstrap_logging()` called as the FIRST statement of `main()` (before lazy imports of hadavin_sdk.app) for every CLI command. Components:
a. ONE handler on the ROOT logger (replaces `_Stderr`, `_NoTraceback`, `_TICK_LOGGING_READY`, NullHandler, lastResort swap); the handler resolves `sys.stderr` at emit time (keeps the test-compat behaviour); `hadavin_sdk` logger propagate stays True (records reach root; pytest `caplog` keeps working; the 30 hardening tests are re-pointed in R2).
b. Formatter: records from loggers whose NAME starts with `hadavin_sdk` print `logger=<name> level=<l> msg=<getMessage()>` ONLY if the call site passed no exception-derived argument (guaranteed by the AST guard of section 8, backed by a runtime check that `record.args` contains no BaseException and no str(exc)); other logger names map to a closed root list (urllib3, httpx, anthropic, botocore, psycopg, asyncio, py.warnings, sqlalchemy, uvicorn) else `other`; their records print as `logger=<root> level=<l> msg_len=<n>`. `exc_info`, `exc_text`, `stack_info` dropped. Third-party text is not shown; accepted loss, stated to the owner.
c. `handleError` prints one fixed line naming the handler class; `logging.raiseExceptions=False` set in `bootstrap_logging`; `logging.captureWarnings(True)`; hooks: `sys.excepthook`, `threading.excepthook`, `sys.unraisablehook`, the asyncio loop exception handler (set when a loop is created by our code), and `main()` wraps the command in `except BaseException` that prints `render(diagnose(...))` and returns exit code 1 (so `SystemExit("text")` from a library never reaches the interpreter's own printing; our own `SystemExit(int)` is preserved). argparse: custom `ArgumentParser.error` prints usage and the option NAME only.
d. UNATTENDED TICK ONLY: `sys.stderr` and `sys.stdout` are replaced by `_GuardedStream`: lines written by our handler/hook carry a private per-process marker byte and pass; any other line (print() from a dependency, C-level writes that go through Python, argparse leftovers) is rewritten to `stderr_line len=<n>` (text dropped). C extensions writing to file descriptor 2 directly are NOT intercepted: stated as an out-of-scope limit to the owner; mitigation: the tick service unit should redirect fd 2 to a file with the same access as the logs.
e. Startup audit runs at bootstrap AND again after lazy imports (`audit_handlers()`): any handler on any logger that is not ours is logged as `foreign_handler logger=<root> class=<cls>` and, for the unattended tick, REMOVED (the owner's requirement is that free text must not reach logs; embedders that call run_tick as a library are documented as responsible for their own handlers).
f. No subprocess in src (verified); a test fails if one appears without review.

## 8. AST guard for our own code (answers critic Minor 3, impl M9)
Rule: inside any function, a value is TAINTED if it is (i) an exception variable bound by `except ... as e` or a parameter named e/exc/err/error/ex or annotated with an exception type, (ii) any attribute/call/subscript/f-string/format/%/+/join/tuple/list/dict built from a tainted value (propagated to a fixed point within the function, through simple assignments, walrus, tuple unpacking, for-targets), (iii) the result of `str()/repr()/format()/getattr/traceback.*` on a tainted value. Sinks: any logging call (`log.*`, `_LOG.*`, `logging.*`), `print`, `write`, `warnings.warn`, a `raise X(...)` of ANY class, keyword `extra=`, store calls (`last_error=`, `errors=`), and any callee not on the SAFE list {diagnose, render, class_name_of (identity rule), isinstance, type, len, id}. A tainted value reaching a sink fails. `raise X from e` is allowed (the cause stays as an object). Known limit (stated): cross-function flow (helper returns str(e)) is caught only when the helper has an exception-typed parameter (checked as above) or the returned value is assigned from a tainted expression in the caller. Waivers are keyed (file, function, statement hash) with a mandatory reason and an expiry date.
