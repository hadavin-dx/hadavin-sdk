Author: the P1d drafting agent (lead order 146 item 2(a)). Studio note: codes allowed. Companion of `handover/tickets/P1d.md`.
**Method.** `grep -rn` over `/home/user/build/CILINT/src/hadavin_sdk` (branch `core/ci-lint-set`, read only, head `eeaa502` then `da40870`) for `redact`, `safe_head`, `scrub`, `mask`, `clean(`, `sanitise`, `_secret`, `sensitive`, log calls, and over `demos/`; the main-line P1 pieces read on `origin/core/P1b-fixwip` (`0d843b4`): `guard/textnorm.py` (public names, `scan_views`, `scan_holds`, `register_value`), the P1b diff of `runmap.py` and `injection.py`. **Run:** probes 1-7 (scripts and raw output in `handover/evidence/P1d/`), against `0dabf1f` (main), `0d843b4` (P1b) and CILINT, in a scratch virtual environment (Python 3.12.13). "M" = measured by a probe; "R" = read only; "UNVERIFIED" = neither. Placeholders: `<KEY>` = the AWS documentation key built from parts, `<K4>` its first 4 characters, `<K16>` the rest; `<HANDED>` = a made-up handed-out secret from parts; `<V>` = any secret value. "Shared views" = does the site read the text through `textnorm` (P1b) or another shared check beyond `runmap.redact_text`'s own views? On main and CILINT textnorm does not exist, so the answer is "no" everywhere except where noted.
**The common root.** Most sites below route through `runmap.redact_text` (`runmap.py:464`), whose views are `canonical`, the JSON-unescaped text and `undo` (P1b adds `composed`). None of them deletes markdown markers, escape sequences or control characters, none folds case or look-alike letters for PATTERN matching, and the known-value sweep is literal and case-sensitive (`redact.py:1204` `_sweep`). So the hole of P1d is a property of the choke point itself; the clean function only shows it to a person, the other sites show it to a model, a log or the audit record.
