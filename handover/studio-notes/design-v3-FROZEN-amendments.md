## D1 Exit codes and main() (impl A1, critic B7)
Keep today's table: ConfigError 2; other Exception 3; StoreUnavailable in tick 4; run_tick uses 1 for "a step failed". New wrapper in main(): KeyboardInterrupt 130; SystemExit(int) preserved; SystemExit(None) 0; any other SystemExit payload -> 1 and the payload text is NOT printed; any other BaseException -> 1. `_tick()` runs `run_tick(app)` INSIDE the covered try. The `HADAVIN_DEBUG=1` tty branch (cli.py:87-88) is reworked to print `render(diagnose(exc))` only (no message text). diagnose() catches Exception, RecursionError, MemoryError ONLY (KeyboardInterrupt/SystemExit propagate); its fallback render cannot raise.
Subprocess tests assert each exit code.

## D2 Kept operator text (impl A2, critic A1, B6)
`Diagnostic.detail: str|None`. detail is set only when (a) the exception class is defined in our package (own-class test via `__dict__` of MRO classes whose module starts with `hadavin_sdk`) AND (b) it is a ConfigError subclass or has `code in {config_invalid, store_unavailable}` AND (c) `args[0]` passes `safe_detail()`: printable ASCII only, length <= 200, no control characters, no URL userinfo (`://x:y@`), no secret-shaped token (sk-, AKIA, AIza, ghp_, xox, a base64/hex run of 24+), else detail becomes `<detail len=N>`. Rendered in Grammar A as ` detail="..."` (quotes/backslash escaped), last; dropped first when the 400-char cap bites. FOREIGN-origin ConfigError sites never put foreign text in args[0] (from_cause).
`t1(value)` helper (new, in codes-adjacent module `guard/t1.py`): every non-literal f-string part inside a ConfigError message or a log call must be wrapped; prints the value only if it fully matches `[A-Za-z0-9_.:/@-]{1,80}` (re.fullmatch), has no `://user:pass@` form and no secret-shaped token; otherwise `<value len=N>`. The AST test requires `t1()` around any non-literal interpolation in ConfigError(...) and log calls. This REPLACES "T1 unchanged".

## D3 Step names and grammars (impl A3, critic A4)
Type renamed `StepToken` (NOT TickStep). Grammar B (tick log line) keeps `step=%s error_kind=%s at=%s message=%r` with step = bare tick token (`first`, `sweep`) or `-` for none. Grammar A prints the same bare token (`step=first`), no `tick:` prefix. Valid token `[a-z0-9_-]{1,30}`; invalid -> `other`. `Where` members (closed, only members used by a real call site): extract, model_call, scan, audit, config_load, registry_load, cli, other. The fixed T0 messages in tick.py 250-272 ("store unreachable", "store answers but is not ready: run hadavin-sdk migrate ...") survive as `detail` (own-class path) or fixed literals. Own classes print the BARE qualname (`ConfigError`); foreign importable classes print `module.qualname`; non-importable `dynamic_class`; builtins print bare (`KeyError`).

## D4 Code precedence (impl A5)
The class `code` always wins; HTTP status and error type go into facts. provider_rate_limit / provider_auth / provider_invalid_request / provider_timeout are used only for a plain `ProviderError` (code derived from status facts set by R1P); ProviderExhausted stays provider_exhausted with facts http_status=429. ## D12 Logging layer (impl A4, critic A2, B8, B10)
No marker byte. Our emitters write to the ORIGINAL stream objects captured before the swap; `sys.stderr`/`sys.stdout` are replaced (unattended tick only) by `_GuardedStream` which rewrites every line written through it to `stderr_line len=N`. `_GuardedStream`: line-buffered across partial writes and threads, flushed at exit, ASCII with `backslashreplace`, provides `encoding`, `errors`, `isatty` (False), `reconfigure` (no-op), `fileno` raising `io.UnsupportedOperation`, `flush`, `write`, `writelines`. Test: a line containing any forged marker is rewritten. File descriptor 2 for the unattended tick: `os.dup2` to a protected file `<tick run dir>/tick-fd2.log` (restrictive permissions via ACL where supported; size cap 1 MiB, 3 rotations; never printed or shipped; may be disabled by config `logging.capture_fd2: false`); this closes the C-level-write gap, and the file is documented as a place that can hold raw text.
bootstrap_logging is IDEMPOTENT and returns a handle; `main()` calls it and `uninstall()`s in `finally` (restores sys.excepthook, threading.excepthook, sys.unraisablehook, root handlers, raiseExceptions, captureWarnings, sys.stderr/stdout). Foreign-handler REMOVAL happens only at the real process entry (`_cli_entry` for the console script and `python -m hadavin_sdk`), never when main() is called as a library or by tests; tests use `library_mode=True`. audit_handlers() runs at bootstrap, after lazy imports, and at each tick step boundary; operators may allow handler classes via config `logging.allowed_handler_classes` (documented consequence: removal also drops operator log shipping unless allowed). The ~36 hardening tests that test `_Stderr`, `_NoTraceback`, `_TICK_LOGGING_READY` are REWRITTEN in R2 (listed in the test migration table). R2 includes a subprocess canary test that must also run on Windows (CI or documented manual evidence).
