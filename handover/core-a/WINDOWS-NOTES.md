# Windows notes for the evidence run (core-a)

Written by reading only: the reviews, the code and the tests. NOTHING in this file was run on Windows. Every row is a
reason to expect a difference, not an observation. "Expected on Linux" is what the code and the tests say should
happen (the Linux runs of this project passed, but these exact commands were not all run; treat an unexpected Linux
result as a defect of this note, not of the code). Candidate fixes are one line each and are not proposals to change
code during the campaign. S = src/hadavin_sdk.

Reviews that spoke of Windows: E-result-review-2 (C2-2, G4 note), E-result-review-3 (D3-1, C3-7), code-D-design-review-1
(N16: exit code 137). The n8n review and D-code-result-review-1 (the file does not exist) have no Windows finding.
Everything else below is "found by this inventory".

Setup for all commands: repo root, the project's venv active, `cmd` or PowerShell. `PG` stands for
`set HADAVIN_TEST_PG_DSN=postgresql://USER:PASS@127.0.0.1:5432/DB` (use 127.0.0.1, see W07) and
`set HADAVIN_REQUIRE_PG=1` so a missing database is a failure, not a skip (tests/triggers/conftest.py).
