## 1. How to use this report

Within one file the rows are sorted from the bottom of the file to the top, so applying them in order never shifts the line number of a row still to come. 'on the default of L-X' = apply it if the studio lead answers L-X with the default or writes 'apply all defaults' (section 3, table 3c); do not apply it if the studio lead answers differently.
