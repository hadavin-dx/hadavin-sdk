# R460 static audit: approval-text command filter (G4) in src/hadavin_sdk/approvals/gate.py (condensed copy of the auditor's inline report, 2026-11-16)
Read only, nothing run; every "passes" is hand-traced through the regexes, so treat as "likely, confirm by running" (an evidence runner should feed the strings to withhold_commands and channel.clean). Not read: runmap.py, redact.py, gate.py lines 229-340 (G3 helpers), actions/*, deferred.py, runtime/agent_loop.py, cards.py, models.py, most tests. Read: tests/test_g4_parity.py and the pending patch (not executed).
Framing: G4 is a DISPLAY filter (replaces a command in model-written text with a withheld marker before a person reads it); it does not decide whether a tool call runs. The stated contract (channel.py:20-21, gate.py:375) is "no command a person could paste, any platform, fail closed". That holds only for programs on a fixed list (_NAMES); everything else is fail-open.
## Blockers
- B1 "fail closed / any platform" is false for programs not on the list: dd, mkfs, chmod -R, kill, shutdown, service stop, eksctl delete, cdk destroy, dropdb, crontab -r, apt, pip, sed -i, rsync --delete, ssh host 'rm', curl -X DELETE, plain rm without flags; file redirections (>, >>, tee) are not matched. No test; the existing prose pin `rm the file` means a naive fix breaks a test. Fix: deny by command shape, or correct the wording to "a closed list of CLIs".
- B2 line-continuation and punctuation-first-token bypass: `kubectl \` + newline + `delete ns prod` (same for aws, docker, terraform, cmd `^`, PowerShell backtick, `kubectl > /dev/null delete ...`) is treated as prose (_story line 614 returns True when the first token is punctuation). Wrapped commands are what models emit. Cheapest high-value fix: join continuations before matching.
## Major
- M1 quoted-in-prose exemption forgeable (`Please run the 'terraform destroy' now`); a test pins `a 'kubectl rollout restart' replaced the pods`.
- M2 bare SQL matched upper case only (drop table, delete from, update ... set, truncate, insert into, grant all in lower case pass); tests pin `drop table pressure` and `we should delete from the queue only after a fix`, so the fix needs a statement-shape check.
- M3 SQL shape gaps even in upper case: UPDATE with alias/ONLY/quoted name, INSERT IGNORE/REPLACE/COPY/LOAD DATA, CREATE with modifiers or other kinds, DROP of unlisted kinds, ALTER ... MODIFY/CHANGE, privilege changes (ALTER USER/ROLE, GRANT/REVOKE without ON), comment-as-space (DROP/**/TABLE), state changers (nextval, setval, pg_reload_conf, VACUUM, CALL, EXEC, DO).
- M4 PowerShell coverage is a closed module list: Remove-SQSQueue, -SNSTopic, -DDBTable, -ECRRepository, -KMSKey, -ADUser, -Mailbox, -VM ... pass; aliases (ri, del, rd, kill) and cmd `rd /s /q`; `Invoke-Expression (Invoke-WebRequest u)` passes (needs a literal pipe). Remove-EC2Instance IS covered (test_g4_parity.py:46,159-161).
- M5 unknown subcommand of a known CLI is treated as prose: git update-ref -d, git config --global core.hooksPath, docker config rm, docker trust revoke, systemctl rescue/emergency/kexec, kubectl plugins. Invert: prose only when the next word is plain English and the CLI is in _ENGLISH.
- M6 a read verb decides the whole command: `git reflog expire/delete`, `git diff --output=/etc/cron.d/x`, `git -c core.fsmonitor=... status`; `terraform plan -out=` (nit).
- M7 name matching is lower-case ASCII with a fixed suffix list: `KUBECTL.EXE`, `AWS ec2 ...`, `kubectl.ps1` (empty token list, prose), `kubectl-1.28`, `tf destroy`, `$K delete`, quoted/obfuscated names, `rm${IFS}-rf`.
- M8 rm shape narrow: `rm -v -rf /x`, `rm -i -r`, `rm --no-preserve-root -rf /`, `find / -delete`, `shred`, `unlink`, `truncate -s0`.
- M9 download-and-run: `| python3/perl/node`, `source <(curl x)`, `eval "$(curl x)"`, `curl -o x u && sh x`, base64 -d | sh, python -c shutil.rmtree.
- M10 capital-first positional argument read as prose: `mysql Shop -e "delete from x"`, `psql Prod -c "drop table x"`, `ansible Prod -m command -a reboot`.
- M11 English-word CLIs mid-sentence pass: `Run: git checkout main`, `Then git clean`, `Run: psql prod < dump.sql` (write verbs list lacks checkout, clean, commit, merge, rebase, pull ...).
