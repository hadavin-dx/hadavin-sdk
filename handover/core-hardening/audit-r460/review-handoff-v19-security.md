# Hand-off v19 security review, round 6 (egm-design, condensed copy), 2026-11-16T18:31:07Z
Static read only; nothing run; every bypass is hand-traced and needs a mutant on a real server. Verdict: 1 blocker, 4 majors, 6 minors. v18 top-level bypasses (bare SELECT, SET "role", DROP, CREATE VIEW, quoted-case aliasing) look closed.
## Failures first
- B1 A definer written with the SQL-standard RETURN <expr> body is never scanned (secdef_guard_v19.py 381-409; body filter at 392): no string or dollar token, so _atomic_problems, _body_problems_v19 and _call_problems never run. RETURN query_to_xml(p_agent, true, false, '') in spend_reserve passes every rule. No mutant covers a RETURN-form body. Fix: any definer with no scannable body, or a head not BEGIN ATOMIC or exactly one string/dollar body, is a problem; scan the RETURN expression.
- M1 _call_problems line 244 skips any word after %I. followed by (, hiding a hostile call in an EXECUTE string (EXECUTE format('SELECT %I.evil_fn($1)', TG_TABLE_SCHEMA)). Refuse %I.name( unless right after INTO.
- M2 S3/S4 let a file DROP or neuter audit triggers (spend_log_decrease, kill_switch_log_*, spend_keep_keys, append-only guards); control K7 marks DROP TRIGGER IF EXISTS as clean; CREATE OR REPLACE TRIGGER ... WHEN (false) passes. Pin triggers per file (name, table, timing, WHEN fingerprint).
- M3 atomic-body relation pin misses MERGE INTO, USING (MERGE and DELETE ... USING) and TABLE x; USING pg_authid not flagged.
- M4 A listed definer is not tied to its return type or body; add a head/body fingerprint.
- m1 expressions in ALTER TABLE CHECK/DEFAULT, CREATE INDEX, CREATE TABLE DEFAULT, trigger WHEN are shape-checked only. m2 SET-after-UPDATE exemption positional. m3 tokenizer vs Postgres non-ASCII (NBSP, astral). m4 agent-id rule: btrim strips spaces only, [[:cntrl:]] locale-dependent, IS NFC NORMALIZED raises on non-UTF8. m5 decrease log noise: every ordinary settle with actual < worst writes a row in both tables, unbounded, undermines the signal. m6 cutover: existing rows open_usd = 0 so a reservation open at cutover cannot settle; day-row-without-month-row settle commits unless store rolls back; NOT VALID checks block settling old bad rows; SET LOCAL timeouts are no-ops outside a transaction.
