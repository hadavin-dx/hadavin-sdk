## Blocker
1 A reservation is released after a possibly billed attempt (4.1 table, 4.2 gate): gate runs per attempt inside _retry (retry.py:92-107); attempt 1 times out/5xx after generation started, attempt 2 refused by gate (window_ended) or 400/401/403/404/422 -> table says release, though attempt 1 may be billed (exception 2c). One reservation covers one worst case, but each attempt can be billed; bound says N calls in flight, not N attempts. Fix: track whether any attempt left the process; release only if none; else keep; reserve per attempt or state bound max_attempts x reserve. Test: attempt 1 transient, attempt 2 ProviderRefused/window_ended -> keep.
## Major
2 Gate only checks some scope exists (4.2): raw NetworkLLM inside a caller's scope passes without reservation. Fix: one-shot reservation token in the ContextVar, consumed per attempt; negative test.
3 finish_spend and add_cost are two writes (4.1 end): crash between leaves run cost row low, weakening the per-run cap (D14). Fix: same transaction, or record the increment on the final op row and reconcile.
4 Run cap ignores in-flight reservations (reserve step 4): read outside transaction, excludes open reservations of the same run; "stricter than today's" claim dishonest unless open reservations count.
5 Under-reported actual cost booked as truth (settle): Reply.cost_usd may be 0 on a billed call; D11 covers prices only. Floor settle at input-token estimate x input price on a non-fake route; cost 0 with non-empty output = keep and log; settle above MAX_SPEND_OP_USD raises ValueError despite "never raise": book the cap value.
6 "Runtime cannot lower a total" holds only in app code (4.1, section 5): UPDATE grant on spend/spend_month lets a compromised runtime set totals. Compute totals from append-only spend_op (or a view), remove UPDATE/DELETE from the runtime role, or soften section 5. Needs a live second-role negative test (E0-3 lists only spend_op).
7 D5 is not non-blocking: migration 0006 fixes NUMERIC/Decimal; CLAUDE.md says money is integers; later switch = another migration plus rewrite of store methods, Money, Reply.cost_usd. D5 needed before M2a. Fuzz is_finite() first for sNaN.
8 Open-reservation/orphan handling thin (D15): crash loop fills the daily cap; relief only manual Limits.correct per reservation; no bulk path or expiry; availability bound unstated; res_id generation unspecified; test that a repeated res_id with different usd/agent is refused.
9 Redaction contract (4.7): Valid.mapping repr=False but the test asserts asdict/JSON hold no canary; asdict includes mapping whenever restore_kinds non-empty. Specify both cases or make mapping a private holder with __reduce__ raising; add pickle and deepcopy checks; output_schema defaults/examples guard; test that DeadLetter.errors and log lines hold no original (canary in model's echoed reply).
10 Over-claims: anchor_retention_proven -> anchor_retention_probed; signing_key_location is "configured"; "never raise" list the caught exceptions; "told one call later at most" depends on card delivery and in-process dedupe; section 0 "never/cannot" on unverified properties; window_owner "never a personal e-mail" needs a validator (reject @ and spaces) or drop it.
## Nits

Lock-in: no vendor SDK added outside kind modules; watch point is status mapping for ProviderRefused: make refused(exc) a kind hook like retryable. Estimator 3 chars/token acceptable only with a measured margin (D20 unmeasured).
