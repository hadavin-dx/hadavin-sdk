## 1. What this is, and the words
You make one filmed run of a demo that uses made-up people and a paid AI model. The model program asks the paid model once per made-up person to judge that person's made-up sales enquiry; each ask costs money. Every word below is explained once; read them first.
- **Lead** = the Claude session you chat with, where you received this sheet. It is software on this laptop under your Linux user (the name you log in with in WSL). It never sees your screen and never types your answers, but it could run commands as you, so it could read any file you can read, your clipboard and what Windows shows (R1). **Message place** = that chat only; a message from anywhere else is not genuine (R8).
- **Numbers message** = the lead's written message with every value for this run (sample in section 3). **Clean-up message** = its second message after the run. **Second way** = a way to reach the lead outside the message place that you already used before today; the numbers message names it (R8). None named: no run.
- **Report in words** = write in your own words which step you are at, what kind of line you see and any plain numbers (counts, times and the like). Never copy, type or photograph a key, an app password, any long random-looking text, or an address of a real person; no screenshots. A fingerprint is reported only as "first 16 match" or "first 16 differ".
- **UNVERIFIED** = nobody has run or seen it. The numbers message lists which UNVERIFIED items the lead has since seen. Where this sheet says UNVERIFIED and what you see differs: **FREEZE** (the stop-and-wait state defined in R10).
- **HubSpot** = a ready-made online service for customer records; its free test account holds the contacts. **Contact** = the HubSpot record of a person. **Contact id** = the number after `record/0-1/` in the address of that contact's page (UNVERIFIED).
- **Run name** = 4 to 12 lowercase letters and digits, starting with a letter, that you choose. **Test people** = three made-up people, "person A", "person B", "person C", with test addresses `take-<run name>-a@example.com` (`-b@`, `-c@`). **Prep contact** = one more made-up contact the lead creates before the run, `prep-<run name>@example.com` (the film search `take-<run name>` never finds it; the clean-up list includes it). **Person id** = a made-up number given to each test person (not a contact id).
- **Take program** = what you start in **WSL** (the Ubuntu window in Windows, using bash); it sends the test people into **n8n** (a ready-made tool that writes one contact per person and sends one mail). **Model program** = the lead's small piece of software that asks the paid model, using the paid key defined below. **Rehearsal** = the lead's earlier practice of the whole run on this laptop with a stand-in instead of the paid model: made-up data, no money.
- **Version id** = a short code naming the exact version of the take program. **Fingerprint** = a short code worked out from a file's contents; one changed letter changes it. You compare fingerprints with `sha256sum` (7.2).
- **Model key** = any paid-model key you create after starting section 6, named `run-<run name>`. **Older key** = the key you saved earlier for this project, if the numbers message names one. Only these two are called "key". **Key list** = the model account page that lists keys with name, creation time, last-used time and state word. **Valid key** = a key the key list shows as usable (not cancelled, not expired). **Cancelled word** = the state word you saw beside the older key right after cancelling it in 6.2 (none if there is no older key). **Key alive** = a model key not yet proven cancelled (R3). **Key file** = the file in WSL that holds the model key. **App passwords** = Gmail passwords made for one application.
- **Take terminal** = the WSL window in which the take program runs. **Second terminal** = another WSL window, for read commands only (R6). **Take settings file** = the take program's settings (you never edit it). **Model settings file** = the model program's settings (you only read named lines).
- **Notice** = the screen of numbers the take program prints before "Type y to start". **Challenge** = the 6-digit number it prints next. **Printed result** = what it prints after `end`. **Exit code** = the number the take program leaves when it ends; 0 means it says it passed. **Film pause** = the wait after the sends while the contact list and mails are filmed; it starts at the **film cue** in the numbers message (a printed line it copies, or minutes after you send "run started").
- **Recording** = any screen recording or screen sharing; **Recording OFF** = all of it switched off and nobody else can see your screen. **Privacy switches** = Windows "Clipboard history", "Sync across your devices" and Recall. **Film person** = a human who films the browser only and says "recording" (starts Recording) and "filmed" (done, Recording OFF), and switches Recording OFF at once when anyone says "stop". **Editor** = a human who crops and cuts the film. **Post checker** = a human who compares your post with the sentence. All three are named in the numbers message; you are none of them.
- **Demo mail** = a mail in the receiver Gmail under label `demo` whose subject starts with the subject start in the numbers message.
- **Window end** = Mon 23 Nov 2026 18:29 UTC = 23:59 IST: no run starts and nothing may spend after it. **Latest start**, **alarm time**, **cancel-by time** = three times on the run date in the numbers message: the latest moment you may press Enter on the start line (7.3); the latest moment the run can be finished (latest start + minutes at "Type y to start" + run length + film pause); alarm time plus a margin, never later than 10 minutes before the window end. **Program's last start** = the last time the take program itself accepts a start. **Call ceiling** = the most model calls one run can cause. **Run total** = call ceiling x worst-case price per call, what a correct run should use.
- **Plain money words:** **prepaid** = you pay first and calls draw the amount down; **auto-reload** = the account tops itself up when low (it must be OFF); **per-key limit** = a spending limit set on one key; **tokens** = the small pieces of text the model is charged by; **masked account** = an account name with the middle replaced by dots, as in the sample notice; **silence minutes** = how long the take terminal may print nothing before you treat it as stuck (R10).
- **Balance** = the whole prepaid amount the prepaid page shows: the most you can lose (R4). **Highest balance you accept** = your own limit on that figure. **Program limit** = a spending limit the lead sets inside the model program (the lead's promise, not the model company's, UNVERIFIED). **Usage page** = the model account page that shows balance and money used (a record that lags, not a control).
- **Throwaway accounts** = the receiver Gmail, the sender Gmail and the HubSpot test account you made earlier; never your real mailbox. **Verbs:** cancel (model key, older key), revoke (app password), delete (contact, demo mail).
- **What you may say:** post only the one sentence the lead sends in writing, word for word; say nothing else about what the system does or guarantees. Want more said: ask; the lead answers.
- **If the lead does not answer:** nothing starts. The one thing that never waits is cancelling your key (R2, R3); you can always do it alone.
