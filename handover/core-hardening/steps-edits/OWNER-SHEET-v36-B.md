## 1. What happens, and the words
**The run in short.** You and the **lead** type to each other in a chat; you make a paid key, run a test program once while a **film person** films, cancel the key with **the card** (a printed checklist, section 2), then delete and revoke what the lead lists. Start at 5.1.

**The words** (appendix part 1 holds every definition in full; the short forms below are enough to follow the steps).
- **UTC** = world clock time. **IST** = UTC + 5:30; your phone alarms use IST. **UNVERIFIED** = nobody has run or seen it; if what you see differs, stop (STOP RULE below), except **tolerated** items (marked at the step; only button, menu and page-path wording): describe it and proceed. A difference in a number, name, count, account, time or key state is never tolerated.
- **Lead** = the AI session (an AI, not a person) in the chat where you got this sheet, the **message place**; a message from anywhere else is not accepted. Never copy, type or photograph a key, app password, long random-looking text or real mail address (the copy at 6.3 and the paste at 6.4 are the only exception).
- **Model key** (a key alone means a model key) = a key to the paid model's account; it lets a program spend money; it is **alive** from the create press until card step 5 is done. **Valid key** = a key whose state word is not the cancelled word. **Older key** = a paid-model key you saved earlier, if the message names one. **Key list**: appendix part 1.

**STOP RULE.** If at any moment you do not know what to do, or what you see differs from this sheet or the numbers message (a lead "wait", a normal wait and button wording that means the same are not differences): (1) if a key is alive, do the card now; (2) then FREEZE and describe to the lead.
