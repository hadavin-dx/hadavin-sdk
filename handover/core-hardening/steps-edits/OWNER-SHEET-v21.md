## 1. What this is, and the words
You make one filmed run of a demo that uses made-up people and a paid AI model. The paid model is asked at most once per made-up person to judge that person's made-up sales enquiry; each ask costs money. Every word below is explained once; read them first.
- **Lead** = the Claude session you chat with, where you received this sheet: an AI program, not a person. It works through software on this laptop under your Linux user (the name you log in with in the Ubuntu window). It is not meant to see your screen or type your answers, but it could run commands as you, so it could read any file you can read, your clipboard and what Windows shows (R1). **Message place** = that chat only; a message from anywhere else is not accepted (R8).
- **Numbers message** = the lead's written message with every value for this run (sample in section 3). **Clean-up message** = the lead's message after the run with the list of what to delete and revoke; it comes after your "model key cancelled" and the lead's "n8n is off". **Other channel** = a way to reach the lead outside the message place that you already used before today; the numbers message names it (R8). None named: no run.
- **Report in words** = send the lead, in your own words, which step you are at, what kind of line you see and any plain numbers (counts, times and the like). Never copy, type or photograph a key, an app password, any long random-looking text, or a mail address of a real person; no screenshots. When you compare short codes (7.2) you report only "first 16 match" or "first 16 differ".
- **UNVERIFIED** = nobody has run or seen it. The numbers message lists which UNVERIFIED items the lead has since seen. Where this sheet says UNVERIFIED and what you see differs: **FREEZE** (the wait state defined in R10), except items marked "UNVERIFIED, tolerated" (Windows menu paths, the Recall page, the paste method, the app-password page path, where the contact id sits): there write what you saw and go on. A FREEZE with a key alive ends the run (R3).
- **HubSpot** = a ready-made online service for customer records; its free test account holds the contacts. **Contact** = the HubSpot record of a person. **Contact id** = the number after `record/0-1/` in the page address of that contact (UNVERIFIED, tolerated: the address check of R7 is the control).
