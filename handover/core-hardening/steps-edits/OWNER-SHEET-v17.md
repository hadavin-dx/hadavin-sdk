Written Mon 16 Nov 2026. Times are UTC and IST (IST = UTC + 5:30). This sheet replaces v4 to v16 (nothing deleted). Every check that rests on someone else's knowledge is in a separate note and is not asked of you.

## 1. What this is, what you may say, words
You make one filmed run of a demo that uses made-up people and a paid AI model. You do six things: make one paid key, type one written yes with numbers, type three answers, cancel the key, delete listed made-up contacts, post one sentence.
- **Lead** = the Claude session that works with you. It is software, runs commands on this laptop under your Linux user, never sees your screen and never types your answers. **Message** = a written message between you and the lead, in the place the lead names.
- **Test people** = three made-up people, "person A", "person B", "person C", with addresses `take-<run name>-a@example.com` (`-b@`, `-c@`). **Run name** = one new word of letters and digits that you choose. **Take program** = the program you start in **WSL** (the Ubuntu window in Windows), which sends the test people into **n8n** (a ready-made tool that writes one contact per person and sends one mail). **Model program** = the lead's small program that asks the paid AI model; it holds your model key.
- **Model key** = the paid AI key you make, named `run-<run name>`. Only this is called "key". Gmail passwords made for one program are **app passwords**.
- **Take settings file** = the take program's settings (you never edit it). **Model settings file** = the model program's settings (you only read named lines).
- **Contact** = the HubSpot record of a test person (HubSpot test account only). **Contact id** = the number HubSpot shows after `record/0-1/` in the address of that contact's page (UNVERIFIED; the lead's message gives one example).
- **Notice** = the screen of numbers the take program prints before "Type y to start". **Challenge** = the 6-digit number it prints next. **Printed result** = what it prints after `end`. **Film pause** = the wait after the submissions while the contact list and mails are filmed.
- **Window end** = Mon 23 Nov 2026 18:29 UTC = 23:59 IST: no run starts and nothing may spend after it. **Key deadline** and **latest start** = times on the run date that the lead's message gives. **Call ceiling** = the most model calls one run can cause. **Run total** = call ceiling x worst-case price per call. **Usage page** = the model account page that shows balance and money used so far (a record that lags, not a control).
- **Throwaway accounts** = the receiver Gmail, the sender Gmail and the HubSpot test account you made earlier; never your real mailbox. **UNVERIFIED** = nobody has run or seen it: if it differs, FREEZE (R10).
- **Verbs:** cancel (model key), revoke (app password), delete (contact, demo mail).
- **Step 0** (a live HubSpot check) is not part of this sheet; the lead may add it later, only in writing as a separate message.
- **What you may say:** post only the one sentence the lead sends you in writing, word for word. Nothing else about what the system does (no portal, approval step, audit trail, crash recovery, permissions, "deleted permanently", hard spend limit, "nothing can spend before both answers"). Want more said: ask; the lead decides.

## 5. The model key (R1 applies; every command UNVERIFIED)
1. Phone alarm (R3). Switch off Settings, System, Clipboard, "Clipboard history" and "Sync across your devices", Windows Recall and every screen recorder.
2. In the model account (address by hand) create a key named `run-<run name>`. If the message says a per-key limit exists, set it and check it shows; if not, the key is not limited. The page shows the key once: copy it with the page's copy button, close the page.
3. In WSL: `( set -C; umask 077; read -rs -p 'paste key, Enter: ' K; printf '%s\n' "$K" > "<model key file>" ); echo "exit $?"`. Paste only after the prompt shows. Exit not 0: copy a harmless word (this overwrites the clipboard), do not go on; the key is still on the page: copy it again, or cancel it (R2) if you cannot.
4. `ls -l "<model key file>"` starts `-rw-------`. Copy a harmless word (this overwrites the clipboard). Send the key's name as the key list shows it, its creation time and the file path (never its value).
5. The lead restarts the model program and sends its process number and start time. In WSL: `TZ=UTC ps -o pid=,lstart=,args= -p <number>` and `pgrep -af "<command line from the message>"` print one process with that start time, later than the last change of both files (`TZ=UTC ls -l --time-style=full-iso <model settings file> <model key file>`). This shows when it started, not which key it loaded. A difference: R10.
