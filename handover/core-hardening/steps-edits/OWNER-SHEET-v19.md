## 1. What this is, and the words
You make one filmed run of a demo that uses made-up people and a paid AI model. The words below are explained once; read them first.
- **Lead** = the Claude session that works with you in the chat where you got this sheet. No second way named: no run.
- **Numbers message** = the lead's written message with every value for this run (sample in section 3). **Clean-up message** = its second message after the take.
- **UNVERIFIED** = nobody has run or seen it. The numbers message lists which UNVERIFIED items the lead has since seen. Where this sheet says UNVERIFIED and what you see differs: FREEZE (R10).
- **Version id** = a short code naming the exact version of the take program (the lead calls it the "commit id"). **Fingerprint** = a short code worked out from a file's contents (the lead calls it the "checksum"); one changed letter changes it. You compare fingerprints with `sha256sum` (7.2).
- **Run name** = 4 to 12 lowercase letters and digits, starting with a letter, that you choose. **Test people** = three made-up people, "person A", "person B", "person C", with addresses `take-<run name>-a@example.com` (`-b@`, `-c@`). **Person id** = a made-up number the take program gives each test person (not a contact id). **Take program** = what you start in **WSL** (the Ubuntu window in Windows, using bash); it sends the test people into **n8n** (a ready-made tool that writes one contact per person and sends one mail). **Model program** = the lead's small piece of software that asks the paid AI model once per test person, using the model key.
- **HubSpot** = a ready-made online customer-contact service; its free test account holds the contacts. **Contact** = the HubSpot record of a person. **Contact id** = the number after `record/0-1/` in the address of that contact's page (UNVERIFIED).
- **Model key** = the paid AI key you make, named `run-<run name>`. **Older key** = the model key you saved earlier for this project, if the numbers message names one. Only these are called "key". **Key list** = the model account page that lists keys with name, creation time, last-used time and state. **Key file** = the file in WSL that holds the model key. **App passwords** = Gmail passwords made for one application.
- **Take window** = the WSL window in which the take program runs. **Second window** = another WSL window, for read commands only (R6). **Take settings file** = the take program's settings (you never edit it). **Model settings file** = the model program's settings (you only read named lines).
- **Notice** = the screen of numbers the take program prints before "Type y to start". **Challenge** = the 6-digit number it prints next. **Printed result** = what it prints after `end`. **Exit code** = the number the take program leaves when it ends; 0 means it says it passed. **Film pause** = the wait after the submissions while the contact list and mails are filmed.
- **Window end** = Mon 23 Nov 2026 18:29 UTC = 23:59 IST: no run starts and nothing may spend after it. **Latest start**, **alarm time**, **cancel-by time** = three times on the run date in the numbers message: the latest moment you may press Enter on the start line (7.3); the latest moment the run can be finished (latest start + minutes at "Type y to start" + run length + film pause); alarm time plus a margin. **Program's last start** = the last time the take program itself accepts a start. **Call ceiling** = the most model calls one run can cause. **Run total** = call ceiling x worst-case price per call, what a correct run should use.
- **Balance** = the whole prepaid amount the prepaid page shows: the most you can lose (R4). **Highest balance you accept** = your own limit on that figure. **Program limit** = a spending limit the lead sets inside the model program (a promise of the lead's software, not the model company's, and UNVERIFIED). **Usage page** = the model account page that shows balance and money used (a record that lags, not a control).
- **Throwaway accounts** = the receiver Gmail, the sender Gmail and the HubSpot test account you made earlier; never your real mailbox. **Verbs:** cancel (model key), revoke (app password), delete (contact, demo mail).
- **What you may say:** post only the one sentence the lead sends in writing, word for word. Say nothing else about what the system does or guarantees. Want more said: ask; the lead answers.
- **If the lead does not answer:** nothing starts. The one thing that never waits is cancelling your key (R2, R3); you can always do it alone.
