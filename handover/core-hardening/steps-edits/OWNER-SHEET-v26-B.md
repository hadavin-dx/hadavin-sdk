## 1. What happens, and the words
**The run in short.** You and the **lead** type to each other in a chat; you make a paid key, run a test program once while a **film person** films, cancel the key with **the card** (a printed one-page checklist, section 2), then delete and revoke what the lead lists. You need a film person and a post checker (5.2). Start at 5.1.

**The words.**
- **UTC** = world clock time. **IST** = UTC + 5:30; your phone alarms use IST. **UNVERIFIED** = nobody has run or seen it; if what you see differs, stop (STOP RULE below), except **tolerated** items (marked at each step; only button, menu and page-path wording): describe it and proceed. A difference in a number, name, count, account, time or key state is never tolerated.
- **Lead** = the AI session (an AI system, not a person) in the chat where you got this sheet; that chat is the **message place**: a message from anywhere else is not accepted. The lead sends the **numbers message** (every value for this run, sample in section 3); you check it by hand, type a yes and wait for "go". A **run name** is 4 to 12 lowercase letters and digits, starting with a letter, never used before. The **other channel** (card words) and the **backup person** (a human you can call who can reach whoever runs the lead) are named in the numbers message; none named: no run.
- **WSL** = the Ubuntu window inside Windows (Start menu, type Ubuntu, Enter). The **test terminal** and **read terminal** (card words) are two WSL windows; the read terminal is for `date -u`, `ls -l`, `clear` and the grep of 5.7 only; keep it open from 5.1.
- **Send** = type in the message place and press Enter. **Describe** = send which step you are at, what kind of line you see and plain numbers. Never copy, type or photograph a key, app password, long random-looking text or real mail address; no screenshots. **Set phrase** = words you send exactly (list at the end of section 2). **Run** as a verb = type a command and press Enter; a **run** = this one filmed attempt. **Key** alone = a model key; the words take in `take-` and `--take` are plain text.
- **Clean-up message** = the lead's message after the run (8.2) with the lists to delete and revoke.
- **Model key** = a key to the paid model's account; it lets a program spend money; it is **alive** from the create press until card step 5 is done. **Model account** = the paid model company's account where you pay and make keys; open it only from your own bookmark or an address you type. The **test program** is the program you start by hand: it sends three made-up people through **n8n** (a ready-made linking tool) into **HubSpot** (a ready-made customer-record service; here a free test account), making one **contact** (customer record) and one mail per person. **Older key** = a paid-model key you saved earlier, if the numbers message names one. **Valid key** = a key the key list shows as usable. **Cancelled word** = the state word of a cancelled key, given in the numbers message (none: no run).
- **Film pause** = the wait while the film person films; it starts at the **film cue** (a printed line copied in the numbers message, or minutes after you sent "run started"). **Recording OFF** = every screen recording or sharing is off. **Recording box** = the page area of the film profile's browser window (no tab strip, address bar or profile menu). **Privacy switches** = Windows Clipboard history, Sync across your devices, Recall. **Film profile** = the Chrome profile `demo-take` (5.5). The numbers message names the film person, the **editor** (cuts the film) and the **post checker** (compares your post with the sentences); you are none of them.
- **Demo mail** = a mail in the receiver Gmail under label `demo` that R7 allows you to delete. **Throwaway accounts** = the receiver Gmail (gets the demo mails), the sender Gmail (sends them) and the HubSpot test account you made earlier, never your real mailbox. **App passwords** = Gmail passwords made for one application; **HubSpot app secrets** = secret values of the flows' HubSpot private apps.
- **Made-up people** = person A, B and C, with addresses `take-<run name>-a@example.com` (`-b@`, `-c@`); the **prep contact** = one extra practice contact (the clean-up message lists it). **Key file** = the file in WSL holding the model key. **Model program** = the lead's software that asks the paid model with your key; you never edit its settings file or the test program's.
- **Money.** **Prepaid** = you pay first and calls draw the amount down; **auto-reload** = the account tops itself up when low (must be off). **Balance** = the whole prepaid amount: the most you can lose. **Last-resort step** = one action in the model account that only stops spending; the numbers message names it and says whether it can be undone (UNVERIFIED).
- **Times** (in the numbers message). **Run day** = the one day of the run, as in `Wed 18 Nov 2026`. **Deadline** = the end of the period your spending approval covers, Mon 23 Nov 2026 18:29 UTC = 23:59 IST: after it nothing may spend. **Earliest key time**: before it you do not press create. **Latest start** = the time after which you do not press Enter on the start line (7.3). **Give-up minutes** = how long the test program waits for `end` before it gives up. **Alarm time** and **cancel-by time** = when the run should be over, and the backup; **silence minutes** = how long the test terminal may print nothing before you treat it as stuck. **FREEZE** (a key alive: the card first) = type and close nothing more in the test terminal (except `n` at "Type y to start"); in the read terminal run only `date -u` and `ls -l "<path from the message>"`; in the browser do only the card and the deleting R7 allows; describe; wait for the lead's word "continue". If a key was alive the run ends after the card: no word resumes it.

**STOP RULE.** If at any moment you do not know what to do, or what you see differs from this sheet or the numbers message: (1) if a key is alive, do the card now; (2) then FREEZE and describe to the lead. If two rules disagree: the card first, then R1, then R10, then the rest.
