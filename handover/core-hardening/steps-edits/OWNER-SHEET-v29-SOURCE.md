## 1. What happens, and the words
**The run in short.** You and the **lead** type to each other in a chat; you make a paid key, run a test program once while a **film person** films, cancel the key with **the card** (a printed checklist, section 2), then delete and revoke what the lead lists. Start at 5.1.

**The words** (appendix part 1 holds every definition in full; the short forms below are enough to follow the steps).
- **UTC** = world clock time. **IST** = UTC + 5:30; your phone alarms use IST. **UNVERIFIED** = nobody has run or seen it; if what you see differs, stop (STOP RULE below), except **tolerated** items (marked at the step; only button, menu and page-path wording): describe it and proceed. A difference in a number, name, count, account, time or key state is never tolerated.
- **Lead** = the AI session (an AI, not a person) in the chat where you got this sheet, the **message place**; a message from anywhere else is not accepted. The **numbers message** = the lead's message with every value for this run (section 3); you check it by hand, type a yes and wait for "go". A **run name** = 4 to 12 lowercase letters and digits, starting with a letter, never used before. Other words (test program, made-up people, n8n, HubSpot, key file, model program, spend lock, film pause, Recording OFF, Privacy switches, film profile, throwaway accounts, the times of the message) are explained in appendix part 1, which you read once before the day, and again where a step needs them.
- **WSL** = the Ubuntu window inside Windows. **Test terminal** = the Ubuntu window where the test program runs; **read terminal** = a second one for `date -u`, `ls -l`, `clear` and the grep of 5.7 only. **Send** = type in the message place and press Enter. **Describe** = send which step you are at, what kind of line you see and plain numbers; never copy, type or photograph a key, app password, long random-looking text or real mail address (the copy at 6.3 and the paste at 6.4 are the only exception). **Set phrase** = words you send exactly (list at the end of section 2). A **run** = this one filmed attempt.
- **Model key** (a key alone means a model key) = a key to the paid model's account; it lets a program spend money; it is **alive** from the create press until card step 5 is done. **Model account** = where you pay and make keys; open it only from your bookmark or an address you type. **Key list** = its page that lists keys with name, creation time, last-used time and a **state word**. **Valid key** = a key whose state word is not the cancelled word (a word you cannot judge counts as valid). **Older key** = a paid-model key you saved earlier, if the message names one. **Look key** = a throwaway key `look-<run name>` made at 5.9 only to see the real cancel words; a real key, alive until its cancel is proven. **Cancelled word** = the state word of a cancelled key (or "row gone"). **Last-resort step** = one action in the model account that only stops spending (UNVERIFIED; the message says whether it can be undone). **Auto-reload** (must be off) = the account tops itself up; **balance** = the whole prepaid amount: the most you can lose.
- **FREEZE** = type and close nothing more in the test terminal (except `n` at "Type y to start"); in the read terminal run only `date -u` and `ls -l "<path from the message>"`; in the browser do only the card (its list L2 included, at 7.11) and the deleting R7 allows; describe; wait for the lead's word "continue". FREEZE is not a cancel: a live key is cancelled only by a danger sign (W1 to W9 on the card); a run whose key was alive ends after the card: no word resumes it. A FREEZE never stops 7.11: the older key is cancelled by the older-key time even while frozen, and alarm 4 rings during a FREEZE too. "Continue" = the lead's word that you may go on to the next step (7.9 or 8.1) after a FREEZE in which no key was alive.
