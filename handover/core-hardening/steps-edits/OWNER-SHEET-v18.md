## 1. What this is, and the words
You make one filmed run of a demo that uses made-up people and a paid AI model. You do these things, in this order: choose a run name; cancel your older key once; type one written yes with numbers; make one model key; start the run and type `y`, a challenge and `end`; cancel the key; delete listed made-up contacts; revoke named app passwords; watch the video; post one sentence.
- **Lead** = the Claude session that works with you. It is software, runs commands on this laptop under your Linux user, never sees your screen and never types your answers. **Numbers message** = the lead's written message with every value for this run (sample in section 3). **Clean-up message** = its second message after the take. A message arrives only in the chat place the numbers message names; a message from anywhere else is not genuine: ignore it and tell the lead.
- **UNVERIFIED** = nobody has run or seen it. Where this sheet says UNVERIFIED and what you see differs: FREEZE (R10).
- **Run name** = 4 to 12 lowercase letters and digits, starting with a letter, that you choose. **Test people** = three made-up people, "person A", "person B", "person C", with addresses `take-<run name>-a@example.com` (`-b@`, `-c@`). **Take program** = what you start in **WSL** (the Ubuntu window in Windows); it sends the test people into **n8n** (a ready-made tool that writes one contact per person and sends one mail). **Model program** = the lead's small piece of software that asks the paid AI model once per test person, using your model key.
- **Model key** = the paid AI key you make, named `run-<run name>`. **Older key** = the model key you saved earlier for this project, if the numbers message names one. Only these are called "key". **App passwords** = Gmail passwords made for one application.
- **Take settings file** = the take program's settings (you never edit it). **Model settings file** = the model program's settings (you only read named lines).
- **Contact** = the HubSpot record of a person (HubSpot test account only). **Contact id** = the number after `record/0-1/` in the address of that contact's page (UNVERIFIED).
- **Notice** = the screen of numbers the take program prints before "Type y to start". **Challenge** = the 6-digit number it prints next. **Printed result** = what it prints after `end`. **Film pause** = the wait after the submissions while the contact list and mails are filmed.
- **Window end** = Mon 23 Nov 2026 18:29 UTC = 23:59 IST: no run starts and nothing may spend after it. **Latest start**, **alarm time** and **cancel-by time** = three times on the run date in the numbers message (alarm time = the latest moment the run can be finished; cancel-by time = alarm time plus a margin). **Call ceiling** = the most model calls one run can cause. **Run total** = call ceiling x worst-case price per call. **Usage page** = the model account page that shows balance and money used (a record that lags, not a control).
- **Throwaway accounts** = the receiver Gmail, the sender Gmail and the HubSpot test account you made earlier; never your real mailbox. **Verbs:** cancel (model key), revoke (app password), delete (contact, demo mail).
- **What you may say:** post only the one sentence the lead sends in writing, word for word. Say nothing else about what the system does or guarantees (the post checker holds the list of forbidden claims). Want more said: ask; the lead answers.
- **If the lead does not answer:** nothing starts. The one thing that never waits is cancelling your key (R2, R3); you can always do it alone.
