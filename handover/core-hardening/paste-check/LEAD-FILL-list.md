## PROPOSAL for item 1: body of `pastes\P-4b.sh` (NOT part of the plan; the lead may use, change or discard it)
Read-only scan by uid of /proc. Definition used (my guess, to be replaced by the lead's from the final-head `n8n_kill.py`): "this uid" = the owner of /proc/<pid> equals the uid that runs the script; "unreadable" = opening /proc/<pid>/environ for reading fails; "n8n-shaped" = the command line contains `n8n` (case-insensitive). It prints `P-4b-HIT pid=<n>` per process, nothing else, and exits 0 also when it finds nothing (a plain `grep` would exit 1). It does not use env.sh, `$T`, `$R` or `$P`.
```bash
#!/bin/bash
# P-4b (PROPOSAL, lead to replace): read-only. Prints one line per process of THIS uid whose /proc/<pid>/environ cannot be read
# and whose command line mentions n8n. Never kills. No env.sh, no $T/$R/$P. Always exits 0.
me=$(id -u)
for d in /proc/[0-9]*; do
  p=${d#/proc/}
  [ "$p" = "$$" ] && continue
  u=$(stat -c %u "$d" 2>/dev/null) || continue
  [ "$u" = "$me" ] || continue
  if ! { : < "$d/environ"; } 2>/dev/null; then
    if tr '\0' ' ' < "$d/cmdline" 2>/dev/null | grep -qiF n8n; then echo "P-4b-HIT pid=$p"; fi
  fi
done
exit 0
```
Tests (evidence-c3g.md section 6; v3: evidence-c3f.md 4.4; STUB tests on this Linux container, not WSL): `bash -n` and `dash -n` rc 0; as root with nothing n8n-named: no output, exit 0; as uid 65534 with no stub: no output, exit 0 (negative control); as uid 65534 with a stub process whose command line contains `n8n-stub` and that is not dumpable (prctl PR_SET_DUMPABLE 0, so its environ is unreadable to that uid): prints `P-4b-HIT pid=<n>`, exit 0 (positive control). Not tested: real WSL Ubuntu, a real unreadable n8n process, a process that shows its command line only to root, `hidepid` mounts.
Positive-control instructions for the lead (to make `pastes\P-4b.control.txt`): (1) save the final `P-4b.sh`; (2) start a stand-in of this user whose command line contains `n8n` and whose environ this user cannot read (the stub above used `prctl(PR_SET_DUMPABLE, 0)` from python as a non-root user; root cannot test this, root reads everything); (3) run the script once: `bash pastes/P-4b.sh > /tmp/p4b-run.txt; echo "exit=$?"`, it must print at least one `P-4b-HIT` line and `exit=0`; (4) write the control file: first line `P-4b.sh sha256 ` + the output of `sha256sum pastes/P-4b.sh | cut -d' ' -f1`, then the lines of `/tmp/p4b-run.txt` (every line must be `P-4b-HIT pid=<digits>`; write the file as plain ASCII with LF line ends, no CR); (5) end the stand-in by its exact pid (you started it); (6) any later edit of `P-4b.sh` needs steps 1 to 4 again (P-3b compares the hash); (7) note in PROGRESS how the stand-in was made.
