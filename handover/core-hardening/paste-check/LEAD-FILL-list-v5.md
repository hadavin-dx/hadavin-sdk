## PROPOSAL for item 1: body of `pastes\P-4b.sh` (NOT part of the plan; the lead may use, change or discard it)
Read-only scan by user id of /proc. Definition used (my guess, to be replaced by the lead's from the final-head `n8n_kill.py`): "this user" = the owner of /proc/<pid> equals the user id that runs the script; "unreadable" = opening /proc/<pid>/environ for reading fails; "n8n-shaped" = the command line contains `n8n` (case-insensitive). It prints `P-4b-HIT pid=<n>` per process, nothing else, and exits 0 also when it finds nothing. It uses no run variables. v5: the file must not contain the words `kill` or `env.sh` anywhere (P-3b searches for them, comments included), so the text below avoids them.
```bash
#!/bin/bash
# P-4b (PROPOSAL, lead to replace): read-only scan of /proc.
# Prints one line per process of THIS user whose /proc/<pid>/environ cannot be read
# and whose command line mentions n8n. Changes nothing. Needs no run variables. Always exits 0.
me=$(id -u)
for d in /proc/[0-9]*; do
  p=${d#/proc/}
  [ "$p" = "$$" ] && continue
  u=$(stat -c %u "$d" 2>/dev/null) || continue
  [ "$u" = "$me" ] || continue
  if ! { : < "$d/environ"; } 2>/dev/null; then
    if tr '\0' ' ' < "$d/cmdline" 2>/dev/null | grep -qiF n8n; then echo "P-4b-HIT pid=$p"; fi
  fi
done
exit 0
```
Tests (evidence-c7f.md section 9; STUB tests on this Linux container, not WSL): `bash -n` and `dash -n` rc 0; word scan prints nothing; as user 65534 with no stand-in: no output, exit 0 (negative control); as user 65534 with a stand-in process whose command line contains `n8n-stub` and that is not dumpable (prctl PR_SET_DUMPABLE 0, so its environ is unreadable to that user): prints `P-4b-HIT pid=<n>`, exit 0 (positive control); P-3b prints `P-4b files ok` for the control made as below, and `P-4b files STOP` after `P-4b.sh` is edited. Not tested: real WSL Ubuntu, a real unreadable n8n process, a process that shows its command line only to root, `hidepid` mounts.
