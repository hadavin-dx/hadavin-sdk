# Re-pin v6 security review (egm-design, uncapped; condensed copy of the inline report), 2026-11-16
Target: lead-repin/lead-repin-verify.sh (1805 lines) and LEAD-REPIN-VERIFY.md (guide v6). Read-only; nothing was run, every leak is derived from the sed and awk rules, not observed. Verdict: NOT READY TO FREEZE. No blocker by reasoning; 6 majors; 11 minors.

## MAJOR
- M1 Names inside escaped quotes are not recognised (rules 252, 282, 254): `\"password\": \"hunter2\"` (JSON inside a JSON string or shell string; n8n jsonBody, curl -d). Values under 24 characters show. Same family: a key written with a JSON escape. Fix: allow optional backslash before each quote; add cases.
- M2 Password-flag rule (line 289) anchored with `^` and lowercase command word: misses commands after `&&`, `;`, `|`, `$(`, `./tool`, `FOO=1 tool`, a flag on a continuation line; only -p/-P/-w; value >= 3 chars; quoted multi-word value only first word masked; values starting with `/ ~ - <` skipped. The guide describes it too generously. Fix: drop anchor, allow separators and paths, reuse STR, continuation handling, state limits.
- M3 A recognised name does not always hide the value: XML element text (`<password>x</password>`); glued names (`DBPASS=`, `ROOTPW=`, `requirepass x`, `masterauth x`, `jsessionid=`); values starting with `<`; `password == "x"`; mid-line `:=`; SQL `IDENTIFIED BY 'x'`; a second literal after a hidden one; mid-line unquoted values containing `]"')}`. Fix: add self-test cases and rules; list the rest in the guide.
- M4 Guide's git promise is false: LEAD_REPIN_NO_STATUS=1 skips only `git status`; `git log -1` (line 1626) still runs with the folder's own config (log.showSignature plus gpg.program, about 80% sure). Fix: `-c log.showSignature=false --no-show-signature -c gpg.program=/bin/false -c core.hooksPath=/dev/null` in g(), or narrow the wording.
- M5 User-info forms not covered "of every form": `//TOKEN@host` hidden only for 16+ chars (shorter only by the e-mail rule when the host has a dot); dotless host shows; `https:\/\/bob:pw@h`; `bob:pw@host` without scheme. Fix rules and test, or narrow the claim.
- M6 Evidence does not support guide claims: timing-1mb.txt and mutants-bash.txt missing; mutants-dash.txt empty; no transcript of v6 self-test passed=1191; signals-v6.txt 12 of 16 BAD (INT, HUP, QUIT time out, folders left, strays); exit codes 130/131/141 untested; probe-v6-result.txt is the builder's own probes. Fix: rerun signals, self-test under both shells, save raw output.
