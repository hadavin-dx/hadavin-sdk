## M2 closed: cause, fix, proof
- **Bug class:** a pattern written for readable names also matches random tokens built from the same letters (cmdlet-shape rule `Verb-<module><Noun>`). Rule: `gate.py` `_WRITE_SHAPES`, the `(?!get-)[a-z]+-(?:az|azurerm|azuread|ec2|s3|iam|rds|lm|cfn|ecs|eks)[a-z]\w*` alternative (line 671 on base). The reviewer was right that it is in `gate.py`, not `channel.py` (`channel.clean` calls `gate.withhold_commands`; my earlier "channel.py not touched" was the wrong file; I had not diagnosed it).
- **Why only `ec2`:** a Hadavin id is `prefix-` plus 32 hex digits (`models.new_id`). Only `ec2` followed by a letter a-f is spelled with hex digits (`s3`, `iam`, `rds`, `lm`, `cfn`, `ecs`, `eks`, `az...` contain non-hex letters). So `pln-ec2a...` to `pln-ec2f...` is withheld as "a cloud command".
- **Per-id arithmetic:** chance per id = (1/16)^3 (digits e, c, 2) x 6/16 (fourth digit a-f) = 9.155e-5 (1 in 10,923). The s4 test builds 4 ids (`run`, `pln`, `apr`, `evt`; any lowercase prefix qualifies): 4 x 9.155e-5 = 3.66e-4 per test (1 in 2,731). Expected in 20,000 loops: 7.3 bad. The reviewer's 2.4 counted one id and a partial rate; the earlier 9 base / 3 patched are both consistent with 7.3 (Poisson: P(<=3) = 0.066, P(>=9) = 0.31). Patched is not better than base: its gate code is the same, apart from the docstring.
- **Exact count:** all 4 prefixes x all 65,536 first-four-digit values (262,144 ids) through `clean()`: base 24 bad (= 4 prefixes x 6 values, matches 9.155e-5 exactly), fixed 0 (`sibling-clean-allids-OLD.log`, `-NEW.log`, script `sib.py`).
- **Loop (script saved: `flake-loop.py`, `flake-loop-run.sh`):** 200,000 iterations of the s4 logic with the real `new_id`: base 81 ids missing of 800,000 (expected 73.2); fixed 0 of 800,000.
- **Sibling check in `_WRITE_SHAPES`:** the other alternatives need SQL keywords, `rm`, `curl`/`wget`, `invoke-*`, `irm|iwr|iex` or a named cmdlet: none can be spelled by `prefix-` plus hex digits. Supported by the exhaustive `clean()` sweep (0 bad on fixed code, the only bad ids on base were the 24 `ec2[a-f]` ones). `_PROGRAM` pass (program names) also gave no hit in the sweep.
- **Fix:** one lookahead in that alternative: `[a-z]+-(?![0-9a-f]{32,}\b)(?:az|...)`. A token that is a hyphen then 32 or more hex digits (id or hash) is not a cmdlet; a real cmdlet noun always holds a letter outside a-f, so `Remove-EC2Instance`, `Remove-AzResourceGroup` etc. are still withheld (tested). New file `tests/test_g4_ids_not_withheld.py`: 14 tests (named id; every first-four-digit value for each of the 4 prefixes; 20,000 sha256-derived texts, fixed so each run is the same, no random module (`S311` was flagged and I removed the generator instead of suppressing); 2,000 real `new_id`; 6 real-cmdlet still-withheld cases; one not-all-hex case).
