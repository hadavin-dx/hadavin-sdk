# About this folder

This is the studio's distilled rule book (the 'bible'), written as the owner's own notes from a forward-deployed-engineer course. It is copied here so the cloud session can follow the same rules the laptop session uses. Rule ids look like R110. It contains no course images, PDFs or slides (those stay private). Names of third-party products inside it are only examples of what a rule means. Delete this folder with the rest of `handover/` before the final merge. Paths such as `<studio>/...` point at the owner's private laptop and do not exist here.
