## Claims verified correct (abridged by the lead)
- The three modules are separable by imports (`rowstore`, `config_view` import only the standard library; `stop_gate` imports `audit.labelkey`, `limits`, `models`; none import `textnorm` or each other). Line counts at PR50-local match (stop_gate 425, rowstore 225, config_view 181, labelkey 39, limits 70).
- PR50-pushed lacks `labelkey.py`, `switch`/`expect`, `unaudited`, `allow_unbounded` and byte caps. Mutant counts by prefix are right (view 14, gate 31, rowstore 7, rows 3 = 55); the weak row is at `promoted_mutants.py:868`, the pinned test at `test_promoted_controls.py:1787`.
- Fail-closed reads are right: `durable_on()` and `_stopped_fresh()` treat any exception as ON; Postgres reads a missing row as ON. Caveats: the `cache_ttl` stale-allow window and C5. `agent_loop._limits_stop` has no exception handling around `limits.blocked`, so an unreadable store raises out of it (the ticket's UNVERIFIED stays open).
- RowStore is memory-only so no migration; the atomic `UPDATE ... WHERE` needs no migration. `config.py:52` is `extra="forbid"`, so "ce70eb5 fails at load on new keys" holds (closes that UNVERIFIED).
- The E-mail is stored in clear (`_LABEL` includes `@`). MANIFEST ids, demo commit `3d78bc7be`, dealdesk/refunds line references and the named tests at L exist as cited. The hot-file text of A9 F6 for `limits.py`, `errors.py`, `postgres.py` is quoted correctly. Template: all 17 fields present in order.
