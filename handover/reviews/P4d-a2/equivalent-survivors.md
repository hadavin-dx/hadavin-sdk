m19 (llm/common.py price_cost returns cost unrounded) and m20 (llm/fake.py cost not wrapped) are EQUIVALENT survivors. Reply.cost_usd and Verdict.cost_usd carry a field_validator that applies round_cost_up at construction, and every producer returns its cost only inside a Reply or Verdict. So the producer-side round_cost_up is a second layer behind the validator: removing ONE layer cannot change any value a caller can see. m55 removes round_cost_up itself (both layers) and is killed, which proves the rounding is tested; m18 (validator removed) is killed because the producers still round. No observable behaviour distinguishes m19/m20 from the code, so no test can kill them; they are kept in the table as equivalent, not hidden.
