## Considered and found sound (reviewer's list, abridged)
- Never degrading compare-and-set; the single conditional UPDATE under READ COMMITTED closes the read-then-write window.
- Missing row or read error treated as ON (`postgres.py:446-451`); a reset against that synthetic token matches no row.
- Writing the switch before the audit on stop; the audit intent before the clear on reset.
- New errors derived from `RuntimeError`, not `OSError`; core rejecting an unknown `limits` config section is a loud rollback signal; `IS NOT DISTINCT FROM` on `by` handles the seeded NULL row; raw-name check before masking, mask once; barrier scope stated honestly (this process only); replay of an old token fails except the clock edge in A13.
