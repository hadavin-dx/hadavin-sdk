## Positions
1. **Choke point over spellings (ADV-R7-2, CONTEST of the design, not of the finding).** The text rules can only list spellings; indirection (a function body, an XML helper) defeats any list. The server tells us the truth after each file in one query. This is cheaper than another round of text rules and it closes the whole class. The two rules cut are the ones that were never able to be complete.
2. **Recipe is self-protecting (ADV-R7-1).** Two independent layers (`-X`, and the recipe's own `\set ON_ERROR_STOP on`) because each is defeated by a different mistake; both are probed. A reader running the message by hand with a personal startup file is the real-life case.
3. **Closing the CR hole now (ADV-R7-3).** Using the lexer in `_scan` is two lines of change plus two failing-first tests; the argument "keep the diff small" does not hold when the hole is a blinded grant scan in the file being edited.
4. **Surface cut (ADV-R7-15, ADV-R7-8, COR-R7-3, ADV-R7-6, COR-R7-7).** Removed: two text rules, `BEGIN ATOMIC`, four comparer kinds, two equivalent mutants, the differential test (never added). Added: the read-back (one function and three plants), the exact-output tests, one rule (`DISABLE TRIGGER`), generated first line, separators, escape tests. The author recounts; I expect net mutants roughly flat (UNVERIFIED), net design smaller.
5. **What I did NOT do.** No second oracle (`pglast`). No `CREATE ROLE`/`GRANT` rules. No `ENABLE ALWAYS` refusal. Each is in the v1.1 table.
