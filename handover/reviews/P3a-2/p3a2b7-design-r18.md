A `ClientError` message can carry an account id or role ARN; a log handler or error tracker that walks `__context__` and ignores `__suppress_context__` records exactly the text the batch says it hides. CHANGELOG and docstring ("never the SDK's own words", "prints none of the cloud library's words") are true of the printed message only. Fix: build the error outside the `except` block (set a variable, raise after) so `__context__` is empty, or set `err.__context__ = None`; assert the words are absent from `"".join(traceback.format_exception(...))` and that `__context__` is None; or reword to "not printed".
