## Reviewer's verdicts on specific attack-list points (abridged)
- Arbitrary file: no (the stem must equal a file in the shipped folder). Skipping a dependency: not blocked (CI's fresh install is the only guard). Marking a migration applied without running it: no (the ledger insert follows the execute in the same transaction). It runs under the lock and adds no right; the abuse risks are A1 (unusable), A2 (no trail) and A3 (COMMIT breaks the transaction).
- The order check is correct after the lock; `gone` then order is the right order. Manifest recommended scope is safe but weak (A9). Layer 1 is useful for structure, not rights or data (A5, A6). Runtime read and decode of every file is cheap. Nothing widens rights.
