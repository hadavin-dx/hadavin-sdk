Fix: zero-width look-ahead finder or `search(low, i)` advancing one character; add overlapping joins to the corpus (`pass`+`session`, `access`+`sessid`, `access`+`secret`, `pass`+`sas_token`, `client`+`token`); a mutant planting non-overlapping finding.
- **F2** A capital-first hyphenated token is read as the scheme word, so the token stays readable (redact.py:61 `_ANY_SCHEME_WORD`, used at :935). Tests cover lower-case only (M240 and `test_b12_4_a_lower_case_hyphen_token_is_not_read_as_a_scheme_word`, :212; comment "capitals only" shows the capital case was not considered). Fix: short allowlist of known hyphenated schemes (`AWS4-HMAC-SHA256`, `SCRAM-SHA-*`), or read as scheme only when a second token of 8 or more characters follows on the same line with no break, or give the hyphen class only to the fold rule at :979; negative test and mutant.
