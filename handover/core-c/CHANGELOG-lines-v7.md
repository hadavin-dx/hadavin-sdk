#### Upgrade steps

- **Model gate: budgets, a wider safety net, and a RunMap-only bind (`guard/model_gate.py`, `guard/runmap.py`).** <!-- C1 K69 --> `ModelGate.bind(..., mapping=)` accepts only a `runmap.RunMap` or `NO_MAP`. A plain dict, or a copy made with `dict(run_map)`, raises `TypeError`. An empty `RunMap` is accepted and the audit row says `map_enforced_empty`. The gate cannot tell the run's own map from another `RunMap`. <!-- C2 K13 K64 --> One budget covers the characters, the steps and the time of one chat call: at most 32,768 steps and two deadlines of `defaults.REDACT_BUDGET_S` (6.0 s). The CPU deadline is passed into the redactor's sweep. The monotonic wall-clock deadline is read by `EnforceBudget.check` between values and after each sweep. Past any of them the call is refused with the code `mask_budget_exceeded` (`MaskBudgetExceeded`, a subclass of `UnmaskedInput`). One regex scan of one stretch of text inside the redactor cannot be interrupted. At most 4,096 held-back values and 20,480 entries are accepted per call; before, 256 held-back values refused every later call of a run. <!-- C3 K65 K78 K79 K80 --> The safety net (`held_value_left`, code `held_value_left`) checks every known secret of 4 or more characters in each enforced chunk. A secret hidden in a made-up `<NAME_1>` token that is not a key of the map refuses the call. A secret that spans a fixed framing word is cut by the word and passes as written (stated limit, pinned). The net's newer reach is in C17. <!-- C4 K14 K66 --> `framing_refused` also fires when a known secret is a piece of a name in the call's `tools` list. A name that is in that list stays exact in the assistant line and the marker. A planted value equal to a tool name refuses every later call of the run. <!-- C5 K16 K22 --> A KeyboardInterrupt in the enforce step, in `worst_case`, in `reserve` or in the instant after it writes an audit row (`call_interrupted` or `reserve_interrupted`) and passes on. A stop inside `settle` or inside the audit write writes no row. A `cost_usd` that is `-0`, has an absurd exponent, or raises on read is `cost_unknown`: the reply is returned and not settled. The install test names the judge's four call points and holds five strict expected failures until the gate is installed.

- **Model gate: the "refused before any answer" mark is honoured on an exhausted call (`guard/model_gate.py`).** <!-- C14 K20 --> `refused_before_response` is now True for any `ProviderError`, `ProviderExhausted` included, whose `refused_before_response` attribute is exactly `True`. Such a call is settled at 0 with the code `provider_refused`. An unmarked `ProviderExhausted` stays `provider_exhausted` and is not settled. A mark that is truthy but not `True`, or that raises on read, is not honoured. The gate cannot verify the mark: an adapter must set it only when no attempt may have been billed. `llm/retry.py` sets no mark yet, so today every failed call keeps its worst case booked.
  LEAD DECISION (gate (c) contract): default built, the mark is honoured on `ProviderExhausted`.

- **Redactor: the pattern passes run to a fixed point; refusal words (`guard/redact.py`, `defaults.py`).** <!-- C6 K39 --> After the first pass, `_Redactor.settle` repeats the table and the sweep over the strings the previous round changed, at most `_SETTLE_ROUNDS` (4) repeat rounds. A call that still changes a text in the fourth repeat round (round 5 of the call) is refused with `RedactionError("NotSettled")`. The CPU deadline is read before every round and inside every sweep, finder build and written-forms scan. It is NOT read inside one pattern pass over a string, or in the loop over the strings of one round. <!-- C7 K73 --> A hostile text can force a refusal of the whole document (fail closed, nothing shown). The words are `InputTooLarge("SpelledWorkTooMuch")` past `defaults.SPELLED_MAX_WORK` (4,000,000 units), `InputTooLarge("SpelledMemoryTooMuch")` past `defaults.SPELLED_MAX_CHARS` (1,000,000 characters of written forms in one call), and `InputTooLarge("InputTooLarge")` for the time or size limit. C16 and the E14 entry add `SpelledNotSettled`, `SpelledUnionTooMuch` and `FinderMemoryTooMuch`. <!-- C8 K72 --> The two overlap limits pinned before (a written form completed only in a later round; two values that overlap as raw text) are closed by C16.

- **Redaction of glued values, G8 (`guard/redact.py`).** <!-- C9 K38 K70 --> An IPv4 address, a UUID, a phone number written with `+`, and an IBAN beside `_` are masked when a letter or `_` is glued to them (`10.20.30.40_x` becomes `<IPV4_1>_x`). The glued text stays outside the placeholder. Over-masking, accepted: some look-alikes are masked too. Four-part version numbers glued to a word are masked, and so are long digit runs after an underscore (`card_4242424242424242` becomes `card_<PHONE_1>` and is kept in the run's map as a phone number). <!-- C10 K70 --> Not masked, as built (pinned): a phone number or card number written as one run of digits with a letter beside it (`x4155550132`, `telephone4155550132`, `x4242424242424242`). Also not masked: a phone number before a full stop that a letter, digit or `_` follows (`call 415-555-0132.Thanks`). The same holds for an IBAN with a letter or digit before it, or inside a file name, path or key (`acct_iban_DE89...`, `xDE89...`).
  LEAD DECISION (G8 L-D15, L-D17): the code has the defaults (the short-word IBAN rule, no card-number check). L-D13 is built as C15 on the lead's build order.

- **Redaction: a phone number before a full stop is masked (G7-F3, `guard/redact.py`).** <!-- C15 K70 --> All four PHONE patterns now end with `(?!\w|\.\w)`. A number followed by a full stop and then a space, the end of the text, `)` or `,` is masked up to the stop (`call 415-555-0132.` becomes `call <PHONE_1>.`; `call +44 20 5550 1234.` becomes `call <PHONE_1>.`). A stop followed by a letter, digit or `_` still ends no phone (`1732095071.123`, `1234567890.tar`). - **Redaction: overlaps reach a fixed point (G9, ticket E10; `guard/redact.py`, `guard/runmap.py`, `defaults.py`).** <!-- C16 K72 K5 K78 --> Each sweep reads the text back with the map's values put back and masks a value found across a placeholder. It repeats until nothing changes, at most `defaults.SPELLED_MAX_PASSES` (4) passes. A sweep still changing then is refused (`InputTooLarge("SpelledNotSettled")`). Values `abcdefgh` and `efghijkl` in `abcdefghijkl` are now masked whole. The read-back reaches `defaults.SPELLED_READBACK_REACH` (1,024) characters into a run of placeholders; a longer value is found by an anchored check. Unions of overlaps are limited to `defaults.SPELLED_MAX_UNION_CHARS` (1,000,000 characters) per call (`InputTooLarge("SpelledUnionTooMuch")`). - **Model gate: the safety net reads pieces beside a key and decoded spellings (G13, G13b; `guard/runmap.py`, `guard/model_gate.py`).** <!-- C17 K3 K12 K78 K79 K80 K85 --> The net also refuses a call when a piece of 4 or more characters of a known secret touches a key of the map, as the value's start or end (`hunter2-<SECRET_2>`). #### Changed

- **Redaction: base64 text is decoded and read (G4 Phases 0-3; `guard/runmap.py`, `guard/redact.py`, `defaults.py`).** <!-- C18 K37 K82 --> `redact_text` now decodes base64 runs of 12 or more characters (`defaults.B64_MIN_CHARS`) and searches the decoded text. A run whose decoded text holds a value the redactor finds is masked whole as the new kind `ENCODED` (`<ENCODED_1>`); the value found inside is entered in the run's map too. `secret is cGFzc3dvcmQ9aHVudGVyMnp6` becomes `secret is <ENCODED_1>`. Limits: at most 3 levels decoded; a unit over 65,536 characters is masked unread; more than 2,000 decodable units or 262,144 decoded characters per call are refused (`InputTooLarge`). Not decoded (stated limits, five pinned as strict expected failures): a blob glued to other base64 characters, split across fields, wrapped with a log prefix on each line, hex, base32, base85, gzip, quoted-printable, a decoded text under 90 percent printable, and an all-capital blob between angle brackets. A direct `redact()` or `redact_many()` call has no base64 step. Base64 whose decoded text holds no known shape stays readable.
  LEAD DECISION (G4 L24-L28, L-B8): defaults built; no fallback for padded blobs.
  NOTE: the host-name half (Phase 4) is NOT merged; do not write a host-name line.

- **Redaction: the plain copy of a secret stored with punctuation at its ends (G12, G12b; `guard/redact.py`).** <!-- C19 K77 K84 --> A SECRET value is now also registered without the characters at its ends that are not letters or digits, markup tags (`<b>`, `</b>`) and escaped `\n` `\r` `\t`. So `password=hunter22, hunter22` becomes `password=<SECRET_1> <SECRET_2>`; the second copy was readable before. The same for a leading bracket and wrappers such as `**hunter22**`. One secret then has two placeholders. No second entry is made for a "no value" word (`none!`), a placeholder-like core, or a value holding `‹` or `›`. Not fixed: punctuation inside the value (`password=hunter22,x` leaves a later `hunter22` readable), escaped edges such as `%0A` or `&quot;`, `<br/>`, and an all-capital `ADMIN_1`.
  LEAD DECISION (G12 6.1-6.7): defaults built.
  NOTE: G12c (fixes of the round 2 review) is not in fd1fb3e31.

- **Redaction: one shortcut in the base64 step (E22; `guard/runmap.py`).** <!-- C20 K37 --> When the text left after the base64 view holds only `<ENCODED_n>` placeholders, every stored original is ASCII, and none occurs in that text, the second `redact` call is skipped. Measured: output and map byte-identical on 2,345 inputs; the 262,144-character `_4155550132` shape went from 1.64-1.74 s to 0.97-1.09 s.

- **Redaction: text typed like the redactor's own output, and spelled placeholders (E9, E15).** <!-- C21 K43 K76 --> A SECRET value stays as typed, with no map entry, when it is made only of escaped `‹SECRET_n›` tokens, only of typed `<SECRET_n>` tokens, only of genuine placeholders of any kind (`password=<EMAIL_1> <IPV4_1>`), or of a cut-off start `<S` to `<SECRET_12`. A placeholder written as `&lt;TENANT_1&gt;` or `%3CTENANT_1%3E` can come back decoded from `redact_text` when its digits are not masked. No value stands behind it (the map has no such key), and a restore gives nothing. Accepted: a probe found no case in which this returns a real value; that is a probe, not a proof. Pinned by `tests/test_runmap_e15_placeholder_spellings.py` (15 cases).
  <!-- C12 K53 --> The class of 30 code points changed when the look-alike scan was ported onto the fold. They are 20 code points (dashes and the minus sign), 6 quotes, 3 slash look-alikes (U+2215, U+2571, U+29F8) and the replacement character U+FFFD. Each has a "Q9" deliberate code break in `tests/redact_mutants.py` and a killing test in `tests/test_redact_g3_port.py`.

- **Correction of a stated limit (K5-core, CHANGELOG line 29).** <!-- C22 K46 --> A quoted secret value that holds spaces (`password="my secret phrase"`) is masked whole. An unquoted value is masked only up to the first space or `;` (`password=my secret phrase` leaves `secret phrase`). A `,` or `&` inside a key=value value does not end it; then the value's plain copy can stay readable (C19).
