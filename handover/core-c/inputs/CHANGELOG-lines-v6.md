## Upgrade steps

- **Model gate: budgets, a wider safety net, and a RunMap-only bind (`guard/model_gate.py`, `guard/runmap.py`).** <!-- C1 --> `ModelGate.bind(..., mapping=)` now accepts only a `runmap.RunMap` or `NO_MAP`; a plain dict, or a copy made with `dict(run_map)`, raises `TypeError`. An empty `RunMap` is accepted and the audit row says `map_enforced_empty`; the gate cannot tell the run's own map from another `RunMap`. <!-- C2 --> One budget covers the characters, the steps and the time of one chat call: at most 32,768 steps, a CPU deadline of `defaults.REDACT_BUDGET_S` (6.0 s) that is passed into the redactor's sweep, and a monotonic-clock deadline that `EnforceBudget.check` reads between values; past any of them the call is refused with the new code `mask_budget_exceeded` (`MaskBudgetExceeded`, a subclass of `UnmaskedInput`). One regex scan of one stretch of text inside the redactor cannot be interrupted; the gate's own note gives about 7 s for 262,144 characters of `a` with 500 planted values (not re-measured). At most 4,096 held-back values and 20,480 entries are accepted per call; before, 256 held-back values refused every later call of a run. <!-- C3 --> The safety net (`held_value_left`, code `held_value_left`) now checks every known secret of 4 or more characters in each enforced chunk, not only the held-back ones, and a secret hidden in a made-up `<NAME_1>` token that is not a key of the map refuses the call. A secret that spans a fixed framing word is cut by the word and passes as written (stated limit, pinned). <!-- C4 --> `framing_refused` also fires when a known secret is a piece of a name in the call's `tools` list; a name that is in that list stays exact in the assistant line and the marker. A planted value equal to a tool name refuses every later call of the run. <!-- C5 --> A KeyboardInterrupt in the enforce step, in `worst_case`, in `reserve` or in the instant after it writes an audit row (`call_interrupted` or `reserve_interrupted`) and passes on. A `cost_usd` that is `-0`, has an absurd exponent, or raises on read is `cost_unknown`: the reply is returned and not settled. The install test now names the judge's four call points and holds five strict expected failures until the gate is installed.

- **Redactor: the pattern passes run to a fixed point; refusal words (`guard/redact.py`, `defaults.py`).** <!-- C6 --> After the first pass, `_Redactor.settle` repeats the table and the sweep over the strings the previous round changed, at most `_SETTLE_ROUNDS` (4) rounds, so a call makes up to 5 rounds; a call that still changes a text in round 4 is refused with `RedactionError("NotSettled")`. The CPU deadline is read before every round and inside every sweep, finder build and written-forms scan; it is NOT read inside one pattern pass over a string or in the loop over the strings of one round. <!-- C7 --> A hostile text can force a refusal of the whole document (fail closed, nothing shown): `InputTooLarge("SpelledWorkTooMuch")` past `defaults.SPELLED_MAX_WORK` (4,000,000 units), `InputTooLarge("SpelledMemoryTooMuch")` past `defaults.SPELLED_MAX_CHARS` (1,000,000 characters of written forms in one call), `InputTooLarge("InputTooLarge")` for the time or size limit. <!-- C8 --> Stated limits, pinned by tests: a written form completed only in a later round, and two compound values that overlap as raw text, leave the literal start or end of one readable (`abcdefgh` and `efghijkl` in `abcdefghijkl` become `<S1>ijkl`). The memory of the finder for very large plain values is not limited (eight 260,000-character values measured 956 MB; escalation E14, no ticket yet).

- **Redaction of glued values, G8 (`guard/redact.py`).** <!-- C9 --> An IPv4 address, a UUID, a phone number written with `+`, and an IBAN beside `_` are masked when a letter or `_` is glued to them (`10.20.30.40_x` becomes `<IPV4_1>_x`), the glued text left outside the placeholder. To be safe, some look-alikes are masked too: four-part version numbers glued to a word and long digit runs after an underscore (`card_4242424242424242` becomes `card_<PHONE_1>` and is kept in the run's map as a phone number). <!-- C10 --> Not masked, by design (pinned): a phone number or card number written as one run of digits with a letter beside it (`x4155550132`, `telephone4155550132`, `x4242424242424242`); a phone number directly before a full stop (`call 415-555-0132.`, and `call +44 20 5550 1234.` keeps its last group); an IBAN with a letter or digit before it, or inside a file name, path or key (`acct_iban_DE89...`, `xDE89...`). LEAD DECISION (G8 L-D13, L-D15, L-D17): the code has the defaults: no full-stop mask, the short-word IBAN rule, no card-number check. <!-- C11 --> A UUID or a number of 10 or 11 digits set off by `_` inside a long opaque token is cut out and a remainder under 40 characters stays readable (the whole token was masked before; limit L15, rows OL1 to OL7). LEAD DECISION (E16): the code has the default, accept the limit.

- **Redaction: text typed like the redactor's own output, and spelled placeholders (E15, Q9).** <!-- C12 --> A placeholder written as `&lt;TENANT_1&gt;` or `%3CTENANT_1%3E` can come back decoded from `redact_text` when its digits are not masked; no value stands behind it (the map has no such key) and a restore gives nothing. Pinned by `tests/test_runmap_e15_placeholder_spellings.py` (15 cases); resolved as an accepted fail-safe. <!-- C13 --> The class of 30 code points changed when the look-alike scan was ported onto the fold: 20 dashes and the minus sign, 6 quotes, 3 slash look-alikes (U+2215, U+2571, U+29F8) and the replacement character U+FFFD. Each has a "Q9" deliberate code break in `tests/redact_mutants.py` and a killing test in `tests/test_redact_g3_port.py`.
