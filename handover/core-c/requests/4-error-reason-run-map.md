Wanted: redact error text with the run's map in ONE pass (no throw-away map, no second pass). The own-output rule in `redact._mask` (a value made only of escaped look-alikes is left alone) makes the current double pass harmless for junk entries, not for this gap. Needs a test: a secret in an error text is masked in a later tool result of the same run.
