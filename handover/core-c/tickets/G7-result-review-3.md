Design verdict: no leak found in `settle`; the linear trie scan has a real cost and deadline problem and its stated linearity does not hold. 0 Blocker, 2 Major, 2 Nit.
- M-A The spelled-form scan is not linear and its deadline can be skipped (redact.py:1660-1695, 1672, 1127): per token it walks every registered offset (cost about tokens x distinct offsets x walk depth); planted: about 500 secrets `password=a^k<SECRET_1>Z` (k = 1..500, about 125 KB) plus about 130 KB of `a^500<SECRET_1>` repeated, followed by something other than `Z`: about 3e7 dict lookups; the ticket (item 8) and the `_spell` docstring say "independent of the number of forms": false. The deadline check at :1672 is after `if by_offset is None: continue`, so tokens without forms skip it (a plain `<EMAIL_9>` at n = 0, 256, 512 means it never runs); the first sweep in `redact()` (:952) and `redact_many()` (:2038) passes `deadline=None`, so forms registered by `find` in that call are scanned unchecked (defaults.py:59 admits it; the ticket item 7, the wording and the `settle` docstring "inside every sweep" present it as bounded); later rounds repeat the scan on every changed string up to 4 times. Fix: check the deadline per token before the `continue` or per N walk steps; cap offsets per first token and forms registered per first token; or verify forms by prefix comparison; pass a deadline into the first sweep; add a hostile-map test (many offsets, one token) beside the 5,000-forms test.
- M-B Overlap rule: the first matching offset wins, not the leftmost or longest (:1674-1691; docstring says "left to right, the longest form at a position"): F1 `<S_1>ab` (offset 0) and F2 `xyz<S_1>` (offset 3), text `xyz<S_1>ab`: F1 matches first, `xyz` stays readable; a form with a later first token is skipped if an earlier form consumed the span (`start < last`). Fix: collect candidate (start, length) pairs, sort by earliest start then longest, take non-overlapping; or document and test the real rule.
- N1 A ghost entry can revive on a same-value reissue (:1681; the guard `mapping.get(placeholder) == full` does not check the form's own tokens still mean what they meant): contrived corruption not leak; ghosts never pruned. Fix: delete the `_spelled` entry in `_rollback`.
- N2 Stale or imprecise claims: defaults.py:34-36 Windows "7.2 s end to end" predates the deadline and exceeds the 6 s budget (that machine would now be refused; "its unit is larger" gives no number); defaults.py:37-39 and the ticket report 4.8-4.95 s for `curl -u ` against 6.0 s: a machine about 25% slower refuses that text (InputTooLarge; fail closed; a legitimate 262 KB document resembling it is lost: say so); the `settle` docstring "checked inside every sweep" is false for the first sweep.
