### 3.1 What `redact_text` does to the map
All work (485-523) runs on copies: `redact()` copies the map (`self.mapping = dict(mapping or {})`, redact.py:897) and returns a new one;
the loop over views keeps the newest in the local `current` (518). After success, 524-525 empty the caller's dict in place and refill it
from `current`: same object, with a new placeholder for every value found. On an exception (520-523) the map is untouched. No argument
turns the write off.
### 3.2 A check-only variant MUST
- read the text exactly as `redact_text` does (`_within_cap`, `_clean`, `fits_after_nfkc`, `_views`, `_decoded_masks`, `_keep_earlier_masks`,
  the budget, and after P2d-1 the fold scan), starting from the caller's map so a value already in it counts as known;
- fail closed: `InputTooLarge`, `TooDeep`, `RedactionError` mean "not clean";
- decide by the rule of line 517: the map would grow (`current != mapping`) OR the result holds more placeholders than the input
  (`_held`, 417). Map growth alone misses a further copy of a known value, which `sweep` masks without a new map entry.
### 3.3 It MUST NOT
- run 524-525 or write the caller's map in any way (plan-v3.md:37: the mask step "never creates a new map"; ORDERS.md:47);
- return or log the masked text, the found values or the would-be map; or use `out != text` as the test (`_clean`, NFKC, `strip_ansi`
  and `neutralise` change text without masking anything).
- OPEN: `mapping.redact_cache`. `_Redactor._build` writes `cache["map"]` and `cache["state"]` (redact.py:1007-1009), so the would-be map
  stays on the `RunMap` object. Results are not affected (the cache is used only when `cache["map"] == mapping`, redact.py:915), but it is a
  write to the caller's object; `_cache=None` avoids it at the cost of one rebuild per call.
### 3.4 Existing functions that check without mutating: none does this job
`runmap.has_placeholder` (runmap.py:617) is pure but only finds `<KIND_n>`. `runmap.storable_original` (runmap.py:244) checks ONE stored
original against `_SECRET_PATTERNS` (235). `redact.redact` (redact.py:862) leaves the caller's map alone (copy at 897) but returns the
masked text and map, runs no decoded views and has no cap; runmap.py:483-484 forbids a bare `redact()` outside runmap. Callers that pass
a throw-away `{}` (judge.py:71, bedrock_guardrail.py:98, evals.py:63, tools.py:1005) redact, they do not check. WARDEN's check
(`leaked_kinds`, `data_leaks`) is "Not ported" (approvals/gate.py:5-7).
