## Words used in this ticket (defined once)
- **old error-text path**: a place on today's main where the program turns an exception into text by printing its message (after a pattern cleaner, or with none) instead of building a diagnostic. The **diagnostic** is the small record of closed parts that P5a builds (code, step, file:line, closed facts) and P5b3 wires in.
- **pattern cleaner**: a function that masks the secrets it recognises by their shape (for example `guard/runmap.py` `safe_head`). It cannot recognise a person's name or an invoice line.
- **backstop**: the one pattern cleaner use that stays, for text that is not an exception message (stored raw model output in `k1b/loop.py` `run_case`). It is NOT the protection for error text; the diagnostic is.
- **leftover**: an old error-text path that is still in the code when P5b4 has merged.
- **pin test**: a test that fails if something removed comes back. **plant test**: a test that copies `src/hadavin_sdk` to a temporary folder, plants one edit (a changed line or a new file), and checks that the checker reports exactly the planted finding (or, for a negative plant, nothing new).
- **equality pin**: a test that compares a measured set with a written set and fails on any difference, in either direction (an extra entry or a missing one).
- **qualified name**: the dotted path of the `def` and `class` blocks around a line, outermost first, for example `serve.Handler` or `Helper.run_case`.
