## Words used in this ticket (defined once)
- **old error-text path**: a place on today's main where the program turns an exception into text by printing its message (after a pattern cleaner) instead of building a diagnostic. The diagnostic is the small record of closed parts that P5a builds (codes, step, file:line, closed facts) and P5b3 wires in.
- **backstop**: the one pattern cleaner that stays for text that is not an exception message (stored raw model output). It is NOT the protection for error text; the diagnostic is.
- **leftover**: an old error-text path, or an interim allowance added by P5a-P5b4, that is still in the code when P5b4 has merged.
- **pin test**: a test that fails if something removed comes back. **plant test**: a test that copies the source to a temporary folder, adds one forbidden line, and checks that the pin test's checker reports it.

This package removes what is left, pins both facts with tests, and tells operators in one page what they now see.
