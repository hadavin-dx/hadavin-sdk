## Words used (one meaning each)
- **demo**: one of the four demo repositories of amendment A7: apexc, dealdesk, intake, refunds. Each is its own git repository.
- **pin**: the one core commit a demo says it is built against. Its places: the `hadavin-sdk @ git+...@<sha>` line in `pyproject.toml`, the same in `uv.lock`, `core_commit` in `core_copies.json`, and any other file R0b finds naming the old pin as a pin (refunds `CORE_COPIES.md:4-5` says `gate_rules.md` also pins it; that file is not in `handover/`, UNVERIFIED). **re-pin**: move the pin.
- **copy**: a core file held inside a demo as a byte copy (some import lines rewritten), listed under `files` in `core_copies.json`. **snapshot** (`pr_snapshot`): the unmerged core commit a copy was taken from.
- **seam**: the one demo module through which the rest of a demo reaches the fold: refunds `textnorm.py`, dealdesk `textnorm.py`, intake `textfold.py` (and `coreredact.py` for the redactor). apexc has no seam: `normalise.py:9` re-exports `fold, squeeze`, and its kept egress copy imports the fold directly.
- **look-alike check**: a demo decision that treats two strings as the same when one uses look-alike letters (for example a Cyrillic "а" for a Latin "a").
- **DENY site**: a fold call whose result can only refuse something (a match blocks). **ALLOW site**: a fold call whose result can let something through (only one verdict passes). Today there is one ALLOW site, dealdesk `guards.py:84-90`.
- **FINAL**: the core `main` commit at the start of the sitting, after every v1 row except P8a, P8b and P8c is merged. Written `<FINAL>`: a placeholder, never a real value in this file.
- **sync check**: the studio tool `tools/core_sync_check.py` on the lead's laptop; nobody here has read it. **copy test**: the test inside each demo that hashes the demo's own copies (named below).
- **blocked demo**: a demo whose re-pin stops at a stop rule. Recorded as "P8a-<demo> blocked" with the rule and the output; the other demos go on.
