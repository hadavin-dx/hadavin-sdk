## Words used (one meaning each)
- **demo**: one of the four demo repositories named in amendment A7: apexc, dealdesk, intake, refunds. Each is a separate git repository, not part of `hadavin-sdk`.
- **pin**: the one core commit a demo says it is built against: the `hadavin-sdk @ git+...@<sha>` line in the demo's `pyproject.toml` and `uv.lock`, and `core_commit` in its `core_copies.json`. **re-pin**: move the pin to a newer core commit.
- **copy**: a core file held inside a demo as a temporary byte copy (some import lines rewritten), listed under `files` in `core_copies.json`. **snapshot** (`pr_snapshot`): the unmerged core commit a copy was taken from.
- **FINAL**: the core `main` commit at the moment P8a starts, after every v1 row except P8a, P8b and P8c is merged. Written as `<FINAL>` below (a placeholder, never a real value in this file).
- **sync check**: the studio tool `tools/core_sync_check.py` (in the studio repository on the lead's laptop, not in this repository). **copy test**: the test inside each demo that hashes the demo's own copies (named below).
