## Words used in this ticket (one meaning each)
- **environment read**: code that reads, writes or lists the process environment variables. The closed list is in field "Interface", item L1.
- **secrets kind**: the `secrets` capability in `TABLE` (`backends/table.py:386`), and the modules its factories name.
- **secret holder**: a module that holds a secret provider or the executor. Today that is the set `SECRET_HOLDERS` in `tests/test_repo_rules.py:131-142`.
- **wiring**: code that builds backends from a config and hands each factory a bound `resolve`. Today that is `app.py`, `backends/factory.py`, `backends/platform_secrets.py`, `backends/builtin.py`, plus `cli.py` and `k1b/audit_sink.py` (facts below).
- **ambient identity** (also called "workload identity"): a cloud SDK signs in with whatever its default chain finds: environment variables first, then files, then the machine's attached role. Examples are the AWS default chain, Azure `DefaultAzureCredential` and Google Application Default Credentials. Our code passes no credential to the SDK in that case.
- **identity** of a kind: the principal the kind acts as toward an outside system. **rights** of a kind: the operations it needs on that system, written as plain text.

## Decisions taken in this ticket (cut surface, order 7(3))
- **D1 Ambient identity is pinned, not rewritten.** F5 asks the lint to check that "the llm and cloud backends pass credentials explicitly (no implicit environment chains)". The lint checks three things:
  - every explicit-key SDK constructor passes `api_key=` (not the literal `None`);
  - every ambient-identity constructor sits only at one of the 13 pinned sites, each tied to its (capability, kind) with a reason;
  - a new site, a moved site or a stale entry fails.
  It does NOT rewrite the 13 sites to a narrower credential class. That would be 13 behaviour changes on unverified cloud kinds, and none can be run here. The honest limit, in plain words: **these SDKs look at environment variables before the machine's role. A key left in the environment of a pilot or prod process is used before the attached role, and no v1 code stops that.** This is v1.1 row V1. PENDING LEAD 2 (owner-visible).
- **D2 Identity and rights live in a new data module `backends/kind_identity.py`, not as `Entry` fields.** Adding two keyword arguments to all 31 `Entry(...)` calls would rewrite most of `TABLE`, a hot file for P5b3, P5b4, P5c and P6a. One new file conflicts with nobody. The contract test joins the two tables and fails on any kind missing from either. PENDING LEAD 3.
- **D3 `demos/` is out of the lint in v1.** Demos are dev-only demonstrations; P8a re-pins them. The evidence prints their reads (report only). v1.1 row V2.
- **D4 No fallback to `HADAVIN_MIGRATE_DSN`.** With no `migrate_credential_ref`, `migrate` refuses, and the message names the new field and says the variable is no longer read. Reading the variable only to warn would itself be the banned read. This is a semantic change for operators (Rollback).
- **D5 The test files keep the plan's names:** `tests/test_env_lint.py`, `tests/test_secrets_import.py`, `tests/test_kind_identity.py`. `tests/test_repo_rules.py` and `tests/test_lockin_guard.py` are imported from, never edited.
