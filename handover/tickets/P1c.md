New private `_b64_view(text: str, current: dict[str, str], cache, started: float) -> tuple[str, dict[str, str]]`. **Behaviour, exactly:**
  1. **Where it runs.** Inside the existing `try` of `redact_text` (`:487-523`), at two places. (a) On the input, after `neutralise` (`:489-490`) and BEFORE the `scan` gate and pass one (`:491-494`): pass one and `_decoded_masks` then read the step's output and map. (b) On each view, after `_keep_earlier_masks` (`:514`) and before that view's `redact` (`:515`). It is never behind the `scan` gate, because a base64 token is plain ASCII with none of `\ % &`.
  2. **Candidate (exact).** `re.finditer` of `[A-Za-z0-9+/_-]{N,}(?:(?<=[A-Za-z0-9+/_-]{60})\r?\n[A-Za-z0-9+/_-]{4,})*(?:=|%3[dD]){0,2}`, where N = `B64_MIN_TOKEN_CHARS` (16, order 64). This is the maximal run over the UNION of both alphabets. A line break continues the run only after a line of 60 or more alphabet characters (MIME wraps at 76, PEM at 64). Trailing padding, written `=` or `%3D`, belongs to the run. Any other `=` ends a run (`key=<token>`).
  3. **Decode.** Remove line breaks and padding; translate `-` to `+` and `_` to `/`. For each start s in 0, 1, 2, 3: take the run from s; if its length mod 4 is 1, drop the last character, otherwise complete the padding; skip it if shorter than N; `base64.b64decode(piece, validate=True)`. Four alignments cover a glued prefix of any length and delimiter exactly. Only `binascii.Error` is caught, and only to mean "not this alignment".
  4. **Read as text (the `strings` rule).** Bytes are decoded `utf-8` with `errors="replace"`, and also `utf-16-le` with `errors="replace"` when at least half of the odd-position bytes are 0 (PowerShell `-EncodedCommand`; PL8). Every character that is not `isprintable()`, or is U+FFFD, cuts the text, except `\t\n\r`. Pieces with at least `B64_MIN_FRAGMENT_CHARS` (6, the shortest maskable value `a@b.co`) non-space characters are kept. A run with no piece is left as it is.
  5. **Redact and mask.** T = the run's pieces (all alignments and readings, de-duplicated, joined by `\n`); T = T + `\n` + `fits_after_nfkc(canonical(undo(T)))`; T = `neutralise_untrusted(T)`, ALWAYS, whatever `neutralise` the caller gave (decoded bytes are untrusted by origin; this is done after the view, so `&lt;...&gt;` cannot come back as a placeholder). `again = redact(T, mapping=current, _cache=cache)`, the plain redactor. If `again.text` holds a placeholder (after neutralising, each one was placed by this call), the run's SPAN is replaced by those placeholders, de-duplicated, in order, and `current = again.mapping`. No decoded character is ever emitted. The output is built with `re.sub` over the runs and a per-call memo, so the same run is computed once and a copy inside a longer run is judged as part of that run. Secret kinds stay unstored (`STORED_KINDS`, `runmap.py:30`, `defaults.py:108-122`). A stored kind restores to the DECODED spelling (`RedactionResult.restore`, `redact.py:855`), and the CHANGELOG says so.
  6. **Bounds, each with its reason.** Depth 1: pieces are never searched for runs again (order 64). No recursion: only `redact`, `canonical` and `undo` are called, never `redact_text`. At most one `redact` pass per run; runs are disjoint and at least 17 characters including their boundary, so a text has at most `MAX_REDACT_CHARS / 17` passes. Each run costs 4 linear decodes. There is no maximum token length and no candidate count (PL2, PL6): the text cap already bounds both. `REDACT_BUDGET_S` is checked before each pass (`InputTooLarge`). A call therefore takes at most the budget plus one pass (`defaults.py:45-48`).
  7. **Fail closed.** Any other exception reaches the existing `except Exception` (`:522-523`) and becomes `RedactionError`. `TooDeep` from `undo` and `InputTooLarge` are re-raised (`:520-521`). In every case nothing is sent.
  8. **HOSTNAME (exact).** The private-suffix alternative of `redact.py:391` becomes `(?:corp|lan|intranet|intra|localdomain|home\.arpa)(?:(?:\.L){1,126}(?![\w-]|\.\w|\()|\b)`, where L is the existing label `[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?`. The tail ends only at the end of the dotted chain (never inside a label, never in front of `(`); otherwise today's match (the suffix only) applies. 126 labels is the DNS limit. `internal|local` and `_KEPT_HOST` (`:809-811`) are unchanged. Names ending `.svc.cluster.local` stay kept and `<label>.corp.<region>.compute.internal` stays masked, both as today (H5).
