  2. **Candidate (exact).** With A = `[A-Za-z0-9+/_-]`, N = `B64_MIN_TOKEN_CHARS` (12) and J = `B64_MIME_JOIN_CHARS` (60): `re.finditer` of `(?:A{N,}\.){0,2}A{N,}(?:(?<=A{J})\r?\nA{2,}(?:=|%3[dD]){0,2}(?=\r?\n|\Z))*(?:=|%3[dD]){0,2}`. One match is one UNIT. A unit that is the name inside a genuine placeholder (`<` before it, `>` after it, and it fullmatches `[A-Z][A-Z0-9]*_[0-9]+`, the `PLACEHOLDER` grammar `runmap.py:31`) is skipped: at N = 12, `HIGHENTROPY_1` would otherwise be decoded (round-3 fact 6). Up to three dot-joined segments of N or more characters are one unit (the JWT compact form, RFC 7519), so a token's header and signature are masked with its payload. A line break continues the last segment only after a line of J or more alphabet characters (MIME wraps at 76, PEM at 64), and only with a WHOLE line of 2 or more alphabet characters (one group with padding, `bw==`, joins; a prose line does not). Trailing padding (`=` or `%3D`) belongs to the unit; any other `=` ends it (`key=<token>`).
  3. **Decode.** The unit is split at `.` into segments; each segment loses its line breaks (`\r`, `\n`) and padding, and `-` becomes `+`, `_` becomes `/`. A segment of at most `B64_WINDOW_CHARS` (65,536) characters is one window. A longer one is cut into windows of `B64_WINDOW_CHARS` characters, each starting `B64_WINDOW_CHARS - B64_WINDOW_OVERLAP` (54,612, a multiple of 4) after the previous one, the last one ending at the segment's end; `B64_WINDOW_OVERLAP = 4 * -(-CUT_MARGIN // 3)` (10,924), so a value of up to `CUT_MARGIN` (8,192) BYTES lies whole inside one window. Every window is decoded; nothing is refused for its length. Per window, for each start s in 0, 1, 2, 3: take the window from s; length mod 4 = 1 drops the last character, otherwise padding is completed; skip it if shorter than N; `base64.b64decode(piece, validate=True)` (the module does `import base64`). Only `binascii.Error` is caught, meaning "not this alignment".
  4. **Read as text for SCANNING.** Bytes are decoded `utf-8` with `errors="replace"`. Every character that is not `isprintable()`, or is U+FFFD, cuts the text, except `\t\n\r`; pieces with at least `B64_MIN_FRAGMENT_CHARS` (6) non-space characters are kept (the `strings` rule). **Deleted reading:** when the decoded text holds no U+FFFD (it was valid UTF-8), the text with every cut character DELETED is kept too, if it has 6 or more non-space characters; this reads one junk control byte inside a value and UTF-16LE of ASCII. Without the UTF-8 condition it over-masks random binary (prototype at N = 12: 9 of 20,000 tokens). A window with no piece adds nothing.
  5. **Redact and mask.** Per window: P = its pieces, de-duplicated, joined by `\n`; `_within_cap(P)`; `fits_after_nfkc(P)` (BEFORE any normalisation: `undo` runs NFKC first, `runmap.py:158`); U = `fits_after_nfkc(undo(P))`; T = P + `\n` + `fits_after_nfkc(canonical(U))`; `_within_cap(T)`; T = `neutralise_untrusted(T)` ALWAYS, whatever `neutralise` the caller gave; the budget check of item 6; `again = redact(T, mapping=current, _cache=cache)`; `current = again.mapping`. If any window of the unit leaves a placeholder in `again.text` (each was placed by this call), the unit's SPAN is replaced by those placeholders, de-duplicated, in order. **Nothing decoded is ever written back (PL1):** at each unit's span the output receives the original characters unchanged or this call's placeholders only (B27, M19). The output is built with `re.sub` over the units. Secret kinds stay unstored (`STORED_KINDS`, `runmap.py:30`; `storable()` filters at storage, the in-call map holds them). A stored kind restores to the DECODED spelling (`RedactionResult.restore`, `redact.py:855`); the CHANGELOG says so.
  6. **Bounds, each with its reason.** Depth 1: pieces are never searched for units again (order 64). No recursion: only `redact`, `canonical` and `undo` are called. One pass = one `redact` call on one T (at most `MAX_REDACT_CHARS`, 262,144) or pass one. `REDACT_BUDGET_S` (6.0 s) is checked before EVERY pass: inside the unit and window loop, before pass one (new) and before each view (as today).
