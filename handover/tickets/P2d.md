## Words used in this ticket (defined once)
- **redactor**: `guard/redact.py` `redact()`: it finds protected values (keys, e-mail addresses, card numbers, account numbers and so on, called **patterns** here) in text and replaces each with a **placeholder** such as `<EMAIL_1>`; the map placeholder-to-value is `RedactionResult.mapping`. **choke point**: `guard/runmap.py` `redact_text()`, the one function every production caller goes through (`guard/producers.py` lists 16 producers; `tests/test_k5_producers.py` enforces it).
- **look-alike**: a character that looks like another one (Cyrillic "a" for Latin "a", a full-width letter, a digit of another script). **fold** (`guard/textnorm.py` `fold`, from P1a): turns text into a form where look-alikes, invisible characters and accents are gone.
- **fold scan**: the second scan that PR #50 adds to `redact.py`: for a line with non-ASCII characters it also runs the patterns on the folded form of the line and, if the fold shows a protected value the line itself did not, masks it. **in place**: only the value is replaced, the rest of the line stays as written. **withhold**: the whole line is replaced by the fixed note `FOLD_NOTE` plus the placeholders of the hits. The folded text is never shown.
- **written spelling**: the characters of a value exactly as they stand in the text the caller gave (`josé@exemple.fr` with the accent). **folded spelling**: what the fold makes of it (`jose@exemple.fr`). **written slice**: the written spelling cut out of a line by position.
- **alias index**: `_Redactor.alias`, a dict inside the redactor, folded spelling to placeholder, for placeholders whose stored value is a written slice that differs from its fold. It is internal: it is not an attribute of the result, not in `mapping`, not in a cache key (Interface).
- **view**: a decoded or normalised copy of the text that `runmap.redact_text` scans in stage 2. **stage 1 / stage 2**: inside `redact_text`, stage 1 is the first `redact()` call, on the text itself; stage 2 is a `redact()` call for each view. A view's text REPLACES the output if EITHER clause of `runmap.py` line 519 at `748849c` holds: `again.mapping != current` (the view's call changed the map) OR `_held(again.text) > _held(out)` (`_held`, line 415, counts placeholders: the view's text holds more of them than the output; V27).
- **budget**: `defaults.REDACT_BUDGET_S`, 6.0 seconds of work one `redact_text` call may use. **CPU time of the thread**: `time.thread_time()`. **wall time**: what a clock on the wall shows.
- **hole**: a text that this package knowingly leaves unmasked. Each hole has a closing package, a trigger and an owner.
- **UTS #39 / UAX #15**: the Unicode standards for confusable characters and for normalisation; P1's look-alike table is generated from UTS #39.
- **direct pass**: one run of the whole pattern table `PATTERNS` over one text. `defaults.py` (lines 45 to 48) says a single pass can take about 7 s on a hostile text. **bare call**: calling `redact()` itself, not through `redact_text`.
- **sweep**: `redact.py` `sweep` / `_sweep`: masks every other copy in clear of a value that is already masked. `_build` makes its rules from the values the run holds (and, after this change, from the alias keys).
- **raw output**: the `.text` that `redact()` returns, exactly as returned. A check on `fold(output)` is a check on a different text: `fold` drops tag characters and unassigned code points (V16), so a leak made of those cannot be seen there.
- **hidden-channel characters** and **`has_hidden_channel`**: exactly two classes, by P1's two rules (P1 rev 16, FROZEN; item "Signals (P1a)"): rule 1 is any tag character (the whole block U+E0000 to U+E007F); rule 2 is any variation selector other than U+FE0E and U+FE0F. Unassigned, private-use, control and other format characters are NOT a signal at all (P1: "UNBOUNDED in v1"). `has_hidden_channel` is a pure scan of P1a on the RAW text: linear, no clock, one answer for a whole text. An ASCII-only text can never make it True (tags and variation selectors are all outside ASCII).
- **look-alike check** and **`LookalikeCopy`**: `check_lookalike` (P2d-2; `guard/redact.py`) refuses the WHOLE text, and shows nothing of it, when a known value (one the run has masked or was handed) appears in it in another spelling. It raises `LookalikeCopy`, a public subclass of `RedactionError` (defined in `guard/runmap.py`; the message is the class name only). The hidden-channel hook of P2d-2 raises the same class. **count form**: the text with each genuine placeholder put back as one space, the original, one space. The exact rules are the design's (`handover/designs/lookalike-leak.md` draft 11, FROZEN, sections 5 to 8); this ticket carries them by reference and does not redesign them.
- **P1 rev 16 (frozen)**: P1 is final and FROZEN (lead order 16); this ticket cites it by ITEM NAME, never by line. Every P1 name used here (`fold`, `has_hidden_channel`, `scan_keyset`, `TextnormError`, `TextTooLong`, `NotText`, `REFUSAL_HANDLERS`, the constants) rests on P1's text, not on code, and is UNVERIFIED against code until P1a and P1b merge (`guard/textnorm.py` at `748849c` is PR #50's own `fold` with none of the P1a features: V15).
