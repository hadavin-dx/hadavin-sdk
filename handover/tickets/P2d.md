## Words used in this ticket (defined once)
- **redactor**: `guard/redact.py` `redact()`: it finds protected values (keys, e-mail addresses, card numbers, account numbers and so on, called **patterns** here) in text and replaces each with a **placeholder** such as `<EMAIL_1>`; the map placeholder-to-value is `RedactionResult.mapping`. **choke point**: `guard/runmap.py` `redact_text()`, the one function every production caller goes through (`guard/producers.py` lists them; `tests/test_k5_producers.py` enforces it).
- **look-alike**: a character that looks like another one (Cyrillic "a" for Latin "a", a full-width letter, a digit of another script). **fold** (`guard/textnorm.py` `fold`, P1a): turns text into a form where look-alikes, invisible characters and accents are gone. An attacker uses look-alikes to hide a value from a pattern.
- **fold scan**: the new second scan of `redact.py`: for a line with non-ASCII characters it also runs the patterns on the folded form of the line and, if the fold shows a protected value the line itself did not, it masks that value. **in place**: only the value is replaced, the rest of the line stays exactly as written. **withhold**: the whole line is replaced by the fixed note `FOLD_NOTE` plus the placeholders of the hits ("a line is withheld"). The folded text is never shown.
- **budget**: `defaults.REDACT_BUDGET_S`, 6.0 seconds of work one `redact_text` call may use. **CPU time of the thread**: `time.thread_time()`, the processor time the calling thread used (not the wall clock).
- **UTS #39 / UAX #15**: the Unicode standards for confusable characters and for normalisation; the look-alike table is generated from UTS #39 (P1).

PR #50 adds a scan on the folded line that closes these and never emits the folded text (a folded line could carry a live mention or link to a person). This package puts that scan into core, fixes one defect I found in it, bounds its work, and writes down honestly what it does not cover.
