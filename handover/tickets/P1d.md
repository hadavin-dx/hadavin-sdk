## Words used (defined once; one word keeps one meaning)
- **Choke point** = `guard/runmap.py::redact_text`. Every model-bound text, log text, tool result and approval card goes through it.
- **Raw input** `r` = `fits_after_nfkc(_clean(text))`, before `neutralise`. **Shown** = the string `redact_text` would return.
- **Work map** `work` = the dict pass one returns (`out, current = result.text, result.mapping`, `runmap.py:448`; `_Redactor.__init__` copies the caller's map, `redact.py:897`). **Commit** = the existing `mapping.clear(); mapping.update(current)` (`runmap.py:477-478`); before it the caller's map is untouched.
- **Views** of a text x = `Views(v0, a, b1, c, d)` from four cumulative steps (pseudocode); never shown. **Residue views** = per entry (round-10 readiness B1): **model entry** (`neutralise` is None): the views of `dropped(shown)`; **card entry** (`clean`, its joined pass, `card_text`): the views of `dropped(shown)` (the text returned) AND the views of `dropped(rr)`, the **raw family**, where `rr = redact(r, mapping=dict(work)).text` (a throwaway copy of the work map; the caller's map and `work` are unchanged). The raw family is needed because the card neutraliser runs before pass one (`runmap.py:441-443`) and removes escapes and controls (`gate.normalise` = `strip_ansi` then `strip_controls`, `gate.py:200-205, 125-136`), so in shown a backspace was never applied and an escape is gone or a space. **Learning views** (P1d-learn) are views of r on every entry.
- **Seed entries** = placeholders already in a card text (`channel._seeded`, originals starting `"\0seed"`).
- **Known value** = every original in `work` after the call's own masking, seed entries excluded, raw length at least `min_key_chars`. Card path: the map is call-local. Model path: the run map (at most `MAX_MAP_ENTRIES` = 2,000), so a value masked in an earlier call is known in every later call.
- **Every-copy value / standalone value** = the sweep's own rule (`redact._sweep`, `redact.py:1202-1220`; D9-1): an original whose kind is in `SECRET_KINDS` (PRIVKEY, JWT, APIKEY, GCPTOKEN, AZURESAS, WEBHOOK, URLCRED, BEARER, BASIC, SECRET, HIGHENTROPY, IBAN, CREDITCARD) and length at least 4 is masked at every copy; any other kind (EMAIL, HOSTNAME, NAME, UUID, PHONE and the rest) only where no ASCII letter or digit touches it; length under 3, digits under 6 and `_COMMON` words are not swept.
- **Dropped form** = shown with each genuine placeholder (in the map, not a seed) replaced by one space. **Put-back form** = each replaced by `" " + original + " "`.
- **Residue rule** = no known value is readable in a residue view (per kind, `_finish`) and the put-back count test passes; else the text is **withheld**.
- **Withheld** = default (`on_residue="withhold"`): `redact_text` returns `WITHHELD_NOTICE` and writes one operator log line. Raise mode (`on_residue="raise"`, card callers only): reason `residue` raises `runmap.LookalikeCopy`; reasons `size` and `error` raise what `redact_text` raises today (`InputTooLarge`, `TooDeep`, `RedactionError(<class name>)`), so card callers keep today's handling of those (round-8 M6). The model path never raises.
- **ref** = the run id (`run-` + 32 hex characters, `models.py:23-24, 91`), logged and used by P1d-c's `approvals show`.
- **KV literal** `KVS` = `"password=" + SV + " and " + SV_A + "**" + SV_B + "**"`: one text whose first half makes SV known (call-local map) and whose second half is a split copy. **KV twin** of a P1d-learn row = `"password=" + SV + " then "` + the row's insertion placed in SV: an insertion between K4 and K16 goes between SV_A and SV_B; a prefix stays a prefix; a look-alike or accent applies to SV_B's second character `x` (Cyrillic U+0445; U+0301 after it).
- **Client profile** = stage `pilot` or `prod` (`deferred.LIVE`). **Operator** = the person who runs the deployment.
- **Test legend:** fb = must FAIL on the base (post-P1d-a, post-P1b main); pb = passes on the base, output unchanged; inv = asserted after P1d (no leak, stated output), base outcome recorded but not gated; ow = accepted over-withhold, counted apart; measure = reported; new-surface = needs a name absent on the base; entry card = `clean`, summary = a plan input through `Approvals.request`/`summary`, model = `redact_text` default. **Property test** = a plain seeded loop (`random.Random(1)`, 500 cases, plus every row); no `hypothesis` (not a dependency, D10-5).

## The algorithm (pseudocode; no code)
```
redact_text(text, mapping, neutralise=None, *, on_residue="withhold", source="", ref=""):
  ctx = (_checked_source(source), _safe_id(ref), len(text), on_residue, card=neutralise is not None)
  try:                                                         # computes an outcome; nothing inside raises on purpose
    _within_cap(text)                                          # moved inside the try
    r = fits_after_nfkc(_clean(text))
    shown, work = <the existing redaction, unchanged, incl. neutralise and the second pass>
    # P1d-learn replaces this line by its learning pass, which calls _finish only when nothing was learned
    out = _finish(ctx, r, shown, mapping, work)                # shown (map committed) or _Held(...); never calls _withhold
  except (InputTooLarge, TooDeep) as exc: out = _Held("size" if InputTooLarge else "error", exc=exc)
  except Exception as exc: out = _Held("error", exc=RedactionError(type(exc).__name__))
  return _withhold(out, ctx, mapping) if isinstance(out, _Held) else out   # called once, outside the try

_Held(reason, work=None, exc=None)                             # private record of a withhold decision
_withhold(held, ctx, mapping):                                 # the only place that logs
  one log line (WARNING; INFO when source == "canary"); re-entrancy guard (RK11); thread-local last reason (P1d-gate)
  default mode, reason residue: commit held.work (masked values stay known; MAP-1)
  reasons size/error, or raise mode: mapping unchanged (MAP-2)
  raise mode: residue -> raise LookalikeCopy from None; size/error -> raise held.exc from None
              (size from max_work has no exc: raise InputTooLarge("work bound"))
  default mode: return WITHHELD_NOTICE

_healing_views(x) -> Views:   # cumulative; a skipped step is the identity; skips are exact (test_skips_are_exact)
  v0 = x
  a  = undo(v0)             only if the existing scan guard is true (`not x.isascii() or any(c in x for c in "\\%&")`)
  b1 = delete_carriers(a)   only if a holds "<", ESC, a C1 character or BS
       # _views.TAG.sub("", a); each BS deletes itself and the character before it (overstrike, ECMA-48 8.3.5;
       #   a BS with nothing before it deletes only itself);
       # then ANSI/CSI/OSC/C1 sequences and lone ESC deleted
  c  = textnorm.fold(b1)    only if b1 is not ASCII
  d  = delete_noise(c)      only if c holds * ~ backtick, a control, CR, LF, U+2028, U+2029    # underscore kept

_finish(ctx, r, shown, mapping, work):
  known = {o in work.values(): not seed(o) and len(o) >= min_key_chars}
  if not known: commit work; return shown
  # every `return _Held(reason, ...)` below goes back to redact_text, which calls _withhold once
  rv = _healing_views(dropped(shown))
  if ctx.card:                                              # neutralise was given (card entry): the raw family too
    rv += _healing_views(dropped(redact(r, mapping=dict(work)).text))
  every, single = split known by the sweep's rule (every-copy / standalone)
  scripted = {k in every: textnorm.value_scripts(k) non-empty}
  short = {k in every: scan key shorter than TN_MIN or empty}
  if (len(scripted) + len(short)) * sum(len(v) for v in rv.all()) > max_work: return _Held("size")
  finder = residue finder of (every - scripted - short)          # cache below
  folded = the folded finder of `single` (the sweep's, below)
  for v in rv.all():                                            # views outer, values inner
    for w in textnorm.scan_views_no_value(v):
      if finder.search(w): return _Held("residue", work=work)
    with textnorm.scan_cache():
      for k in scripted: if _holds(v, k): return _Held("residue", work=work)
    for k in short: if exact_fallback(v, k): return _Held("residue", work=work)
    if standalone_hit(folded, v): return _Held("residue", work=work)
  p = put_back(shown)                                           # conditional, BS-0 (q)
  for k in known: if count(k, p) > e(k): return _Held("residue", work=work)
  commit work; return shown
```
- **Residue finder:** for each every-copy known value with no script and a scan key of at least `TN_MIN`, its needles = `textnorm.scan_needles(v)` plus the keys of `scan_keyset(v)` that reach `TN_MIN`; one trie-regex from `redact._trie`, `_trie_regex`, `_compile_uncached` (not `re`'s cache, R371). **Cache:** in the CALLER's `mapping.redact_cache` when it has one (a `RunMap`), under the key `"p1d_finder"` as `(frozenset of the values, compiled re.Pattern, needle-to-value dict)`, rebuilt when the set differs (cost per call: BS-4 "call N" row); a plain `{}` (judge, guardrail, evals, grounded, `clean`'s call-local map) has none, so the finder is built per call (those maps hold only the call's own values). `test_finder_equals_scan_holds` (property, seeded loop): a hit for (text, v) iff `scan_holds(text=text, value=v)`.
- **`_holds(v, k)`** = `textnorm.scan_holds(text=v, value=k)`; on `ViewTooShort`/`EmptyView` the exact fallback.
- **`standalone_hit(folded, v)`:** the folded finder run on `fold1(v)` (below); a hit counts only where the characters before and after it in v are not ASCII letters or digits (the `_replace_standalone` rule, `redact.py:1223-1241`). So `ChristopherSmith`, `user_id=Christopher123`, `Christophersen` and F21 are not withheld for a known `Christopher` / `anna.m@example.org`.
- **`_edge_run`** is not built unless BS-0 (q) names a row that fails without it (P8-1); M29 then exists.
- **Put-back count** (`handover/designs/lookalike-leak.md` section 5 item 3): each genuine placeholder replaced by `" " + original + " "` in one pass; `count(k, p)` = non-overlapping count of each key of k in each key of p; `e(k)` = sum over put-back originals O of (O's placeholders put back) x (the smallest count of k's key over `scan_keyset(O)`; empty = 0); `count > e` = residue. It stays only if LK-JAMO-PB or a BS-0 (q) row fails without it; else the test, M10, M38, M63 and LK-JAMO-PB are dropped with the reason.
- **Card entry, raw family (round-10 B1):** the rows whose carrier the neutraliser removes are caught by the raw family: H11-kv, H12a-d-kv, H13-kv, H14-kv, H15c-kv, C05-kv, C06-kv, SUM-1..5 (ESC, BS, C1); CR rows (H16-kv) become LF in shown and are caught by both families; marker, entity, accent and look-alike rows by both. `rr`'s pass may add entries to its throwaway map; they are not known values. ### The case- and accent-insensitive sweep pass (`guard/redact.py`, round-8 readiness M-4)
- **`fold1(ch)`** (one character to one character or none): `unicodedata.normalize("NFD", ch)`; if the first character is followed only by combining marks (category Mn), keep the first; then `casefold()`; the result counts only if it is exactly one character, else the sentinel U+FFFF (never in a folded value). `fold1(s)` = the per-character map, so `len(fold1(s)) == len(s)` and position i of the folded text is position i of the text.
- **Which values:** each original o in `_rules` (rule every-copy or standalone, `redact.py:973-981`) whose `fold1(o)` holds no sentinel. A value with a sentinel (`ß`, a ligature) keeps only the exact, case-sensitive sweep (Non-Goal N6).
- **Build (once per map version, inside `_Redactor._build`):** `folded = {fold1(o): (n, placeholder, rule)}` keeping the lowest n (longest-first order of `_ordered`) when two originals fold alike; finders from the same `_trie`, `_split`, `_prefixes`, `_compile_uncached` code; values nested too deep for a finder go to a folded `_slow` list. The cached tuple `redact_cache["state"]` grows from 4 to 5 items (`_ordered, _rules, _finders, _slow, _folded`); its only reader is `_Redactor.__init__` (`redact.py:916-918`).
- **Pass (inside `_Redactor.sweep`, after the existing exact loop):** split the text that loop produced again with `_PLACEHOLDER.split` (`redact.py:817`, as at `:1029`); for each free segment (a part that is not a placeholder): offsets are positions in that segment; `fs = fold1(segment)`; candidates = the folded finders' hits plus `_slow` values found by `in`; for each candidate value, every occurrence in fs (`str.find` loop); for a standalone rule keep an occurrence only if `segment[i-1]` and `segment[j]` are not ASCII letters or digits; collect spans, keep the longest-first by n and drop any span overlapping one already kept; replace the kept spans in `segment` from right to left with the value's placeholder; rejoin the segments in order. A span never crosses a segment, so it never overlaps a placeholder already written. Exact copies are already placeholders, so the pass sees only other-case and accent copies.
- **Interaction:** `redact(..., _sweep_copies=False)` (`redact_many`'s first pass) skips it as it skips the sweep; `_replace_standalone` is unchanged; the 2,000-value map costs one more trie (BS-4 measures; S13-3). The same folded finders serve `standalone_hit` in `_finish` (the `_Redactor` of the call exposes them).
- Tests: H23, S13-1, MP-1..4, `test_folded_sweep_keeps_positions` (seeded loop: `len(fold1(s)) == len(s)`), `test_folded_sweep_never_inside_placeholder`.
