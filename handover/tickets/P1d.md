## The problem in plain words
Secrets and personal data are replaced by placeholders such as `<APIKEY_1>` before a person or a model sees a text. The redactor reads the text only as written, so `AKIA**IOSFODNN7EXAMPLE**` (asterisks make half of it bold), a terminal colour code, an accent, look-alike letters, another letter case or a line break inside a secret hides it, and the reader joins the pieces again. Also: the approval gate turns every `.` in an e-mail address or host name into `[.]` BEFORE the redactor runs, so these are never masked, and a password containing `&` shows the part after the `&`.

## Words used (defined once; one word keeps one meaning)
- **Choke point** = `guard/runmap.py::redact_text`. Every model-bound text, log text, tool result and approval card goes through it.
- **Pass-one text** `t` = the string the existing first pass redacts: `fits_after_nfkc(neutralise(_clean(text)))` (without `neutralise` when none is given). **Shown** = the string `redact_text` would return (after `neutralise`).
- **View** = another spelling of `t`, used ONLY to learn and to detect, never shown. The **deleting views** are v0 (`t`) plus the outputs of four cumulative steps a, b1, c, d (pseudocode): at most five views.
- **Seed entries** = the map entries a call starts with: placeholders already written in the text (`channel._seeded`, original starting `"\0seed"`).
- **Known value** (one definition, both paths) = every original in the map passed to `redact_text` after the call's own masking and learning, seed entries excluded, raw length at least the floor `min_key_chars`. On the card path the map is call-local (`clean` builds it from the text, FR2), so the card decision depends only on the text. On the model path it is the run map (at most `MAX_MAP_ENTRIES` = 2,000 values), so a value masked in an earlier call is known in every later call.
- **Learning pass** = the redactor's patterns run on the views (output thrown away; only the found originals kept) plus the AWS-style learning rule.
- **AWS-style learning rule** = the narrow rule that learns an unknown AKIA/ASIA key in another letter case or with ONE gap character inside; **gap set** = the three characters `&`, `.`, backslash (pseudocode).
- **Dropped form** = shown with each genuine placeholder (in the map, not a seed) replaced by one space. **Put-back form** = shown with each genuine placeholder replaced by `" " + original + " "`.
- **Residue rule** = after masking, no known value may be readable in any deleting view of the dropped form, no known value may be a prefix or suffix of a longer letter-and-digit run whose other side stays in the dropped form, and the put-back count test must pass. If any fails the text is **withheld**.
- **Residue finder** = one combined pattern of the needles of every known value with no script (pseudocode), built once per map version.
- **Withheld** = `redact_text` does not return the text. Default (`on_residue="withhold"`): it returns the fixed sentence `WITHHELD_NOTICE` and writes one operator log line. With `on_residue="raise"` (card callers only) it raises `runmap.LookalikeCopy`, for every reason (residue, size, error). The model path never raises.
- **ref** = the id written in the operator log line: an approval id where one exists, else the run id.
- **KV twin** of a row = the same hostile insertion placed inside a copy of a KNOWN value: the text first holds `password=<SV>` (SV enters the map), then a copy of SV carrying the row's insertion at the same place. It exercises the residue rule and the order of the steps without the learning pass.
- **Carrier row** = a row whose insertion needs a step that changes letters or digits (decode, deleting an escape's payload such as `0m`); it decides that step alone, because the scan key already ignores punctuation (FR1).
- **Client profile** = a configuration whose stage is `pilot` or `prod` (`deferred.LIVE`). **Operator** = the person who runs the studio's deployment for the client. **Tier C** = a core change on a redaction path (extended review, no round cap).
- **Test legend:** fb = must FAIL on the base; pb = passes on the base, output unchanged; pb? = decided by a run on the base at BS-0; ow = accepted over-withhold, counted separately; measure = measured and reported, not claimed; new-surface = the expected side needs a name absent on the base (see fail-before); entry card = `clean` (raise mode), model = `redact_text` default.

## Goals and Non-Goals
**Goals.** (G1) No known value is readable in any text `redact_text` returns or any card `clean` returns, for the families in the rows, up to the cap. (G2) One implementation at the one choke point; `clean`, `card_text`, documents, tool results, tool errors, logs and `redact_value` get it without a new call site. (G3) A text the rule cannot clear is withheld in a stated way (caller table); a request whose card is withheld is never saved and never approvable. (G4) False-withhold rate and H34 over-mask rate measured separately (BS-3). (G5) E-mail addresses and internal host names (`HOSTNAME` kind, FR4) are masked in cards.
**Non-Goals.** (N1) An unknown secret with no pattern. (N2) What a person types after the card is posted. (N3) S6 `tools._secret_forms` / `_scrub_layers`: P2d-2. (N4) A new endpoint or console. (N5) Exactness above the cap: above it the text is withheld; a document above it is refused as `document_too_large`. (N6) Unknown secrets of a token kind other than AKIA/ASIA in another letter case or with `.`, `&` or a line break inserted (case-sensitive kinds; H37d-e measure it). (N7) An unknown AKIA/ASIA key is NOT learned when: its 16 trailing characters hold fewer than two of the digits 2-7 (about 17 percent of keys if characters are uniform: 3.6 percent none, 13.3 percent one; estimate); it is split by whitespace, `_`, `-`, `/` or by two or more gap characters; it is in lower case AND split. A KNOWN one is still caught by the residue rule. These misses are stated non-goals (round-6 N-2, lead brief), not a reason to hold P1d; ORDER 168 item 3 (HELD) covers false learns.

## The algorithm (pseudocode; no code)
```
redact_text(text, mapping, neutralise=None, *, on_residue="withhold", source="", ref=""):
  try:
    ctx = (_checked_source(source), _safe_id(ref), len(text), on_residue)
    text = text.replace("\x00", "")
    if len(text) > _SETTINGS.max_text_chars: return _withhold("size", ctx, mapping)
    t, shown, work = <the existing redaction, unchanged, incl. neutralise, into a WORK copy of mapping>
            # its budget check (REDACT_BUDGET_S) now calls _withhold("size", ...) instead of raising
    views = _healing_views(t)                                  # Views(v0, a, b1, c, d)
    _learn_unknown(views, work)                                # adds learned values to `work` via redact.add_known
    return _finish(ctx, shown, mapping, work)
  except LookalikeCopy: raise
  except Exception as exc:          # InputTooLarge, TooDeep, TextnormError, RecursionError, MemoryError, bugs
    return _withhold("error", ctx_or_minimal, mapping, exc=type(exc).__name__)   # class name only; never the text

_withhold(reason, ctx, mapping, *, work=None, views=-1, known=-1, exc=None):   # the ONLY place that logs
  log one WARNING line (re-entrancy guard RK11)
  map state: model path and reason residue -> mapping updated from `work` (this call's masked AND learned values);
             reasons size/error, or raise mode -> mapping unchanged (FR2)
  if ctx.on_residue == "raise": raise LookalikeCopy (from None) else return WITHHELD_NOTICE

_healing_views(t) -> Views:  # CUMULATIVE; a skipped step is the identity (exact skips)
  v0 = t
  a  = undo(v0)            only if the existing scan guard is true         # entities, percent, backslash/JSON escapes, P1b depth
  b1 = delete_carriers(a)  only if a holds "<", ESC or a C1 character      # _views.TAG.sub("", a), then ANSI/CSI/OSC/C1/lone ESC
  c  = textnorm.fold(b1)   only if b1 is not ASCII                         # look-alikes, accents, full-width
  d  = delete_noise(c)     only if c holds * ~ backtick, a control, CR, LF, U+2028, U+2029   # underscore kept

_learn_unknown(views, work):
  found = find_matches(views.a, kinds=None)                         # all patterns (pass two already masks these)
  for v in (views.b1, views.c, views.d):
      found += find_matches(v, kinds=SECRET_KINDS - {HIGHENTROPY, CREDITCARD, IBAN})
  for m in re.finditer(r"(?i)(?=((?:akia|asia)(?:[a-z2-7]|[&.\\](?=[a-z2-7])){16,17}))", views.d):   # lookahead, overlapping
      c = m.group(1)
      if count of [&.\\] in c <= 1 and len(c without them) == 20 and count of [2-7] in its last 16 >= 2:
          found.append(("APIKEY", (c without the gap character).upper()))
  for kind, value in found: redact.add_known(work, kind, value)    # reuses _Redactor._place numbering

_finish(ctx, shown, mapping, work):
  known = {o for o in originals(work) if not seed(o) and len(o) >= _SETTINGS.min_key_chars}
  if not known: commit work to mapping; return shown
  dropped = shown with each genuine placeholder replaced by " "
  dviews = _healing_views(dropped).all()
  scripted = {k in known with textnorm.value_scripts(k) non-empty}
  if len(scripted) * sum(len(v) for v in dviews) > _SETTINGS.max_work: return _withhold("size", ctx, mapping)
  finder = residue finder of (known - scripted), cached in work's redact_cache under the map version
  for v in dviews:                                                  # views OUTER
      for w in textnorm.scan_views_no_value(v):
          if finder.search(w) or _edge_run(w, known): return _withhold("residue", ctx, mapping, work=work, ...)
      with textnorm.scan_cache():
          for k in scripted: if _holds(v, k): return _withhold("residue", ...)
      for k in short-key values: if exact_fallback(v, k): return _withhold("residue", ...)
  p = put_back(shown)                                               # ONE pass
  for k in known: if count(k, p) > e(k): return _withhold("residue", ...)
  commit work to mapping (in place, FR2); return shown
```
- **Residue finder:** for each known value with no script, its needles = `textnorm.scan_needles(v)` plus the keys of `textnorm.scan_keyset(v)` that reach `TN_MIN` (`TEXTNORM_MIN_DIGIT_CHARS` for a key of digits only): the same needles `scan_holds` uses (FR4). All go into ONE trie-regex built with `redact._trie`, `_trie_regex`, `_compile_uncached` (not into `re`'s cache, R371). **Identity test:** `test_finder_equals_scan_holds` (property test, Latin values and texts from `p1d_corpus.py`): a finder hit for (text, v) if and only if `scan_holds(text=text, value=v)`.
- **`_holds(v, k)`** = `textnorm.scan_holds(text=v, value=k)`; on `ViewTooShort` or `EmptyView` the exact fallback.
- **`_edge_run(w, known)`** = a known value occurs in w as the start or end of a longer letter-and-digit run. Row H34b, mutant M29.
- **Case copies are masked, not withheld:** `_Redactor.sweep` gets one case-insensitive pass for every original whose `str.lower()` keeps its length (ASCII), masking the copy in place under the original's placeholder with the existing every-copy/standalone rule. Only split copies withhold.
- **Put-back count (copied from `handover/designs/lookalike-leak.md` section 5 item 3, frozen draft 11):** each genuine placeholder is replaced by `" " + original + " "` in ONE pass (a placeholder-shaped text inside a put-back original is not replaced again). `count(k, p)` = non-overlapping `str.count` of each key of k in each key of p. **`e(k)` = the sum over the put-back originals O of (number of O's placeholders put back) x (the SMALLEST count of k's key over the unfiltered keys of `scan_keyset(O)`; an empty key list counts 0).** `count > e` = residue. Two put-back originals that join into k's key are NOT explained (fail closed). Only `shown` is put back (row PB-ENC tests that cut). BS-0 (j) checks this against the note.
- **The put-back test stays only if a named row fails without it:** candidate killers H34b and LK-JAMO-PB; BS-0 (q) runs both with the test off; if neither fails, the test, M10, M38 and LK-JAMO-PB are dropped.
- **The text checked is the text returned:** `_finish` runs on `shown`, after `neutralise`. `defang_text` only inserts `[` `]` around `.`, which the scan key ignores (FR1). `test_returned_card_bytes_pass_the_check` re-runs `_finish` on every returned card; `test_defang_text_only_inserts_brackets`; `test_defang_text_idempotent`.
- **`find_matches(text, *, kinds=None) -> list[(kind, original)]`:** builds a throwaway `_Redactor(None)` and returns what its `find` would place, in order (same `_mask` filters and piece rule), without touching any caller's map. `redact_text`'s own pass does not call it. `test_find_matches_equals_redact_mapping`.
- **Commit rule for learning views (BS-4):** a view stays in the learning loop only if a named H, C or S13 row fails without it.

## Short scan keys (ORDER 166 item 5, ORDER 167)
For a known value whose scan key is shorter than `TN_MIN` (or `TEXTNORM_MIN_DIGIT_CHARS` for digits only) or empty: (1) **exact fallback**: case-INSENSITIVE exact substring search in EVERY deleting view of the dropped form, with `(?<![0-9A-Za-z])` before and `(?![0-9A-Za-z])` after the escaped value, each side only when the value's own first or last character is a letter or digit; (2) one INFO line per call that used it: `redaction coverage=exact_only values=%d` (no content); (3) **strict mode unchanged:** P1d never calls `register_value`; `TEXTNORM_STRICT_COVERAGE` still makes it raise `CoverageRefused`; `test_strict_mode_still_refuses`. F18: `10.0.0.1` has a digit key of 5 < 6, so it goes through the fallback, and inside `210.0.0.12` it is NOT found.
