## The problem in plain words
Secrets and personal data are replaced by placeholders such as `<APIKEY_1>` before a person or a model sees a text. The redactor reads the text only as written, so `AKIA**IOSFODNN7EXAMPLE**` (asterisks make half of it bold), a terminal colour code, an accent, look-alike letters, another letter case or a line break inside a secret hides it, and the reader joins the pieces again. Also: the approval gate turns every `.` in an e-mail address or host name into `[.]` BEFORE the redactor runs, so these are never masked, and a password containing `&` shows the part after the `&`.

## Words used (defined once; one word keeps one meaning)
- **Choke point** = `guard/runmap.py::redact_text`. Every model-bound text, log text, tool result and approval card goes through it.
- **View** = another spelling of the same text, used ONLY to learn and to detect, never shown. The **deleting views** are v0 (the text) plus the outputs of four cumulative steps a, b1, c, d (pseudocode): five views. **Squeezed** = a text with every character that is not a letter or digit removed (digits kept).
- **Seed entries** = the map entries a call starts with: placeholders already written in the text (`channel._seeded`, original starting `"\0seed"`).
- **Known value** (the one definition) = an original masked in THIS call or learned in THIS call, seed entries excluded, raw length at least `P1D_MIN_KEY_CHARS`. On the card path the call's map starts with only the seed entries the text itself yields, so the card decision depends only on the raw text and the arguments. On the model path (default mode, no approve step) the cumulative shared run map is used for masking; "masked in this call" includes a value of that map that the sweep masks again in this call.
- **Learning pass** = the redactor's patterns run on the views (output thrown away; only the found originals kept) plus the squeezed rule.
- **Dropped form** = the shown text with each genuine placeholder (in the map, not a seed) replaced by one space. **Put-back form** = the shown text with each genuine placeholder replaced by `" " + original + " "`.
- **Residue rule** = after masking, no known value may be readable in any deleting view of the dropped form, no known value may be a prefix or suffix of a longer letter-and-digit run whose other side stays in the dropped form, and the put-back count test must pass. If any fails the text is **withheld**.
- **Withheld** = `redact_text` does not return the text. Default (`on_residue="withhold"`): it returns the fixed sentence `WITHHELD_NOTICE` and writes one operator log line. With `on_residue="raise"` (approval-card callers only) it raises `runmap.LookalikeCopy`, for every reason (residue, size, error). The model path never raises.
- **Not approvable** = a request whose card was withheld: no buttons, and the approve path refuses it.
- **KV twin** of a row = the same hostile insertion placed inside a copy of a KNOWN value: the text first holds `password=<S>` (S enters the map), then a copy of S carrying the row's insertion at the same place. It exercises the residue rule and the order of the steps without the learning pass.
- **Carrier row** = a row whose insertion needs a step that changes letters or digits (decode, deleting an escape's payload such as `0m`); it decides that step alone, because the scan key already ignores punctuation (fact R1).
- **Operator** = the person who runs the studio's deployment for the client. **Tier C** = a core change on a redaction path (extended review, no round cap).
- **Test legend:** fb = must FAIL on the base; pb = passes on the base, output unchanged; pb? = decided by a run on the base at BS-0; ow = accepted over-withhold, counted separately; measure = measured and reported, not claimed; new-surface = the expected side needs a name absent on the base (see fail-before); entry card = `clean` (raise mode), model = `redact_text` default, approve = the approve function.

**Non-Goals.** (N1) An unknown secret with no pattern. (N2) What a person types after the card is posted. (N3) S6 `tools._secret_forms` / `_scrub_layers`: P2d-2. (N4) A new endpoint or console. (N5) Exactness above the cap: above it the text is withheld. ## The algorithm (pseudocode; no code)
```
redact_text(text, mapping, neutralise=None, *, on_residue="withhold", source="", approval_id=""):
  try:
    ctx = (_checked_source(source), _safe_id(approval_id), len(text), on_residue)
    text = text.replace("\x00", "")
    if len(text) > P1D_MAX_TEXT_CHARS: return _withhold("size", ctx)
    shown = <the existing redaction, unchanged, incl. neutralise; updates `mapping` in place (R2)>
            # its budget check (REDACT_BUDGET_S) now calls _withhold("size", ctx) instead of raising
    views   = _healing_views(text)                            # Views(v0, a, b1, c, d); (v0,) on the fast path
    learned = _learn_unknown(views)                           # set[str]
    known   = {k for k in originals_masked_this_call(mapping) | learned if len(k) >= P1D_MIN_KEY_CHARS}
    return _finish(ctx, shown, mapping, known)
  except LookalikeCopy: raise
  except Exception as exc:         # InputTooLarge, TooDeep, TextnormError, RecursionError, MemoryError, bugs
    return _withhold("error", ctx_or_minimal, exc=type(exc).__name__)    # class name only; never the raw text

_withhold(reason, ctx, *, views=-1, known=-1, exc=None):   # the ONLY place that logs; -1 is logged as "-"
  log one WARNING line (re-entrancy guard RK11); if ctx.on_residue == "raise": raise LookalikeCopy (from None) else return WITHHELD_NOTICE

_healing_views(t) -> Views:   # CUMULATIVE: each step takes the previous output; Views.all() de-duplicated
  v0 = t
  a  = undo(v0)                 # entities, percent-codes, backslash/JSON escapes, to P1b depth (BS-0 (b); H08, C10 need two rounds)
  b1 = delete_carriers(a)       # tags and comments (_views.RENDERED_MARKUP; if absent on the base, BS-0 STOP), ANSI/CSI/OSC/C1 and a lone ESC (redact._ANSI): payload gone
  c  = textnorm.fold(b1)        # look-alikes, accents, full-width
  d  = delete_noise(c)          # [*~`] always; controls; Cf/Cc; CR, LF, U+2028/2029. Underscore is kept.
  # fast path (if BS-0 builds it): the existing `scan` guard extended to the step characters
  # (`* ~` backtick, `< >`, ESC, controls, C1, CR/LF, plus today's `\ % &` and any non-ASCII); when it is false all
  # five views equal v0 and only v0 is built. The squeezed rule and the residue check still run on v0.

squeezed(s) = the characters of s with str.isalnum() true, in order, with a list of their positions in s

_learn_unknown(views) -> set[str]:
  found = set()
  for v in (views.a, views.b1, views.c, views.d):        # v0 is covered by the existing redaction
      found |= set(redact.find_matches(v))
  sq, pos = squeezed(views.d)                            # views.c if step d is deleted (H37 rule)
  for m in re.finditer(r"(?i)(AKIA|ASIA)([A-Z2-7]{16})", sq):          # unanchored (H35)
      span = views.d[pos[m.start()] : pos[m.end()-1] + 1]               # the 20 characters' span in the view
      if count of [2-7] in m.group(2) >= 2 and _pieces_ok(span): found.add(m.group(0))
  return found

_pieces_ok(span) = every whitespace-separated piece of span is at most 4 characters long, OR span holds no whitespace
  # the OR is this draft's reading, see OPEN QUESTION 3; without it no unsplit key (H32, H33, H35) is ever learned

_finish(ctx, shown, mapping, known):
  dropped = shown with each genuine placeholder replaced by " "
  dviews = _healing_views(dropped).all()
  if len(known) * sum(len(v) for v in dviews) > P1D_MAX_WORK: return _withhold("size", ctx)
  with textnorm.scan_cache():                            # entered once per call; redact_value enters it once around all leaves
    for v in dviews:                                     # views OUTER, values INNER
      for k in known:
        if _holds(v, k) or _edge_run(v, k): return _withhold("residue", ctx, views=len(dviews), known=len(known))
  p = put_back(shown)                                    # ONE pass
  for k in known: if count(k, p) > e(k): return _withhold("residue", ctx, views=len(dviews), known=len(known))
  return shown
```
- **`_holds(v, k)`** = `textnorm.scan_holds(text=v, value=k)`; on `ViewTooShort` or `EmptyView` the exact fallback (next section).
- **`_edge_run(v, k)`** (residue sub-rule, G3) = k occurs in v as the start or end of a longer letter-and-digit run (the run continues past k on one side). Row H34b, mutant M29.
- **Put-back count (copied from `handover/designs/lookalike-leak.md` section 5 item 3, frozen draft 11):** each genuine placeholder is replaced by `" " + original + " "` in ONE pass (a placeholder-shaped text inside a put-back original is not replaced again); the spaces stop NFKC joining a put-back original with its neighbour. `count(k, p)` = non-overlapping `str.count` of each key of k in each key of p. **`e(k)` = the sum over the put-back originals O of (number of O's placeholders put back) x (the SMALLEST count of k's key over the unfiltered keys of `scan_keyset(O)`; an empty key list counts 0, never `min()` of an empty list).** `count > e` = a copy outside any put-back original = residue. Two put-back originals that join into k's key are NOT explained (refused, fail closed; the note's FR-43). Differences from the note, kept from rev 5: only `shown` is put back (no `undo(shown)` form; row PB-ENC is the test of that cut); if P1b exposes one scan key per text instead of a key set, the "smallest over keys" is over that one key. BS-0 (j) checks this against the note.
- **The put-back test stays only if a named row fails without it:** candidate killers H34b and LK-JAMO-PB; BS-0 runs both with the test off; if neither fails, the test, M10 and LK-JAMO-PB are dropped.
