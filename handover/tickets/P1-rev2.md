## Words used here (plain meaning, once)
- **Spelling variant**: one of the at most three ways the fold reads a text (for example: Greek "ypogegrammeni" U+0345 dropped, or read as an iota; or the look-alike table applied before the case fold).
- **Check name** (code: "key"): the text the fold makes from one spelling variant. `identity_key` is one check name; `identity_keys` is all of them.
- **View**: one reading of a text that a scan looks through. `fold_views` and `squeeze_views` give every view; `fold` and `squeeze` give ONE (a single reading).
- **Marks-dropped view**: a view made after removing every spacing mark (Unicode category Mc, for example the Devanagari visarga U+0903), modifier letter (Lm, for example U+02B0, a small raised h) and modifier symbol (Sk, for example `^`) from the raw text.
- **DENY comparator**: a test that refuses when two names could be the same person (`could_be_same_person`). Matching too much is the safe side; matching too little lets a person approve their own request.

### Item 6 (ORDER 175): the same-class fix at the textnorm views choke point

**Bug class (named):** a reader of text that must match a name or a protected value reads ONE spelling of it (`fold`, `squeeze`, `identity_key`, or its own `unicodedata.normalize`) instead of every view, so a character that one reading keeps hides the value. Here the hiding characters are spacing marks (Mc), modifier letters (Lm) and modifier symbols (Sk). Standard it violates: Unicode UTS #39 section 4 (confusable detection compares skeletons after removing what does not change the look) and UAX #15 (NFKD turns some Lm into a plain letter, for example U+02B0 into `h`, so a mark must be removed before NFKD).

**What is wrong today (I reproduced it on `bf955e9`, read-only, Python 3.13.18, Unicode 15.1.0):**

| Text compared with "alice" | inserted character | `could_be_same_person` | `allow_equal` | `has_mixed_script` | found by `squeeze_views` / `fold_views` |
|---|---|---|---|---|---|
| `ali` + U+0903 + `ce` | Devanagari sign visarga (Mc) | False | DIFFERENT | False | yes / yes |
| `al` + U+02B0 + `ice` | modifier letter small h (Lm) | False | DIFFERENT | False | yes / yes |
| `ali^ce` | circumflex accent (Sk) | False | DIFFERENT | False | yes / yes |
| `b` + U+02BC + `ob` vs "bob" | modifier letter apostrophe (Lm) | False | - | - | yes / yes |

So the views already handle the marks; the DENY comparator and the mixed-script signal do not, and nothing makes a caller use the views. On `core/P2d-1` (`8b2b716`) the redactor imports `fold` and calls it at `redact.py:34, 909, 943, 1017, 1036, 1061, 1123, 1222` (my grep), which is PR 77 codebase B1.
