**Words used (plain meaning, one meaning each).**
- **step**: one unit of pipeline work on one item (for example: read a document, cut it into passages, make embeddings). **item**: the one thing a step works on (a document, a message, a passage).
- **step contract**: the fixed shape every step takes in and gives back, and the rule that every item that a step returns ends in exactly ONE final state.
- **final state** (terminal state): `done`, `needs_person` ("a person must look") or `refused`.
- **tenant**: one customer of the system; text of one tenant must never reach another. **readers**: the list of people or roles allowed to see an item. A step may narrow the readers, never widen them.
- **outbound text**: text that leaves our process. Two kinds: text sent to a third party to be PROCESSED (a model, an embedding service, a re-ranking service, a vendor text screen), and text DELIVERED to a named person or system (a tool's HTTP call, an approval card in a chat tool, an outbound message).
- **the AK1 gate** (in this ticket, "the gate"): the one barrier every PROCESSED outbound text passes, doing, in one fixed order: check, mask, audit, reserve money, send, book money. It is built into the place where such parts are made, so code receives only the gated object. **the recipient gate**: the second barrier, for DELIVERED outbound text; it belongs to package AK-G22 (governed outbound messages), not to AK1.
- **gated kind**: a replaceable part (kind) whose calls send text out to be processed. **`Gated`**: the one generic wrapper object the gate gives code instead of the raw part. **gate context** (`GateContext`): the four things the gate needs that the part factory must never see: the environment, the redactor, the audit sink and the spend limits.
- **transport helper**: a core module that sends whatever bytes its caller gives it (`guard/http.py`, the senders in `llm/common.py`).
- **mask / placeholder / mask session**: as in P5c (`tickets/P5c.md`, "Words"): a protected value is replaced with a placeholder such as `<EMAIL_1>`; the mask session holds the run's placeholder map and cannot be copied.
- **hold / reserve / settle / W**: as in P4b1: money is set aside before a call (the worst case; `Meter.hold`, `tickets/P4b1.md:102`), then replaced by the booked cost. **W** is the most ONE request can cost (`P4b1.md:262`).
- **no-training statement**: as in P6b1: a dated, written record by the operator that the provider's terms or account setting keep our text out of training. It records a promise; it does not stop a provider from training.
- **pilot/prod**: a config whose `environment` is pilot or production (the client profile, P6a).
- "UNVERIFIED" = I did not read it in code or could not run it. "PENDING LEAD" = a decision for the lead or the owner, with my recommendation. "INFORM" = my decision on my recommendation, final unless the lead says otherwise (order 6(g)). "ANSWERED" = the lead decided it in a numbered order.

## The decisions that shape this ticket (read before the fields)

**Decision 1 (INFORM I1): the gate is a barrier at the place parts are made, not a helper callers are trusted to use.** Revision 1's public `gated_call(..., call, cost_of, worst, statement_ok)` is deleted (R1-ADV-1 to -3). Now:
- (a) The llm keeps its frozen gate: `MaskedLLM(MeteredLLM(raw))`, built once in `app.build` right after `app.py:162` and before the detectors (`tickets/P4c.md:177`, `tickets/P5c.md:342`), and in `cli.py` (`P5c.md:343`); Runtime refuses anything else (order 22 items 22 and 30).
- (b) Every other kind classified `gated` that has a gate registry row is built by `backends.make` as ONE generic wrapper `Gated` (in `guard/outbound.py`). **Code receives only the `Gated` object; the raw part is not reachable by ordinary attribute access.** No adapter class is written per capability: AK2b and AK2c add a registry row and a price record, not a class.
- (c) "One implementation per step": masking is `mask_leaves` (moved out of P5c-2's `MaskedLLM`, behaviour-preserving); every money booking is ONE function `book_call` in `llm/metered.py` (moved out of P4b1-b's call flow, behaviour-preserving; Interface 7 P10). The gate writes no second masking engine and no second meter.
- Rejected: per-kind adapters over a public helper (a bypass the lint cannot see); a network-level gate in `guard/http.py` (text is already serialised at the socket and cannot be masked or priced; vendor libraries bypass `urllib`).
- Confidence 80 percent; reversible (one module, one change in `make`). **Limit, stated plainly:** this stops mistakes in code that lives in this repository and its demos. Plain Python can still read a name-mangled slot (`object.__getattribute__(g, "_Gated__raw")`); the barrier stops mistakes, not deliberate code in the same process (PENDING LEAD 4). Python code in the same process that imports a vendor library itself is caught only by lint row L8 at test time; code outside the repository is not caught (PENDING LEAD 4).

**Decision 2 (ANSWERED, order 27 item 63 option (a); amends order 23 item 4): every outbound-text path goes through the AK1 gate OR the AK-G22 recipient gate; no path goes through neither.** Path by path after this revision:
- The llm: `MaskedLLM(MeteredLLM)` (frozen, decision 1(a)).
- Registry kinds (embedder, reranker later): `Gated`, and `make` will not build them without a gate context (Interface 6a; rows L10, G11).
