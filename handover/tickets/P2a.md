- Problem in plain words: Hadavin agents need an emergency stop that still works when parts of the system are down, and a reset that records who removed the stop. Core has an on/off switch row with two audited calls, `Limits.stop(by)` and `Limits.reset(by)` (`limits.py:43-51`). Nothing makes a running program refuse a new outside action after the stop, nothing waits for actions already running, and any caller can reset with any name. PR #50 has a gate (425 lines), an in-memory row store (225) and a read-only configuration view (181) that cover part of this. P2a first fixes PR50-local's failing test and a mutation row that proves nothing, then lands the three modules as one `stop_state` kind in which only a person with the right database role can reset.
