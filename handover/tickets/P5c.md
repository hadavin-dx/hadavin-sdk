## Words used in this ticket (defined once)
- **mask**: replace a protected value (an e-mail address, an account number, a key...) with a **placeholder** such as `<EMAIL_1>` before text goes to a model. **put back** (restore): replace a placeholder by its original value again, in code, after the model answered.
- **run map**: on main, the one placeholder-to-value dictionary of a run (`guard/runmap.py:384` `RunMap`, a `dict` subclass). **mask session** (`MaskSession`, new): the object this package puts around the run map: it holds the map privately, cannot be copied, and can be closed.
- **redactor kind**: the replaceable part, chosen by configuration, that masks text (plan-v3 section 5, row "redactor"). Its default is `regex` (the patterns of `guard/redact.py`).
- **masked model wrapper** (`MaskedLLM`, new): the only object through which core code may call a model; it masks every message and document of a call with the run's session before the inner model sees them.
- **stored kinds**: the identifier kinds whose originals may be saved and put back (`defaults.py:108-122` `STORED_KINDS`: ACCOUNTID, ADDRESS, ARN, AZURERESOURCE, EMAIL, GCPRESOURCE, HOSTNAME, IPV4, IPV6, MAC, NAME, PHONE, TENANT). Every secret kind and every regulated kind (IBAN, card, bank account, tax ids) is masked but never stored and never put back.
- **a person looks**: the run stops in state NEEDS_PERSON with a reason code; nothing more is sent to the model.
- **fail before**: a test that fails on the code before this package and passes after it.

- **Problem in plain words:** Before a model reads a document, the core must replace every personal or secret value with a placeholder, and the person who runs the system must be able to trust that no code path skips this. On main, the run loop already does it, but three things are missing. First, there is no single door: five modules call the model directly, and one of them, `extract.extract`, sends the raw document unmasked. Second, nothing ties an agent's approval to the masking rules: change a pattern and the agent keeps running on its old approval. Third, the masking state of a run can be copied and used after the run, and a value put back can be a "cleaned up" spelling rather than what the document said. P5c adds the redactor as a kind (so a second masking method can be plugged in), one wrapper every model call must go through, a version that re-qualifies agents when the masking changes, a session that cannot leak, and narrow rules for putting values back. It also closes two account-number gaps that Intake found, and says plainly which ones stay open.
