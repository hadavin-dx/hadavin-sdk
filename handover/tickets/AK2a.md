**Words used (plain meaning, one meaning each).**
- **document**: one file a client gives us (a PDF or a plain-text file). **page**: one page of it, as the reader returns it. **reader**: the part that turns the file's bytes into page texts. **text PDF**: a PDF whose pages carry real text; a **scan** is a PDF whose pages are pictures of text.
- **quality report**: numbers about one document (pages, characters per page, share of characters that are not text, the main writing system, whether it looks like a scan) plus one **quality code** from a closed list. It never holds document text.
- **cleaning**: a fixed list of small text repairs (line endings, control characters, words split by a line-end hyphen, repeated page headers and footers, page-number lines, extra spaces). **removal report**: for each repair, how many characters it removed. Never text.
- **chunk** (passage): one piece of the cleaned document, cut at headings, paragraphs and sentences, with its page range and position. **chunker**: the part that cuts. **chunk set**: all chunks of one document plus the two reports.
- **writing system** (script): Latin, Cyrillic, Greek, Arabic, Devanagari, Han and so on. The report names the main writing system; it does NOT detect the language (that needs a library; row V3).
- **child process**: a separate Python process the reader starts for each PDF, so a hostile or broken file cannot crash, hang or fill the memory of our own process.
- **step**, **item**, **final state** (`done`, `needs_person` = "a person must look", `refused`), **tenant**, **readers**, **gate**: as in AK1 (`tickets/AK1.md`, "Words used").

     - `c6_spaces`: runs of spaces and tabs inside a line become one space; trailing spaces removed.
     - `c7_blank_lines`: three or more newlines become two.
     - After all rules: if `sum(removed) > KIT_MAX_REMOVED_SHARE_PPM` (300,000 = 30 percent) of `chars_before`, the quality code is `over_cleaned` (a rule ate the document; a person must look).
     - Idempotent: `clean(clean(x)) == clean(x)` with an all-zero second removal report (row R10).
  6. **Chunking (AK2a-1, `ingest/chunk.py`).** `Chunker` (Protocol): `name: str`, `chunk(pages, settings, *, tenant, item_id, content_sha256) -> tuple[Chunk, ...]`.
     - **Text the chunker works on**: the cleaned pages joined with `"\n\n"` (a page break is also a paragraph break); `char_start`/`char_end` index into that joined text; `page_start`/`page_end` are the pages of the first and last character.
     - **`StructureChunker` (neutral default; kit-plan "structure-aware"; bible R139 per AK0 D3).** Blocks = text between blank lines. A block is a **heading** when it is one line of at most `KIT_HEADING_MAX_CHARS` (120) characters, does not end in `.`, `,` or `;`, and is either (a) numbered (`1`, `1.2`, `1.2.3` up to `KIT_MAX_HEADING_DEPTH` (8) parts, or a Roman numeral or a single capital letter followed by `.` or `)`, then a space and text), (b) a Markdown heading (`#` to `######` then a space), or (c) at least 3 letters with every letter upper case. Heading level: the number of numbered parts, the Markdown `#` count, or 1 for (c). A heading closes every open section of its level or deeper and starts a new chunk; `heading_path` is the open headings' texts, outermost first, at most `KIT_MAX_HEADING_DEPTH` entries (a deeper "heading" is treated as a paragraph). Blocks of one section are packed into a chunk until adding the next would pass `KIT_CHUNK_MAX_CHARS` (2,000). A block longer than that is split at the last sentence end (`.`, `?`, `!`, `;` followed by whitespace) before the limit, else the last whitespace, else a hard cut at the limit; no cut ever falls between a character and a following combining mark (category M), a ZERO WIDTH JOINER or a variation selector (row K4). A chunk shorter than `KIT_CHUNK_MIN_CHARS` (200) is merged into the next chunk of the same section; the last chunk of a section may be short.
     - **Overlap**: each chunk after the first in a section starts with up to `KIT_CHUNK_OVERLAP_CHARS` (200) characters of the previous chunk's end, moved forward to a whitespace boundary; never across a heading; `overlap_chars` says how many. Overlap repeats text, so a personal value near a cut appears in two chunks; the gate masks each.
     - **Coverage rule** (checked in `from_bytes` and by row K5): for every chunk, `text == joined[char_start:char_end]`; removing each chunk's first `overlap_chars` characters and joining the rest, separated by the block gaps the cut fell in, reproduces `joined` without losing or repeating a non-space character.
     - **Chunk ids**: `"chk-" + sha256_hex(tenant_key(tenant, content_sha256, settings_fp, str(index)))[:32]` (the `new_id` grammar `prefix-<32 hex>`, `models.py:23`, but derived, not random). Same bytes, tenant and settings give the same ids (AK2d needs that); the same file in two tenants gives different ids, so a store that forgot the tenant key still cannot merge two tenants' chunks by id.
     - **`ParagraphChunker` (built alternative):** the `k1b/bundle.py:181-183` rule (blank-line split, empty parts dropped), then the same over-length split and the same ids; no headings, no overlap. Use: plain notes without structure, or as a fallback a recipe chooses.
     - **Injection flag**: after chunking, `injection_check(detector, chunk.text, source="kit_ingest")` per chunk; `injection_flag = verdict.flagged`; the text is never changed.
  7. **The step (AK2a-1, `ingest/step.py`).** `DocumentStep(readers: Mapping[str, DocumentReader], chunker: Chunker, detector: Detector, settings: IngestSettings)`, `name = "read_and_chunk"`, implements AK1-a's `Step`. Construction refuses (`TypeError`) a detector whose class is not in `LOCAL_DETECTORS = (RegexDetector,)` (I5) and a reader map whose keys are not a subset of `{"text", "pdf"}`. `run(inp: StepInput) -> StepOutput`, in order:
     - (a) `type(inp.body) is bytes`, else `refused invalid_input` (a `str` body is refused, not encoded: the step reads files, not text a caller already decoded).
     - (b) `len(inp.body) > KIT_MAX_FILE_BYTES` (32 MiB) gives `unreadable` `too_large` BEFORE any reader is called.
     - (c) `pick_reader`; `None` gives `unsupported_type`.
     - (d) `reader.read(...)`; an unreadable code ends here. Page count over `KIT_MAX_PAGES` (2,000) gives `too_many_pages`; total characters over `KIT_MAX_DOC_CHARS` (4,000,000) gives `too_many_chars` (the reader stops early; the step re-checks).
     - (e) quality rules on the raw pages, in this order, first failure wins: all pages have zero non-space characters -> `empty`; `nontext_share_ppm > KIT_MAX_NONTEXT_PPM` (50,000 = 5 percent), counting U+FFFD, private-use (Co), unassigned (Cn), surrogate (Cs) and control characters other than `\t` and `\n` -> `high_nontext`; poor pages over `KIT_MAX_POOR_PAGE_PPM` (100,000 = 10 percent) of pages -> `suspected_scan`, where a **poor page** has fewer than `KIT_MIN_CHARS_PER_PAGE` (100) non-space characters and `has_images` is `True` or `None` (a page with `has_images=False` and little text is a blank or short page and is not poor; `None` counts as poor: fail closed); median characters per page below `KIT_MIN_CHARS_PER_PAGE` -> `low_text`.
     - (f) `clean(...)`; `over_cleaned` ends here.
     - (g) chunk, flag, build the `ChunkSet` (tenant and readers copied from `inp`, unchanged), `done` with `body = chunk_set.to_bytes()`.
     - **Mapping to AK1-a outcomes** (`STEP_OUTCOME: Final[Mapping[str, tuple[Outcome, str | None]]]`, one row per code, total over `QUALITY_CODES`, row R13): `ok` -> `done`; the six poor codes -> `needs_person` `low_quality`; the ten unreadable codes -> `needs_person` `unreadable` (I8). Every non-`done` output has `body=None` (AK1-a rule). A person sees the item id and the reason in AK1-a's outcome audit event; the full quality report is reproducible from the stored file and `settings_fp` (the report is a pure function of both), so AK2a stores nothing for it (row V7 if a durable copy is wanted).
     - Exceptions: AK2a raises none for a bad document; an unexpected bug raises and AK1-a's runner turns it into `needs_person step_error` (AK1 Interface 3(d)).
  8. **Settings (AK2a-1, `ingest/settings.py`).** `IngestSettings` (pydantic, frozen, `extra="forbid"`) with one field per `KIT_*` constant, defaulted from `defaults.py`, each with bounds (`gt`/`ge`/`le`). Model validators refuse: `KIT_CHUNK_MAX_CHARS + KIT_CHUNK_OVERLAP_CHARS > defaults.MAX_REDACT_CHARS` (a chunk must fit the redaction cap, so the gate never cuts a chunk before masking it, `defaults.py:41-44`); `KIT_CHUNK_OVERLAP_CHARS >= KIT_CHUNK_MIN_CHARS`; `KIT_CHUNK_MIN_CHARS >= KIT_CHUNK_MAX_CHARS`. `settings_fp` is a read-only property.
  9. **`PdfTextReader` (AK2a-2, `ingest/pdf_text.py`, the neutral default for PDFs).** `name = "pdf"`. `read(data, settings)`:
     - Starts `[sys.executable, "-I", "-m", "hadavin_sdk.ingest._pdf_worker"]` with `subprocess.Popen(..., stdin=PIPE, stdout=PIPE, stderr=DEVNULL, env=_child_env(), close_fds=True, shell=False)`. `_child_env()` keeps only the names in `KIT_PDF_CHILD_ENV` (a tuple in `defaults.py`; on Linux empty, on Windows `("SYSTEMROOT",)`, because Python cannot start there without it: UNVERIFIED, the builder checks on the CI images); no secret, token or `HADAVIN_*` variable reaches the child.
     - Writes the bytes, closes standard input, reads at most `KIT_PDF_MAX_RESULT_BYTES` of standard output (a derived constant, `4 * KIT_MAX_DOC_CHARS + 1 MiB`: four bytes per character of UTF-8 at worst, plus room for the JSON frame), waits at most `KIT_PDF_TIMEOUT_S` (30) seconds of wall time; on expiry `kill()`, `wait()`, code `timeout`. Exit code not 0 with no valid result: `worker_crash`. A result over the size cap: `too_many_chars`.
     - The worker (`ingest/_pdf_worker.py`) imports only the standard library and the PDF library; on POSIX it first sets `resource.RLIMIT_AS` to `KIT_PDF_MEMORY_MB` (1,024) MiB, so a decompression bomb gives `MemoryError` -> code `memory`; on Windows no memory limit exists (stated limit; row V2). It refuses an encrypted file (code `encrypted`, even when an empty password would open it: fail closed), stops after `KIT_MAX_PAGES` pages or `KIT_MAX_DOC_CHARS` characters, and writes one JSON line: `{"code": ..., "pages": [[text, has_images], ...], "reader": "pdf:<library>==<version>"}`. Library errors give `corrupt`; the error text is never written out.
     - `has_images`: `True`/`False` only where the library reports a page's image objects; otherwise `None` (counted as poor, fail closed). Library-specific markers for unmapped glyphs (some libraries write placeholders such as `(cid:NN)`) are replaced by U+FFFD in the worker, so `high_nontext` sees them; the builder lists the chosen library's markers.
  10. **Errors.** AK2a defines no new exception class for documents (bad files are codes). `TypeError` for wrong argument types, `ValueError` for invalid settings or a refused `from_bytes`. Messages name the field or code, never a value.
