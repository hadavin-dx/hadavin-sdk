**Words used (plain meaning, one meaning each).**
- **pipeline**: several steps run one after another on many items (AK1's words "step", "item", "final state", "tenant", "readers", "gate" keep AK1's meanings, `tickets/AK1.md:10-15`).
- **harness**: test code that runs a whole pipeline on made-up items with the fake model, then runs a fixed list of **checks** over everything the run left behind (log lines, printed text, audit events, written files, the texts the fake model received, the outputs).
- **canary**: a made-up value planted in the input as if it were personal data, for example the e-mail address `canary-<32 hex>@example.invalid`. If the canary is found where personal data must never be, a check fails. The hex part is random per run, so it cannot appear by chance.
- **finding**: one failed check, as a closed code plus where (a logger name, an audit field name, a file path relative to the run folder); never the canary itself.
- **fault**: something broken on purpose by the fake model: a call that times out, a "too many requests" answer (HTTP 429), a bad reply, a reply cut off part way, or a document carrying an injected instruction.
- **billing ledger**: the list the fake model keeps of what a real provider would have charged for each attempt (made-up prices). It is the "truth" a spend check compares with the cap; it is NOT the core's own meter.
- **golden set, bucket, trap**: the agent's examples with the right answers (`golden_dir/<agent>.jsonl`), each line labelled `easy`, `hard` or `trap`; a trap is a request that must be refused (the right answer is "no action").
- **abstain / false abstain**: the agent proposes no action; false abstain = an answerable item (one whose right answer IS an action) that was abstained. Reported apart from correct refusals of traps.
- **qualify / green run**: a gate run that passed; it is one line in `qualified.jsonl`, and an agent with no matching green line cannot start (`evals.py:1-5`, `runtime/agent_loop.py:141-157`).
- **pilot/prod**: a config whose `environment` is `pilot` or `prod` (`config.py:317`).
- "UNVERIFIED" = I did not read it in code or could not run it. "PENDING LEAD" = an owner or lead decision, with options and my recommendation. "INFORM" = my decision on my recommendation, reported, final unless the lead says otherwise (order 23 item 4, order 6(g)).
