## Tests that behave differently between 3.12 and 3.13: exactly ONE (same on BASE and STACK)
`tests/test_path_confinement.py::test_v3_our_device_list_covers_what_python_says_windows_reserves`: SKIPPED on 3.12 -> PASSED on 3.13. Cause (read from the skip reason and M's report): the test calls `ntpath.isreserved`, which exists only on Python 3.13 (checked: `ntpath.isreserved` is present in the 3.13 venv). So the repo's own list of Windows reserved device names agrees with what Python 3.13 says on this Linux machine.

## No other id differs
Every other test id that both runs report has the same status (3682 identical PASSED, 199 identical SKIPPED, no FAILED or ERROR on any of the four runs). The same 199 skips remain on 3.13 (Playwright missing, gitleaks missing, the Windows-only reset test, the root-user permission test, the LEAD_DESK_LOAD_N measurement) because Playwright and gitleaks were not installed in the 3.13 venv.
