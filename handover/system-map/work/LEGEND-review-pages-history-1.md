# Legend for the review and resolve pages in work/
Read this first. It is a key, not a finding. Everything here is UNVERIFIED unless a page says otherwise.

- lead session: the Claude session that gives orders to this session (system-map).
- studio lead: the Claude session that does the technical steps (running n8n, the rehearsal, the take).
- owner: the human who films and posts.
- studio head: an older name for a person role; nobody is confirmed to hold it. Treat as "unknown".
- take: the one filmed run of the lead-intake demo on made-up data, run through n8n.
- desk: the older demo program; the lead decision list says it is retired from the take (UNVERIFIED).
- SWEEP.md and ONE-PLACE-TABLE.md: the two summary pages produced from the lane files (L1..L6) by tools/write_outputs.py. Both are held pages (read, not edited, by this session).
- lane (L1..L6): one cold read of a group of repository files, written to work/L<n>.md.
- job key: one word for a job the system does (store, log, filter, count, retry, notice). The page that uses it gives its own meaning; if two pages differ, work/GLOSSARY.md wins.
- verdict words in resolve pages: PROPOSE FIX = the finding is right and a fix is written; CONTEST = the finding is rejected with evidence; ESCALATE = a fact is needed from the lead; DECLINE = a Nit, no fix.
- reviewer codes: CD = codebase-details reviewer, ZO = zoom-out, DE = design, CO = comprehension. A code like CD-B1 means reviewer CD, Blocker 1.
- severity: Blocker = a reader cannot act or will act wrongly; Major = a reader may be misled; Nit = style only.
- NOT RECORDED = the fact was not found in the files read; it is not a statement that it is false.
- Times: UTC first, IST (UTC+5:30) second.
